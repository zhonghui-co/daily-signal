2.1 师父世界观骨架：一条生存链

师父的心法不是散句，是一条环环相扣的链条。读懂这条链，就懂了他所有话：

「只用输得起的钱」→「余闲（现金）永远在手」→「心态从容」→「能执行纪律」→「止损无情、先保命」→「活得久」→「等确定性、耐心伺机」→「只在关键点出手」→「赚国运的钱」。

反过来，这条链断了任何一环，人就会：拿输不起的钱 → 满仓 → 焦虑 → 乱动 → 不止损 → 死得快。师父所有心法，本质都是给这条链上保险。

平行主线：看大哥、跟国家走。 市场是筹码游戏，散户没信息、没资金、没定价权，唯一能赢的路，是站在有定价权的那一方后面——大哥（主力）没上桌，一切都是噪音；国家意志还在，就跟着走；大哥走了，你也走。这一条贯穿「对手盘观」和「国运观」。

3. 坑三式（挖坑填坑：大坑 / 小坑 / 小洞）

  • 意：赚"恐慌深坑→修复"的确定性钱；核心是目标价算法（祖宗之法）：坑口价×2 − 坑底价。
  • 大坑（月线级）：有历史新高 + 长时间屁滚尿流一路下跌 + 起稳一段时间 → 赚大钱（拿住不动/信仰）。
  • 小坑（周线级）：有阶段高点 + 回调后起稳 + 不破阶段前低 + 拱到大复值 → 赚小钱（少妇战法）。
  • 小洞（日线/30 分钟级）：N 型上升趋势中黑天鹅突然下杀 + 勾到大复值 → 快进快出碎银子（就一根，不建议碰）。

2. 三波理论（建仓波 / 拉升波 / 冲刺波）

  • 意：把一波行情拆成三段，判断"现在赚的是哪一层的钱"：建仓波（底部放量、涨幅 25-50%、不涨停，主力吸筹）→ 拉升波（快速脱离成本、不翻倍）→ 冲刺波（75-80 度连板）→ 横盘 → 再建仓波。建仓波不追（要等第二个 B1 甚至 SB1）、拉升波选股谨慎、冲刺波是出货区。
  • 形：建仓波"两个 30%"（涨幅 + 大阳线累计换手率各 30% 掐正态分布尖）；换手率 >100%（甚至 150%）=一波流出货。涨停幅度折算（创业板 20% / 主板 10%）。
  • 案例（原文带数字）：建仓波涨幅 25-50%；四根线换手率 164%=把散户全换了。
  • 组合关系：三波理论用于"定位一波行情的阶段"，配合 0AMV 择时判断"现在该做哪一层"。
  • 出处：20250716、20251217、20260309。

3. 择时三要素（天时地利人和）

  • 意：择时的三根支柱。
  • 形：天时=宏观经济周期（康波是西方经济学，中国不适用；现在中国=扩张周期即可）；地利=政策周期（中国最重要，"有形的手比无形的手牛逼一万倍"）；人和=增量资金（最重要，"不管天时地利，最终干事的还得人和"）。
  • 出处：20250702。

5. 量价六概念（量价关系）

  • 四分之三阴量线：突破次日量缩到前日 1/2~4/4 之间的阴线 = ≥70% 假突破，不加仓；缩半量以下 = 真突破 77-80%。
  • 缩半量：完美加仓图形（量缩前日约一半 + 小阳）。
  • 平量：趋势延续（非常好）。
  • 倍量：≥前日 2 倍=真实买入；倍量再倍量=天量。
  • 天量/倍量：S1 候选（加速 + 放天量 + 大阴线）。
  • 地量：缩到极致，配合小阴小阳=B1 最好买点。
  • 出处：20250531、20251210、20251224。

6. MACD 用法——一票否决权 / 最后顾问

  • 意："唯一具有趋势预判性质的指标之王"，把 B1/B2/双线/S1/筹码验完再回看它。三大用法：判多空（DIF 零轴）/ 看背离（顶背/底背）/ 金叉空死叉多（空中加油）。背离背后 = 建仓完成后洗盘锁筹 → 量价关系失效 → MACD 难创新高。
  • 形：顶背离看日线、底背离可参考周线；与活跃市值印证（活跃市值先翻、MACD 后确认、共振最好）。⚠️ 白线/黄线在此是 DIF/DEA，勿与知行趋势线混淆。MACD 默认参数（12/26/9）不用改。
  • 案例（原文带数字）：1800→1664 底背离案例（20260422）；530 案例（2007 印花税半夜政策 3 个跌停）。
  • 组合关系：MACD 是"最后顾问"（一票否决权），可作 B1 后复核。
  • 出处：20260422。

7. 筹码理论

  • 意：只看低位筹码有没有转移到高位——没转移=锁仓/没出完，转移=出货/换装。筹码峰下沿"不是顶就是底"：向上突破=底（新主力建仓）、向下跌破=顶（出货）。只判断建仓与出货、不决定买卖点；SE 永远优先于筹码。
  • 形：锁仓拉升=长庄形态（B1 敢买）；高位密集=危险；超大盘（万亿市值）不看筹码；反弹看上方套牢盘比例（需 ~80% 低位密集才可能启动）；周线不看筹码。
  • 案例（原文带数字）：某票 924 后 73→140 翻倍，横盘期间新大哥成本 128，最后多杀多，满盘套牢 95.7%；某票主力底仓从 85% 只剩 8%；双峰填谷 26 块填谷从 26 启动看 52。
  • 出处：20260408、20260419。
