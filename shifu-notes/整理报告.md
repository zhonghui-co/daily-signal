# 二、道的骨架（心法）：一条保命链 + 八大观 + 12 条内化版 + 50 金句

> 底料：《师父心法总纲》（八大观 + 50 金句，约 38.5KB 全文）。本章只取"道"，战法参数一律不进本章（除非那个数字本身就是心法，如"年化 18% 是极限""66/24/10""一周最多 1-2 个新仓"）。

## 2.1 师父世界观骨架：一条生存链

师父的心法不是散句，是一条环环相扣的链条。读懂这条链，就懂了他所有话：

**「只用输得起的钱」→「余闲（现金）永远在手」→「心态从容」→「能执行纪律」→「止损无情、先保命」→「活得久」→「等确定性、耐心伺机」→「只在关键点出手」→「赚国运的钱」。**

反过来，这条链断了任何一环，人就会：拿输不起的钱 → 满仓 → 焦虑 → 乱动 → 不止损 → 死得快。师父所有心法，本质都是给这条链上保险。

**平行主线：看大哥、跟国家走。** 市场是筹码游戏，散户没信息、没资金、没定价权，唯一能赢的路，是站在有定价权的那一方后面——大哥（主力）没上桌，一切都是噪音；国家意志还在，就跟着走；大哥走了，你也走。这一条贯穿「对手盘观」和「国运观」。

## 2.4 12 条心法全文（内化版 + 出处 + 关键金句）

> 以下 12 条是 Mimo 依据 108 课 digest 内化、已进入 SOUL.md 的版本；每条配出处课次与关键金句原话（金句统一来自《师父心法总纲》第 50 句）。

1. **先保命，永远记住先保命。** 止损第一公理；每条建议先过"会不会死"。
   - 出处：20260730（先保命）、20261011（Lesson One=止损）、20250903（牛市亏大钱）、20260923（止损无情）、20250712（止损=正常成本）、20260408（止损像球星投篮）。
   - 金句："先保命，永远记住先保命。""Lesson One = 止损 = 不要被套住。""永不套牢，只输一根。""善输善败者无敌。"

2. **只用输得起的钱；余闲=现金，永远不满仓；仓位越重人越笨。** 空头区间的弹药是现金。
   - 出处：20260826（稀缺）、20250903（三铁律）、20250922（20% 预备队）、20251112（分仓/重仓）、20251203（手紧手松）。
   - 金句："余闲 = 现金，永远不满仓；仓位越重人越笨。""只用输得起的钱。""分仓目标 = 让自己睡得着觉；重仓目标 = 快速赚爆发差价，赚到马上减。""不主动超配，超配是涨出来的。"

3. **垃圾时间休息，耐心等待、伺机而动。** 0AMV 空头区间=垃圾时间，市场约 66% 时间是垃圾时间。
   - 出处：20260812（垃圾时间）、20260720（66/24/10）、20260902（上课/下课铃）、20261014（八字总纲）。
   - 金句："垃圾时间该休息，主力轮休，散户只是角色球员。""耐心等待，伺机而动。""不要牛熊概念，只有择时（上课/下课铃）概念。"

4. **市场赚人性的钱；反着来、走少有人走的路。** 分析先问大众情绪，站到赢家一边。
   - 出处：20261011（市场赚人性的钱/反着来）、20260805（人弃我取人强我让）。
   - 金句："市场赚人性的钱。""反着来、走少有人走的路。""人弃我取、人强我让。""贪婪=赚了不走想赚更多；恐惧=一套就害怕。"

5. **只做看得懂的；不要对市场问为什么。** 给应对，不做无意义归因。
   - 出处：20260211（不要问为什么）、20250618（只做看得懂）、20260408（守株待兔）、20260812（只做看得懂+足够了解足够相信）。
   - 金句："不要对市场问为什么——没有为什么，只有应对。""只做看得懂的票——知道怎么输的钱。""赚你看得懂的钱。""给了就拿、没给就走、跌了止损、起来了拿着。"

6. **市场永远是对的；价格包含一切。** 不抱怨市场，不劝 MOS 和市场作对。
   - 出处：20260819（价格包含一切）、20260927（市场永远对/世界永远错配）。
   - 金句："价格包含一切信息。""市场永远是对的。""永远不要抱怨市场：市场一切走势都对，错了也对。""你能谈到什么姑娘一定是市场定价，做股票也是，市场不会错。"

7. **纪律是反人性的锁；执行>选股；交易只分正确/错误。** 按纪律执行就是正确交易。
   - 出处：20250716（交易只分正确错误）、20260419（大师靠纪律）、20251119（每天三件事）、20260204（四不）、20260916（次次守纪律）。
   - 金句："交易只分正确/错误，不分成功/失败。""选股不重要，执行才重要。""每天就干三件事 = 止损、放飞、滴滴；没人套得了你。""次次遵守纪律、养成肌肉记忆，才能躲过那一次大的。"

8. **慢就是快；赚的是精神损失费；"我不要了"。** 频率纪律=一周最多 1-2 个新仓。
   - 出处：20260505（慢就是快）、20261011（我不要了/精神损失费）、20260404（慢就是快两个维度）、20260923（煎熬的钱）。

## 3.0 总纲级工具（所有战法的前置环境判断 + 后置持仓骨架）

### 0.1 择时：活跃市值（HYSZ / 0AMV）

- **意（赚什么钱/底层逻辑）**：先于选股解决"现在能不能做"。活跃市值判断大盘**真实增量资金**——红柱=钱转筹码（涨）、绿柱=筹码转钱（跌）；本质=**赚钱效应**。空头区间一切买点分析都降级，多头区间随便干。师父名言："投资收益不来自勤奋，而来自节奏。"
  - 底层原理（20251022 重讲）：活跃市值反映"市场里流通筹码换手情况"，只会有两种情况=筹码变现金 / 现金变筹码，**不存在横盘**。红色=钱转成筹码=筹码被集中变稀缺→好上涨；绿色=有人把筹码变成钱=盘子散了、筹码供大于求。
  - 适用环境：多头/空头总开关；空头区间唯一动作=只卖不买、去弱留强。
  - 失败场景：把活跃市值当"圣杯"、小路过载——20251022 原话"别给活跃市值加双线/顽礼/关键K（哥们别小路过载）；连 N 型结构、突破都不用考虑"。4% 翻红**不是圣杯**：它决定赚钱概率，不告诉你钱进了哪个行业（20260408）。
- **形（操作细则/参数）**：⚙️ MOS 现行口径——转多 = 1-2 日合计涨幅 > **+6.5%**；转空 = 跌幅 < **-4.5%**。课程原始口径（+4% 转多 / -2.3% 转空）仅作历史参照。
  - 课程分级数字（仅历史参照，区分"波段分级"与"入场线"）：小波段 ≥4% 阳线=主题级；大波段 5-8% 阳线=主线级；十年一牛 7-20% 阳线（20250702）。
  - 离场铁律（课程历史口径）：单日跌幅 2.3% 以上绿线=大概率区间见顶（案例 2.34/2.32/2.31/2.4 反复验证）；1.81/1.75/0.6 没事。
  - 指标本身：⚙️ MOS 自研 v5/v5test（Σ成交量×OHLC），指南针 0AMV 数据不公开，属有意替代。
- **案例（原文带数字）**：
  - 924 案例（20250702）：活跃市值 9.87%→8.8%→9.87%→12.83%→27.85%→**25.23%（10 月 8 日=踏空机构不得不买）**→10 月 9 日 0.69%=场内机构倒给你。

  - 20251022：9 月 4 号 -2.52（大于 -2.3）→ 第一根阴线转下跌趋势；此后一切大于 -2.3 都在下跌趋势内。

  - 20250702：924 案例"某队新一波成本 3100-3200"（4/9-4/11 三天 5.78%/4.12% 入场）。
- **组合关系**：活跃市值=所有战法的"总开关"，空头区间只卖不买；转多后板块 B1 扫描才生效（管线 transition_sector_scan）。与 MACD 印证：活跃市值先翻、MACD 后确认、共振最好（20260422）。

### 0.2 双线：白线 / 黄线

- **意（赚什么钱/底层逻辑）**：

## 3.1 进场体系（买点）

### 1. 少妇战法（六步）——体系总纲

- **意**：本质=**跟随不是预测**。赚的是"第一波填坑的钱"（N 型结构回到前期高点）。解决散户三大死穴：①一买就被套（B1=短期获利盘/卖盘枯竭的位置）②盈亏比差（向上 10% / 向下 2% ≈ 5:1）③节奏乱。适用环境 = 有增量资金的多头区间（B1 才有意义）。失败场景=在空头区间硬做 B1（黄线之下 B1 失效）。
- **形（六步）**：
  1. **择时**（最难）：经济周期 + 政策指引 + 增量资金（最重要）+ 入场时机（等 B1）。
  2. **选股（五看）**：看政策 / 行业 / 龙头公司 / 有没有人搞（资金/大哥）/ 估值（主题可放一放）。
  3. **等比一（等 B1）**：主线等周 B1、主题等日 B1；⚙️ J < 15（MOS 口径）。
  4. **设止损（上套）**：当根入场 K 线最低点下方 / N 型上一低点；"只输一根"。
  5. **止盈放飞**：BBI 线上两根中大阳减仓；放飞后不管。
  6. **彻底离场**：连续两日跌破 BBI 线收队。
- **案例（原文带数字）**：20250716 纯盲选 9 个交易日演示——9 天 **12%（半仓）**，最大单笔盈利 16%、最大单笔亏损 4%，其余赚 3%/1.5%/跌 4%/0% 混着；逐笔：-4、+2.5、-1.5、+3、+3、+8、-4、+16、+4（累计约 24%，半仓 12%）。
- **成功率（🔶 口径漂移，仅供参考、不重要）**：约 30%（游资打板十分之零点五）；胜率三处不一致（55-60% / 37-40% / 40%多）——**三个数字仅供参考、不重要，不作定稿依据（MOS 定稿：B1 胜率不重要）**。
- **组合关系**：少妇战法是所有战法的"母战法"，六步是总纲；双线是它的 pro 版；B1/B2/B3 是第 3 步"等比一"的细化；瑜伽裤战法是它的"超短分支版"。
- **出处**：20250531（前 4 步）、20250709（补 5/6 步）、20250712（B1 本质）。

### 2. B1 / B2 / B3 三件套——买点体系（组合关系核心）

**组合关系**：**B1（等比一，最低位潜伏）→ B2（确认 B1 的那根放量阳线）→ B3（⚙️ 定稿：放量后缩量两天加仓点；原"中继小阳"为历史口径）**。B2 一定接 B1（不是凭空突破）；B2 确认 B1、B3 确认 B2（三重保险）。三维排名：**盈亏比 B1>B2>B3；确定性 B3>B2>B1；止损幅度 B2>B3>B1**。

#### B1（等比一）

- **意**：赚"卖盘枯竭→第一波填坑"的钱，盈亏比最高（向上 10%/向下 2%≈5:1，区间内可能 3:1），潜伏型。
- **形**：⚙️ J<15（系统口径，课程 J<13）+ 白线>黄线 + 收盘>黄线。附加量化（20250903）：涨幅 -2%~+1.8%（小阴小阳）、振幅 ≤7%（最好 ≤4%）、缩量地量。次日涨停概率 ≈1%，买入后 3 天窗口。

#### B2（三大高爆发力）

- **意**：赚"最快启动、最敏感"的那一段，B2 一定接 B1。确认 B1 后最快启动、最敏感。

### 3. 坑三式（挖坑填坑：大坑 / 小坑 / 小洞）

- **意**：赚"恐慌深坑→修复"的确定性钱；核心是**目标价算法（祖宗之法）**：坑口价×2 − 坑底价。
  - 大坑（月线级）：有历史新高 + 长时间屁滚尿流一路下跌 + 起稳一段时间 → 赚大钱（拿住不动/信仰）。
  - 小坑（周线级）：有阶段高点 + 回调后起稳 + 不破阶段前低 + 拱到大复值 → 赚小钱（少妇战法）。
  - 小洞（日线/30 分钟级）：N 型上升趋势中黑天鹅突然下杀 + 勾到大复值 → 快进快出碎银子（就一根，不建议碰）。
  - 适用环境 = 有基本面 + 有主线/主题背景的坑。失败场景=没填像样坑 / 基本面不懂 / 不在当前主线主题（三个不能做）。
- **形**：三个不能做（没填像样坑 / 基本面不懂 / 不在当前主线主题）；三个能做（填完中型坑出坑回踩 / 填大坑 N 型完美 / 主线出坑低点抬高）。破位=破坑沿（不是破低点）；假破位=跌破该段 50% 后收回。
- **案例（原文带数字）**：
  - 中石化：盖 5.97 底 3.2 → 8.74（实际 7.24"艺术"）。
  - 小米：盖 35.9 底 8.31 → 63.5（实际 59.45"艺术"）；突破后回踩 36.05 vs 坑口 36（"差一毛钱"）。
  - 三生制药：盖 22.69 底 4.17 → 41。
  - 李宁：净线位 28 底 14.8 → 41.2（实际 44.6"艺术"）。
  - 同概念两龙头（黄金类）：盖 78 底 30 → 126（实际 126.3）。
- **组合关系**：坑三式=中长线第三件武器；大坑靠信仰（基本面），小坑用少妇战法；出坑回踩坑口确认后勾大复值=接着抡。
- **出处**：20250625、20250626、20260219。

### 4. 补票战法 / 单针下 20/30——偷袭机构的超短

- **意**：专治"错过 B1"。用知行洗盘短线指标（红线=机构/长期资金、白线=散户/短期资金）抓主力"既控盘又让散户在底部换筹码"的洗盘末尾。赚主声浪里洗盘结束到再拉升那一段。只在小资金、只做看得懂的那一根。失败场景=在冲刺波（60 度以上）用。
- **形**：单针下20 = 白线≤20 + 红线≥80；单针下30 = 红线 70 / 白线 30（参数可选 80/20、85/30、70/30）。只在主声浪（斜率 35~60 度，45 度最完美；60 度以上冲刺波不用）；持有 1 交易日、必须脱离成本、未脱离次日开盘拍。
- **案例（原文带数字）**：主声浪斜率量化 35-60 度、45 度最完美（20260429）；单针下 20→30 演进：20250601 红线 80/白线 20 → 20260429 红线 70/白线 30。
- **组合关系**：补票是 B1 的"补救"；深水炸弹=小洞（已被淘汰），"威回来形成几尺钉耙更稳定"。
- **出处**：20250601、20260429、20251126。

### 5. 双线（白/黄）与循环操作法

> 详见 3.0.2，此处补循环操作法。

- **意**：少妇战法的"pro 版"——用白黄两条线把"跟随"固化成可循环的持仓骨架，解决"拿不住主升浪"。
- **形**：到 B1 抡 → 白黄区间接着抡 → 加速放飞 → 跌破白线（顶部无量未出货）→ 回 B1 再买，反复循环。"碗"=白线与黄线之间容错买入区（不必追求完美 B1）。加仓纪律：本金 10 万最多加到 18 万，确保一根跌停不破本金。
- **案例（原文带数字）**：八一钢铁 B1/B2 皆可，8.34 可干（放量缩量放量缩量图形完美）；江铜区间 27/26 分批 1 万 1 万买。
- **出处**：20250831、20251004。

### 6. 专形图 / 砖型图（红持绿空，三种定式）

- **意**：底层=宝塔线 + 活跃市值 + 参数 + 量价。红持绿空、绿转红买、红转绿卖。核心是**"数四块砖"**（第 4 块红砖放飞、随时反转）——"4"源自威尔德 Delta 三角洲理论（市场每 4 天/4 月/4 年/19 年重复）。赚 4-6 天波段的钱。
- **形**：三种定式 = ①N 型起跳 ②横盘起跳（"大块红砖压绿砖"成功率更高，起来前一定要有横盘）③上升波段延续。三要素（缺一不可）= 位置 + K 线形态 + 砖块大小。卖出三条件 = 数四块红砖减/清、红变绿走、买入不涨次日走。参数 4 与 6；持仓 4~6 天。
- **案例（原文带数字）**：平均涨幅对比（上百个票样本，20260325）：专形图 **2.87%** > B2 2.46% > B1 2.14%；数砖回测概率 80% 多（A 股 05-07 恨不得 90%，上周只有 20-30%）。
- **组合关系**：可嫁接 B1/B2/B3/单针下 30；B3 之后改盯白线不盯专形图；20 厘米票判断长阳/中阳要除以 2。
- **出处**：20260220（瑜伽裤）、20260224、20260318、20260325。

### 7. 瑜伽裤战法（知行专形图超短线）

- **意**：寻找转折点的爆发力，只做"绿转强红"（红柱幅度 ≥ 绿柱三分之二），赚绿转红后两根 K 线的钱。师父自称"暗器/绝学"，第一次动私心教的真东西。只适合小资金搏命（10 万→100 万）。失败场景=不懂四不原则（不杠杆/不用输不起的钱/不杀红眼/不补仓）。
- **形**：位置过滤=黄线之上 + 白线在黄线之上（多头）才做；六步 = 绿转强红→尾盘买/次日不追高→分两仓→止损=买入 K 线最低价或 2 日不拉起走→蹬起来 3% 以上分批卖→脱离成本 5% 以上最多持 4~6 天。口诀：我要赚钱/给多少拿多少/不给就走/永不完美/下一个会更好。
- **案例（原文带数字）**：牛市平均每笔净盈利 3.5%，熊市参数（4 跟 6）优化后 1% 或 0.8%，一年 500 笔交易；共振（绿转红叠 B1/B2）=胜率从 50% 提到 53-55%；量化机构规模与收益反比：1000 万可做 300%/年，100 亿只能 15%/年。
- **组合关系**：瑜伽裤=少妇战法的"超短分支版"（只买 B1 位置的转折点爆发力）。
- **出处**：20260220。⚠️ 底层参数"优化过的成功率参数"未公开，难以精确复现。

### 8. 单针下 20/30、暴力 K、瑜伽裤 等超短（已合并见上）

### 9. 暴力 K（底部）

- **意**：赚"底部放量转折"的信号钱，前提=倍量柱+关键K。暴力K=确定性的中长期波段开始。三种类型：趋势扭转的大暴力（观察不干）/ 趋势改变的大暴力（开始干）/ 趋势延续的小暴力（干）。
- **形**：四要素：①底部位置（绝对/相对/趋势中第一位置）②很突兀/莫名其妙 ③又粗又大一步到位 ④让你害怕的时间点或位置（最重要、反人性）。A/B/C 三型=趋势扭转/改变/延续。
- **案例（原文带数字）**：比亚迪 2017 年 9 月 12 入场点（后面四倍→八倍到十倍）；厦门空港（钩已 114，不敢干）；央广电源 8 月 8 号涨 9.19% 横盘小突破超级倍量柱。
- **组合关系**：暴力K 建立在关键K + 倍量柱之上（缺一不可）；暴力K 之后最好买点是 B1（等回调给 B1）。
- **出处**：20251224、20251229。

### 10. 关键K 战法

- **意**：绝大部分 K 线无意义，只服从 1~3 根关键K（关键位置/黄线上的放量中大阳线/涨停板）=大资金入场/离场信号。两大意义：趋势反转 + 走势衰竭。失败场景=把"加速阳线"当关键K（连续拉升后两根放量大阳线是加速，不是关键K）。
- **形**：趋势反转六型（V 型/紧急刹车/平地惊雷[横盘→上涨，确定性最高]/A 刹/上涨转横/丢盔卸甲）+ 走势衰竭（卖盘枯竭=B1 买点、买盘枯竭=S1 前兆）。画关键K 最高/最低两条线，站上最高价稳住才做多、跌破最低价离场；高开关键K 最低价≈主力建仓成本。只适用大 A（T+1），港股不能勾大复值。
- **案例（原文带数字）**：乐普（300003）：关键K 价位 11.46、13.89，一半约 12.25；最后拉到 21.21；B1 位置进 40%、任意点进 62%。四会：关键K 高点 35.16、低点 29.4。
- **组合关系**：关键K 是暴力K 的前提之一；关键K 之后任何位置交易都行，只要有一个买入行为之后，后面所有 K 线没用。
- **出处**：20251015。

### 11. 对称战法——独门

- **意**：借杨振宁"对称性支配相互作用"——多空能量本质守恒，**交易做的是"不守恒/走势不完美"**。走横=平衡/对称=无交易价值；**走横的 B1 最有价值（本应跌却横住=趋势被改）**。最大价值=判断某个 B1/B2 到底有没有交易价值。
- **形**：从不完美（打破平衡）位置进，拿到对称（左右平衡/完美）位置卖。斜率太斜的 B1 第二天必须涨停；A 杀（直接对称完美下杀）票不碰；连续上涨后第 1、2 个 B1 别碰、做第 3 个。三个对称=时间对称（择时）/空间对称（找标的）/形态对称（找入场点）。
- **案例（原文带数字）**：盈亏比案例（20251022）往下破位 3 个点、往上 12 个点=3.5 倍盈亏比；5.36% 确定根从底下起来 11.5% 该放飞。
- **组合关系**：对称战法不解决买点卖点，只解决"这个位置有没有交易价值"；与 B1/B2 组合可大幅提高正确率。
- **出处**：20251022、20251027。

### 12. 有序无序均线（20260211 节前答疑）

- **意**：判断均线是"有序"（趋势）还是"无序"（震荡/横盘），有序均线才能做趋势跟随，无序均线=垃圾时间。
- **形**：有序=均线多头/空头排列清晰、斜率稳定；无序=均线缠绕走平。
- **出处**：20260211。

## 3.3 择时体系（何时出手）

### 1. 0AMV（活跃市值）完整用法

- **历史规律**：活跃市值=先行指标（资金变筹码→筹码锁定→盘子清→拉起来成交量变小）；活跃市值扛着不跌→必有第二波；春节前 13 个交易日活跃市值阴跌=机构哭哭卖→预判下蹲。

### 2. 三波理论（建仓波 / 拉升波 / 冲刺波）

- **意**：把一波行情拆成三段，判断"现在赚的是哪一层的钱"：建仓波（底部放量、涨幅 25-50%、不涨停，主力吸筹）→ 拉升波（快速脱离成本、不翻倍）→ 冲刺波（75-80 度连板）→ 横盘 → 再建仓波。**建仓波不追（要等第二个 B1 甚至 SB1）、拉升波选股谨慎、冲刺波是出货区。**
- **形**：建仓波"两个 30%"（涨幅 + 大阳线累计换手率各 30% 掐正态分布尖）；换手率 >100%（甚至 150%）=一波流出货。涨停幅度折算（创业板 20% / 主板 10%）。
- **案例（原文带数字）**：建仓波涨幅 25-50%；四根线换手率 164%=把散户全换了。
- **组合关系**：三波理论用于"定位一波行情的阶段"，配合 0AMV 择时判断"现在该做哪一层"。
- **出处**：20250716、20251217、20260309。

### 3. 择时三要素（天时地利人和）

- **意**：择时的三根支柱。
- **形**：天时=宏观经济周期（康波是西方经济学，中国不适用；现在中国=扩张周期即可）；地利=政策周期（中国最重要，"有形的手比无形的手牛逼一万倍"）；人和=增量资金（最重要，"不管天时地利，最终干事的还得人和"）。
- **出处**：20250702。

### 5. 量价六概念（量价关系）

- **四分之三阴量线**：突破次日量缩到前日 1/2~4/4 之间的阴线 = ≥70% 假突破，不加仓；缩半量以下 = 真突破 77-80%。
- **缩半量**：完美加仓图形（量缩前日约一半 + 小阳）。
- **平量**：趋势延续（非常好）。
- **倍量**：≥前日 2 倍=真实买入；倍量再倍量=天量。
- **天量/倍量**：S1 候选（加速 + 放天量 + 大阴线）。
- **地量**：缩到极致，配合小阴小阳=B1 最好买点。
- **出处**：20250531、20251210、20251224。

### 6. MACD 用法——一票否决权 / 最后顾问

- **意**："唯一具有趋势预判性质的指标之王"，把 B1/B2/双线/S1/筹码验完再回看它。三大用法：判多空（DIF 零轴）/ 看背离（顶背/底背）/ 金叉空死叉多（空中加油）。背离背后 = 建仓完成后洗盘锁筹 → 量价关系失效 → MACD 难创新高。
- **形**：顶背离看日线、底背离可参考周线；与活跃市值印证（活跃市值先翻、MACD 后确认、共振最好）。⚠️ 白线/黄线在此是 DIF/DEA，勿与知行趋势线混淆。MACD 默认参数（12/26/9）不用改。
- **案例（原文带数字）**：1800→1664 底背离案例（20260422）；530 案例（2007 印花税半夜政策 3 个跌停）。
- **组合关系**：MACD 是"最后顾问"（一票否决权），可作 B1 后复核。
- **出处**：20260422。

### 7. 筹码理论

- **意**：只看低位筹码有没有转移到高位——没转移=锁仓/没出完，转移=出货/换装。筹码峰下沿"不是顶就是底"：向上突破=底（新主力建仓）、向下跌破=顶（出货）。只判断建仓与出货、不决定买卖点；SE 永远优先于筹码。
- **形**：锁仓拉升=长庄形态（B1 敢买）；高位密集=危险；超大盘（万亿市值）不看筹码；反弹看上方套牢盘比例（需 ~80% 低位密集才可能启动）；周线不看筹码。
- **案例（原文带数字）**：某票 924 后 73→140 翻倍，横盘期间新大哥成本 128，最后多杀多，满盘套牢 95.7%；某票主力底仓从 85% 只剩 8%；双峰填谷 26 块填谷从 26 启动看 52。
- **出处**：20260408、20260419。

### 8. 防卖飞策略

- **意**：牛市多急跌（盘中/隔日洗盘），真顶唯一标志=放巨量大阴线（放天量）。未放天量的快速下杀一律先当洗盘。价值 1200 万的踏空教训。
- **形**：每日持股检查 7 条（核心：只看收盘价是否比前一天高）；五分评分体系（收盘价升/不破 BBI/无巨量阴线/趋势向上/勾未死叉，5 分拿住、3 分可减、2 分完蛋）。
- **出处**：20250730。
