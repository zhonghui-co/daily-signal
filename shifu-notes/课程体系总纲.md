## 一、核心概念词典（黑话 → 含义）

按出现频率由高到低排序（频率为全六批摘要中相对出现密度，非精确计数）。

### 【最高频 · 交易核心】

| 黑话 | 含义 | 标注 |
|---|---|---|
| B1 / 等比一 | 第一买点。KDJ 的 J 值（"勾"）勾到"大复值"（13 以下）的阶段性低点；主线等**周 B1**、主题等**日 B1**；B1=低位、买底部、要盈亏比、潜伏 3~4 天。又比喻为"楼层地下室一层（地下一层=最低位买点）" | ✅（20250531、20251006、20250617） |
| 白线 | 知行趋势线（短期趋势线/牵牛绳/千牛神）。公式 EMA(EMA(C,10),10)；主升浪不破白线，回踩白线+缩量=B1；跌破白线=短期趋势走坏/减持离场 | ✅（20250906 公式、20250831） |
| 黄线 | 知行多空线（大哥线/多空分界/主力成本线）。公式 (MA14+MA28+MA57+MA114)/4（=BBI(14,28,57,114)）；站上黄线=大哥来了才可做 B1；跌破黄线=大哥走了/熊市；黄线三性质=①主力入场标志 ②拉升前极限洗盘极限位 ③主力控盘成本线（洗盘一般不破） | ✅（20250906、20251004）；🟡 与"≈60日/主力成本线"（20250723、20250813）的周期是否固定待证 |
| 大哥 / 大哥线 | 主力/庄/麒麟会/主导大资金；语境分义：票的主导资金 vs 国家队（20260812"大哥=国家队/有形的手"）vs 高位接盘方（20260202"找大哥变现"）。大哥线=黄线 | ✅（多义，20250723、20260812、20260202） |
| 活跃市值 / 0AMV / 01MA | 指南针软件"活跃市值"指标，杨新宇+陈昊发明；判断大盘真实增量资金的唯一最有效指标。红柱=钱转筹码（涨）、绿柱=筹码转钱（跌）。核心阈值：单日（或 2~3 日累计）+4% 转多头、单日跌幅 >2.3% 转空头。本质=赚钱效应 | ✅（20250702 首次、20251012 出处确认、20251022 极简用法） |
| 放飞 | 减仓/止盈落袋。大阳线起来先卖一部分（10%~50%）；中长阳放飞（中阳 4%+、大阳 7%+）；第 4 块红砖放飞（铁律）；加速/涨停/爆发就减 | ✅（20250907、20260415） |
| 止损 / 只输一根 | 买入当根 K 线最低点下方 3~5 个价位（或 1%~3%）/ N 型结构前低；只亏这一根 K 线；"永不套牢、只输一根" | ✅（20250531、20250716、20251112） |
| 勾 / 大复值 | 勾=KDJ 的 J 值；"勾到大复值"=J 值勾到深度负值区=B1 条件。口径演变：个股 0 以下/<-4~-5；低波红利 20 以下；J<20（公共）/J<12（个人）/J<13（体系定稿） | ✅（20250601、20250716、20251006）；🟡 量纲（负值 -6/-12 vs 正值 80/93/100）始终未统一 |
| 主线 vs 主题 | 主线=能容纳中长线/机构资金、对全市场有号召力、有轮动容错高的板块（新能源车/科技/白酒顺周期）；主题=概念票、快进快出、右侧 B1 一波流、无轮动（可控核聚变/创新药/低空飞行等） | ✅（20250531 核心） |
| 曼城阵容 | 主线投资=主力阵容；主题投资=替补/试训（视讯）。4231 阵型：4 后卫=红利低波底仓、2 后腰=台子+队长、门将=R12 国有大行/美债；70% 主配置+30% 量化灵动。后（20260415）停用，改用"主线(T0)+支线(T1)+答应(调剂)"池子 | ✅（20250531、20251029、20260415） |
| S1 / SE | 第一卖点/见顶出货信号。S1=加速后放天量大阴线（天量天价、最确定大顶），"宁可信其有、走错也要走（至少减一半）"；真 S1=盖过之前所有量的天量。SE=卖出/出货信号（写法待证） | ✅（20250917、20251231）；🟡 SE 写法 |
| 滴滴 / 低低 | 减仓/离场动作。定义演变：①N 型向上反弹高点结束标志（看收盘价）②高位两根阴线第二根收破第一根最低价走（DD=阶梯量两根阴线）。六步离场之一 | ✅（20251112、20251119、20260415） |
| 关键K | 关键位置（大哥线/黄线）出现的放量中大阳线/涨停板=大资金入场/离场信号；绝大部分 K 线无意义、只服从 1~3 根关键K；画最高/最低两条线管理，跌破最低价离场 | ✅（20251015） |

### 【高频 · 形态与量价】

| 黑话 | 含义 | 标注 |
|---|---|---|
| 击穿对手盘 | 主导资金用缩量（连续缩量）跌破短线对手盘公众止损位（关键K/N 型低点/黄白线）洗盘吸筹，非真出货；只忍一根、次日收回。与"斩杀（放量长阴=真砸/基本面变）"相对。口诀：长阴短柱是击穿、放量长阴是斩杀 | ✅（20251231"最难一课"、20260211） |
| 砖型图 / 专精图 / 专形图 / ZRanko | 红持绿空、绿转红买、红转绿卖；底层素材=宝塔线+活跃市值+参数+量价；参数 4 与 6；"数四块砖"（第 4 块红砖放飞、随时反转）；三种定式=N 型起跳/横盘起跳/上升波段延续 | ✅（20260412、20260318、20260325） |
| 大风车 | 顶部出货形态：高位放量巨震/长上影/长腿（螺旋桨），"走错也要走" | ✅（20250531、20250723） |
| 长阴短柱 | 长阴线配缩量短柱=主力洗盘/控盘（砸不出筹码），非出货 | ✅（20251210、20251231） |
| 倍量柱 / 背量柱 | 成交量 ≥ 前日 2 倍以上的放量柱=真实买入"大哥来了"；倍量之后再倍量=天量（警惕放飞） | ✅（20251210、20260415） |
| 阶梯量 | 阶梯式放量出货（量一根比一根大/平量），难看、需长时间消化，其 B1 不做（别抄底） | ✅（20250917、20251210） |
| 四分之三阴量线 | 突破后次日量缩到前日 3/4（>缩半量）的阴线，≥70% 概率假突破、不能加仓；平量/缩量阴线=真突破 77-80%，放巨量阴线=假突破 | ✅（20250723、20250730）；🟡 概率来源未说明 |
| 换筹 / 对倒 | 换筹=筹码交换换手；对倒（对岛）=主力自买自卖做量做价，两作用=对倒拉升+维持活跃度假象 | ✅（20250611、20260211） |
| 建仓波 / 拉升波 / 冲刺波 | 一波行情三阶段（循环）：建仓波（底部放量、涨幅 25-50%、不涨停）→拉升波（快速脱离成本、不翻倍）→冲刺波（75-80 度连板）→横盘→再建仓波 | ✅（20250716、20251217） |
| N 型结构 | 低点-高点交替的上涨结构；高点抬高+低点抬高=上涨、反之=下跌；本质=不断抬高跟风盘成本 | ✅（20250709、20250712） |
| 挖坑 / 填坑 / 出坑 / 起货 | 第三件武器（中长线战法）：挖坑=暴跌深坑、填坑=收复、出坑=突破坑沿（颈线位）、起货=拉升派发；大坑（月线级赚大钱）/小坑（周线级用少妇战法）/小洞（不建议碰） | ✅（20250625、20250626） |
| 一波流 | 无清晰建仓结构、边拉边洗边出、直上直下的短庄拉升；上面/回来的 B1 不碰（"一波流就是耍流氓"）；70% 以上到翻倍才算一波流 | ✅（20250723、20250903） |
| 红肥绿瘦 / 绿肥红瘦 | 红肥绿瘦=阳线放量阴线缩量（健康/吸筹）；绿肥红瘦=顶部阴线量长阳线短（出货） | ✅（20250611、20250917） |
| 螺旋桨 / 定海神针 | 螺旋桨=长上下影十字星（顶部=大风车出货、底部=反转）；定海神针=底部放量长下影企稳 K 线 | ✅（20250716、20260204） |
| 站平台 / 升平台 / 住平台 | 台阶式走势（企稳→抬升→新横盘），不破黄线问题不大 | ✅（20260204） |
| ABC 结构 | 下跌尾声三段：A 放量暴力K→再跌→B 放量暴力K（不创新低）→底部走横→C 再放量暴力K；C 完可能新趋势；"至少先来一个 B 再说" | ✅（20260415、20260304） |

## 二、战法清单

### 1. 少妇战法（六步）【核心/主招】
- 定义：R1 低风险核心战法，本质=跟随不是预测；成功率先约 30%（远高于打板 0.5~5%）。
- 六步：
  1. **择时**（最难，看六维，先讲四维）：经济周期（扩张=宽松货币+积极财政 vs 收缩=双紧）、政策指引（听话听音）、增量资金（最重要，降息降准 M1/M2）、入场时机（微观，等 B1）。
  2. **选股（五看）**：看政策、看行业、看龙头公司、看有没有人搞（资金/大哥）、看估值（主题可放一放）。
  3. **等比一（等 B1）**：主线等周 B1、主题等日 B1；勾大复值。
  4. **设止损（上套/带套）**：当根入场 K 线最低点下方 2~3 价位（小碗）/ N 型结构上一低点。
  5. **止盈放飞**：BBI 线上两根中大阳减仓；放飞后不管。
  6. **彻底离场**：波段足够长、浮盈足够多时，连续两日跌破 BBI 线收队。
- 出处：20250531（前 4 步）、20250709（补齐 5/6 步）。
- 三大底层价值：①解决"一买就被套" ②最大盈亏比（上 10% 下 2%≈5:1）③保持正确节奏。
- B1 三价值：B1 赚的钱=第一波填坑的钱。出处：20250712。

### 2. 双线战法（白线+黄线）【少妇战法升级/pro 版】
- 定义：白线=知行趋势线 EMA(EMA(C,10),10)；黄线=知行多空线 BBI(14,28,57,114)/大哥线。
- 黄线三性质：①主力是否入场标志 ②拉升前最后极限洗盘极限位 ③主力控盘成本线（洗盘一般不破）。
- 金叉/死叉：白线金叉黄线=上涨趋势确立、等回踩 B1 入场；死叉=最后离场时机（走错也要走）；"死叉而未死叉+N 型不破+勾大复值=极限买点"。
- 碗：白线与黄线之间容错买入区（容错率最高，不必追求完美 B1）。
- 用法边界：熊市/震荡用 BBI 单线；右侧牛市用双线吃满波段；转回再归 BBI。
- 循环操作法：到 B1 抡→白黄区间接着抡→加速放飞→跌破白线（顶部无量未出货）→回 B1 再买，反复循环。
- 出处：20250831（诞生）、20251004（最完整论述）。

### 3. 对称战法【独门】
- 理论源头：杨振宁"对称性支配相互作用"；多空能量本质守恒；交易做的是"不守恒/走势不完美"。
- 三种对称：时间对称（择时：加息↔降息、扩张↔收缩）、空间对称（直接=A 字完美 vs 间接=A 起来回一半=上涨 N 型）、形态对称（轴对称=做突破 vs 中心对称=做 N 型波段）。
- 核心：从不完美（打破平衡）位置进，拿到对称（左右平衡/完美）位置卖。
- 走横=平衡/对称=无交易价值；走横的 B1 最有价值（本应跌却横住=趋势被改）。
- 斜率改变=多空守恒失衡；斜率太斜的 B1 第二天必须涨停；平衡后越往上越不守恒越要放飞。
- A 杀（直接对称/完美）票不碰；连续上涨后第 1、2 个 B1 别碰、做第 3 个 B1。
- 最大价值=判断 B1/B2 有没有交易价值。出处：20251022、20251027。

### 4. 砖型图三种定式【红持绿空】
- 底层：宝塔线+活跃市值+参数+量价；参数 4 与 6；红持绿空、绿转红买、红转绿卖。
- 数砖规则："4"源自威尔德 Delta 三角洲理论（市场每 4 天/4 月/4 年/19 年重复）；从红砖起数 4 块，第 4 块后注意随时反转；未反转（创新高/新低）则延续再来 4 块；反转位不能破。
- 三种定式：
  1. **N 型起跳**：N 型低点转折处第一块红砖，买入后第二块红砖应直接往上。
  2. **横盘起跳**：横盘震荡后突破/将突破位置红砖，"大块红砖压绿砖"成功率更高；核心=起来前一定要有横盘动作。
  3. **上升波段延续**：无像样回调、红-绿-红连续翻红=波段延续（不算突破，不追连续上涨）。
- 三要素（缺一不可）：位置+K 线形态+砖块大小；K 线不能是大苗子（长上影）、跳空不做。
- 卖出三条件：数四块红砖减/清仓、红变绿走（收盘前三分钟）、买入后不涨（次日 9:33/9:37 走）。
- 大傻子战法（DSZ）=砖型图傻瓜式玩法（红一块买、绿一块卖、中间数四块）。
- 出处：20260412、20260318、20260325。

### 5. 三大高爆发力 B2 买入法【B2 战法】
- B1/B2/B3 定义：B1=阶段低点（勾<13）；B2=确认 B1 的那根阳线（接 B1 后勾拐头）；B3=B2 放量中长阳后的那根阳线（中继买点）。B2 确认 B1、B3 确认 B2（三重保险）。
- 三大 B2 图形：
  1. **平行重炮**：相对平行位置放量长阳 ≥2 根（双枪/三门重炮）。
  2. **灾后重建**：放量金叉后缩量回踩黄线、黄线处放量长阳确认。
  3. **跃跃欲试**：横盘期间放量大(中)阳线、红肥绿瘦、事不过三（白线已调到黄线上=箭在弦上）。
- B2 选股 5 量化条件（独门记死）：①在 B1 后、勾要拐头 ②中长阳涨幅 ≥4%（底线 3.9%）③比前日放量 ④勾（J 值）<55（历史 95~97% 流畅大牛股在 55 内）⑤无上影线最好。
- 三维排名：盈亏比 B1>B2>B3；确定性 B3>B2>B1；止损幅度 B1<B3<B2（B2 止损设 N 型/B1 低点，幅度最大）。
- 出处：20251006（最完整）、20250907（三件套成型）。

### 6. B3（第三买点 / 不得不发牛）
- 定义：B2 放量中长阳之后的那根阳线（小阳线）=上涨途中中继买点；买入必须涨、不涨马上拍（最多等 1 天）。
- 长安战法/B3：缩到连半量都不到+上方一致 K（缩量小阳/十字星）="发财图"。
- B3 配砖型图稳定性低（能走出=大牛、走不出往白线去），做 B3 一般不看砖型图、盯白线。
- 止损：突破大阳线中间位（20 厘米票设中间给 50% 回撤）/B3 阳线最低点。
- 出处：20250907、20251006、20260415（"B3 未系统讲、会补课"🟡）。

### 7. 防卖飞策略【少妇战法 1.2/1.3 补丁】
- 总纲：牛市多急跌（盘中/隔日洗盘）；真顶唯一标志=放巨量大阴线（放天量），未放天量的快速下杀一律先当洗盘。
- 每日持股检查手册（7 条）：①忽略盘中冲高回落 ②当天下杀看尾盘/次日是否快速收回（次日至少收回一半=强壮的宝宝）③不在下杀中卖 ④不因大盘突然下杀草率处理同步强势股 ⑤收盘缩量小阴线再等一天 ⑥完美形态不破 BBI 就拿 ⑦【最核心】多看日线、只看收盘价是否比前一天高，不看 K 线形态/量/指标。
- 五分评分体系（5 项打分）：①收盘价上升 ②不破 BBI ③无巨量阴线 ④趋势仍向上 ⑤勾未死叉。5 分拿住、3 分可减不可清、2 分完蛋。
- 踏空定义：无任何减仓/清仓条件触发时卖出才叫踏空。
- 出处：20250730。

### 8. 底部暴力 K 线【擒大牛】
- 三个前提：关键K（大部分 K 线服从少数关键K）+倍量柱（只看倍量/天量/缩量）+形态（单底不是底，双底/区间震荡位置才有趋势意义）。
- 四种判断标准：①底部位置 ②突兀/莫名其妙（平地惊雷）③又粗又大 ④让你害怕的时间点/位置（反人性）。
- 分类：大暴力=改变趋势级别（趋势扭转"下跌→横盘"只观察不进场；趋势改变"横盘→上涨"才干）；小暴力=上涨趋势中 B1/趋势延续位置。
- 定海神针=趋势改变那根放量长阳。
- 买点：暴力 K 线后等 B1 最舒服；底部大暴力刚出来白线仍在黄线下→不追（99% 不干），等白线站上黄线后 B1。
- 出处：20251224。

### 9. 瑜伽裤战法（知行专形图 ZRanko Charts）【超短线】
- 核心逻辑：寻找转折点的爆发力，只做"绿转强红"（强红=红柱幅度 ≥ 绿柱三分之二），赚绿转红后两根 K 线的钱。
- 位置过滤：股价在黄线（大哥线）之上、白线在黄线之上（多头）才做；下跌趋势不碰。
- 执行六步：绿转强红→尾盘买/次日不追高买（高开 4~5% 放弃）→分两仓→止损=买入 K 线最低价或 2 日不拉起就走→蹬起来就卖（3% 以上分批）→脱离成本 5% 以上最多持 4~6 天。
- 口诀：我要赚钱/给多少拿多少/不给就走/永不完美/下一个会更好。
- 只适合小资金搏命：不用杠杆、不用输不起的钱、不杀红眼、不补仓。
- 出处：20260220。

### 10. 关键K战法
- 定义：关键位置（大哥线/黄线）放量中大阳线（涨停最好）=大资金入场/离场信号。
- 两大意义：①趋势反转六型（V 型/紧急刹车/平地惊雷[横盘→上涨，最常见确定性最高]/A 刹/上涨转横/丢盔卸甲）②走势衰竭（卖盘枯竭=B1 买点、买盘枯竭=见顶）。
- 画线：关键K 最高价/最低价两条线；站上最高价稳住才做多、跌破最低价离场。
- 高开关键K 最低价≈主力建仓成本、后续洗盘不破；关键K 量不够价值不大、不能追等 B1。
- 只适用大 A（T+1）；港股不能勾大复值（流动性不够）。
- 出处：20251015。

### 11. 指数贡献策略【防踏空】
- 定义：每天收盘看个股对指数"贡献点数"，持续/频繁上榜的权重股=指数贡献股（大而不倒的大央企/大权重）。
- 配法：一纯血+一混血；数量 10 万~100 万配 10 个左右（5~7 行业各 1~2 个）。
- 上车：等指数贡献标的调回 B1，不追已爆发完/翻倍的。
- 特性：真买真砸、不存在对倒；下跌跌得比小票少。
- 历史验证：2015 股灾后研发，专户年均约 25%。
- 出处：20250827；20251221/20251229（2026 核心=指数贡献+结构行情+清晰波段）。

### 12. 筹码理论
- 核心：只看低位筹码有没有转移到高位；没转移=锁仓/没出完，转移=出货/换装。
- 最可复用判据：筹码峰下沿"不是顶就是底"——向上突破=底（新主力建仓）、向下跌破=顶（出货）。
- 锁仓拉升=长庄形态（底仓锁死、每关键价位换手向上），B1 敢买。
- 高位密集=危险；超大盘（万亿市值）不看筹码（无单一庄）。
- 反弹看上方套牢盘比例（上方 40% 套牢盘一反弹必有人卖；需 ~80% 筹码低位密集才可能启动）。
- 只判断建仓与出货、不决定买卖点；SE 永远优先于筹码。
- 周线不看筹码（日线参数与周线不同）。
- 出处：20260408、20260419。

### 13. MACD 用法【一票否决权/最后顾问】
- 定位："唯一具有趋势预判性质的指标之王"，把 B1/B2/双线/S1/筹码验完再回看它。
- 三大用法：①判多空（DIF 零轴上=多头）②看背离（顶背离/底背离，总有一次是真的）③金叉空/死叉多（空中加油）。
- 背离背后的资金逻辑：建仓完成后洗盘锁筹→量价关系不再重要→MACD 难创新高（"股价新高 MACD 不新高"=锁筹不是出货）。
- 顶背离看日线（周线太慢）、底背离可参考周线（周线底背离更可靠）。
- 与活跃市值印证：活跃市值先翻多/翻空、MACD 后确认、共振最好。
- 出处：20260422。

### 14. 补票战法 / 单针下20/30【偷袭机构的超短】
- 指标：知行洗盘短线（红线=长期资金/机构、白线=散户/短期资金）。
- 单针下20：白线（散户）洗到 20 以下 + 红线（机构）仍 80 以上；单针下30：红线 70/白线 30（参数可选 80/20、85/30、70/30）。
- 深微/双微/三叉戟=深 V/双 V/多 V 洗盘。
- 只在主声浪用（沿白线创新高、斜率 35~60 度、45 度最完美；60 度以上冲刺波不用）。
- 规则：超短持有 1 交易日、必须脱离成本、未脱离次日开盘拍；+3% 以上续持参考 BBI；只做 N 型/BBI 向上。
- 出处：20250601、20260429、20251126。

### 15. 挖坑填坑战法【第三件武器】
- 坑的级别：大坑（历史新高+长期暴跌+企稳，月线级，靠信仰拿住）、小坑（阶段高点回调企稳不破前低，周线级，用少妇战法）、小洞（不建议碰）。
- 三个不能做：还没填"像样坑"不做、基本面不了解不做、不在当前主题/主线不做。
- 三个能做：填完一个中型坑后出坑回踩、填大坑过程中 N 型完美、主线/主题出坑过程（低点抬高）区间。
- 目标价（祖宗之法）：坑口价×2−坑底价（=坑口+(坑口−坑底)=高点−低点+高点）。
- 破位=破坑沿（不是破低点）；假破位=跌破该段 50% 后收回没问题。
- 出处：20250625、20250626、20260219。

### 16. 低波红利（底仓玩法）【散户版社保/国家队重筹】
- 定位：跟国家财政绑定，只买不卖；每年先保底约 5% 分红+央企成长+估值提升。
- 玩法：勾大复值定投——周线大复值买"大"、日线大复值买"小"，比例约 5:1；周线大复值一年约五六次。
- 看周线/月线别用日线；周线打黄线以下=历史性低吸机会（"近碗就行"）。
- 出处：20250601、20251012。

### 17. 其他战法/工具（清单）
- **补票战法**（错过 B1 后）：20250601。
- **深水炸弹/双马尾/两排重炮**：两根放量巨量线（人为建底仓痕迹）；定义经 20250601"乾隆 DMI 抄底"→20250716 修正为"两根放量巨量线"。
- **四分之三阴量线**：验证假突破（缩半量以下最好/平量可/天量失效）。
- **大傻子战法（DSZ）/长安战法**：砖型图傻瓜式数砖；量在价先（横盘区莫名其妙放量=大哥进场）。
- **低低战法（DD 战法）**：用前一根 K 线低点作持仓线，收盘价跌破前一天低点就卖。
- **金叉空/死叉多**：MACD 假金叉=诱多、假死叉=诱空（期货反手）。
- **主力出货五种方式**：①加速后放天量大阴线(S1) ②加速后次高点突然巨量长阴(S2) ③新高后连续阶梯放量下跌(S3) ④双头双放量巨阴 ⑤顶部绿长红短（绿肥红瘦）；+第六种综合出货。
- **异动（一动）选牛股**：成交量突然放大+价随量升=选股最底层逻辑。
- **每日 5 步工作流**：择时→定策略→复盘→选股→执行（每天 ≤12 分钟）。
- **量化三模块**：择时（基本面+资金面+技术面）+量化对冲组合+风控（止损/放飞/滴滴）。

## 三、心法与纪律清单（按主题分组）

### 止损
- 只输一根：买入当根 K 线最低点下方 3~5 价位（或 1%~3%）；只亏这一根。20250716、20251112。
- 永不套牢、只输一根；止损=正常成本（篮球 miss 比喻）。20250712、20251119。
- 短线三种止损：①赚钱票回成本价拍 ②该涨不涨（市场没证明你对就是错）拍 ③破止损价（等收盘）拍。20250716、20250806。
- 破位必走；黄线之下卖、最多等一根。20251112、20260406。
- 击穿对手盘只忍一根（第一根最低点画横线，收盘跌破走）；别忍两根。20251231、20260415。
- 止损位≠公众止损位（不能设在关键K/N 型低点公众位置，否则被主力精准击穿）。20251231。
- 赢转亏/迎转亏必走（浮盈转浮亏即走，优先于止损）。20251112、20260415。
- 没涨必拍（不脱离成本区腻歪就拍）。20260415。
- 三种必须走：破止损位/放量斩杀长阴/基本面逻辑重大改变。20251231。
- 止损幅度参考：小钱 3~5%、大资金 20%；B2 止损设 N 型(B1)低点、20 厘米票设大阳线中间位（给 50% 回撤）。20260304、20251006。

### 仓位
- 盈亏同源：按单仓跌停幅度倒推仓位（主板 10%→20%、创业板 20%→10%、科创 30%→7%）。20251112。
- 分仓目标=睡得着觉（吃波段）；重仓目标=快速赚爆发差价（赚到马上减）。20251112。
- 满仓=总资金八成，留 20% 预备队；存款搬家一次只搬一个仓位。20250922。
- 仓位数量：高手 4~5 票、新手 10 票；10 万配 4 个、100 万 5~8 个、500 万约 10 个、1000 万 15~20 个。20251112、20260204。
- 70% 主配置（只做确定性）+30% 量化灵动（B1/B2）。20251029。
- 配置配置还是配置；不单仓重仓赌一个；连续止损 5 次×5% 砍掉一半。20250625。
- 一月只开 4 次新仓（春节前只 2 次）；一周≤2 新仓；一年做四波左右。20260204、20250531、20260202。
- 不主动超配（超配是涨出来的）；体系内无"加仓"、只有"减仓"。20250601、20250922。

### 心态
- 知行合一；不守纪律的亏损都是"充值/交学费"。20251119。
- 对股票零感情（票=彩票/青楼女子）；不要问为什么、别动脑子、别对票有感情。20250606、20251103。
- 永远不要抱怨市场（市场一切走势都对）；敬畏市场（跪下叫大 A 爸爸）。20260219、20260211。
- 空仓也是策略（买 0 卖 0、零伤亡）；空仓≠怂。20260202、20260318。
- 踏空定义：只在策略内完美图形出现却不干才算；别的板块涨没买不算踏空；赚看得懂的钱。20250625。
- 恐惧踏空比恐惧亏损更害人。20260404。
- 去除偏见：选股盖住名字只看图形（二选一必选错）。20260211。

### 认错

## 四、大势体系

### 1. 0AMV 活跃市值用法
- 来源：指南针软件"活跃市值"指标（0AMV/01MA），杨新宇+陈昊发明；判断大盘真实增量资金的唯一最有效指标。
- 本质：筹码↔资金的交换。红柱=钱转筹码（筹码集中/供不应求→涨）、绿柱=筹码转钱（盘子散→跌）；=赚钱效应。
- 阈值（极简版"只看两个数"）：
  - 转多：单日红柱 ≥4%（最好单根 4%，两根合计 4% 次之，三根累计 4% 偏弱、最多看三根，超过三根不显著）。
  - 转空：单日跌幅 >2.3%（一根即转；负 2.2 先稳一天、只卖不买去弱留强；负 2.2~2.4 灵活漂移）。
  - 波段目标位：4.3%。
- 回测概率约 80~90%。
- 空头区间：只卖不买、去弱留强、自然淘汰；多头区间：容错率高、随便干。
- 活跃市值先翻多/翻空、MACD 后确认、共振最好赚钱。
- 用翻红幅度判断资金性质：924=超级大哥包场（单根 10%~27%）、踏空资金、半信半疑资金、龙队护盘（2.63/1.97 类）。
- 出处：20250702（首次）、20251012（出处确认）、20251022（极简）、20260412（回测 80-90%）、20260104（4% 规则例证）。

### 2. CPI 量化阈值（宏观择时）
- CPI 是把所有政策串起来的核心指标。
- 触发：CPI 连续 6 个月 <1% 或核心 CPI 连续 3 个月 <0.5% → 自动运行居民增收计划（初始 3 万亿占 GDP 2%，不够加到 5 万亿）。
- 退出：连续 3 个月 >2% 暂停；>2.5% 卖国债回收；突然 >3% 加息缩表。
- 对应盘面：CPI 到 2% 市场可能已涨 20-30%；2.5% 已涨 50-80%；3% 高位震荡（双头）要收紧。
- 出处：20260927。

### 3. 4%/6% 单日择时
- 上证/大盘单日涨幅：当天 +4% 以上力度强（大仓位）、+6% 更强、三天才累计 4% 力度弱（小仓快进快出）。
- 4% 进场→4.3% 是波段目标/强位置；单日 -2.3% 早信早走。
- 出处：20260927；🔴 与 Mimo v5test 转多阈值 +6.5% 疑似同源（20260916、20260927）。

### 4. 政策红绿灯
- 政策信号三档：鼓励/支持=绿灯（做多）；规范/有序开展=黄灯（收一收）；从严整治/限制=红灯（熄火）。
- 例：2009 四万亿 1664→3478 翻倍，转"稳健"（黄灯）后跌三年。
- 出处：20260913。

### 5. 扩张/收缩周期
- 扩张周期=适度宽松货币+积极有为财政；收缩周期=财政货币双紧。
- 前几年收缩期该"躺好、别折腾、别买房、别捞偏门"。
- 当前"双宽"（适度宽松货币+积极财政）=扩张周期；转"稳健财政+稳健货币"就收手不玩。
- 出处：20250531、20251217。

### 6. 垃圾时间定义
- N 型结构下跌下来的位置 + 无方向无持续性板块 + 机构转场熟悉领域；只等、不选股。
- 大 A 约 66% 时间是垃圾时间（波动率低、阴跌/区间震荡）；24% 舒适区间、10% 大波动时间。
- 出处：20260219、20260720。

### 7. 政策底 → 资金底 → 市场底
- 顺序永远是：先政策底 → 再资金底 → 再市场底。
- 出处：20261003。

### 8. 慢牛框架（2026 生态）
- 慢牛=指数贡献+结构行情+清晰波段；龙队明牌持"几万亿筹码"=筹码硬道理。
- 龙队目标 KPI（消息源供参考）：2025 看 3800 顶、明年 5000 点。
- 慢牛折线：3100→4000→3500→5000→4500→6000（月 100 点，上顶下底）。
- 出处：20251221、20250907。

### 9. 宏观传导链
- 反内卷→上游/出厂价涨→PMI 回升→PPI→CPI→涨价去库存。20250906。
- 化债→反内卷→PPI→调 CPI→房地产企稳→民营经济促进法落地。20260520。
- 中国资本市场=先"集中力量办大事/充值"，办完再"放烟花"。20260531。
