# 师父心法总纲

> 从 6 批《师父课程去水笔记》（约 108 份课次，20250531～20261014）中提炼的「心法」——师父**怎么想、怎么面对市场、世界观、纪律内核**。
> 本稿只取「道」，不取「术」：战法参数（J 值、百分比阈值、公式、买卖点规则）一律不录，除非那个数字本身就是心法的一部分（如「年化 18% 是极限」）。
> 每条心法后括号内是出处课次（YYYYMMDD）。师父的原话尽量保留，不翻译成学术腔。

## 先看总纲：师父的世界观骨架

师父的心法不是散句，是一条环环相扣的链条。读懂这条链条，才读得懂后面九章每一句话：

**「只用输得起的钱」→「余闲（现金）永远在手」→「心态从容」→「能执行纪律」→「止损无情、先保命」→「活得久」→「等确定性、耐心伺机」→「只在关键点出手」→「赚国运的钱」。**

反过来，这条链断了任何一环，人就会：拿输不起的钱 → 满仓 → 焦虑 → 乱动 → 不止损 → 死得快。师父所有心法，本质都是给这条链上保险。

另一条平行主线是**「看大哥、跟国家走」**：市场是筹码游戏，散户没信息、没资金、没定价权，唯一能赢的路，是站在有定价权的那一方后面——大哥（主力）没上桌，一切都是噪音；国家意志还在，就跟着走；大哥走了，你也走。这一条贯穿了「对手盘观」和「国运观」。

## 一、风险观（止损、杠杆、输得起的钱、先保命）

**师父风险观的一句话内核：先活着，再谈赚钱；所有亏大钱的人，都是先破坏了「保命」这一条。**

- **先保命，永远记住先保命。** 防守/红利是保命策略，不是发大财工具。（20260730）
- **Lesson One = 止损 = 不要被套住（永不套牢法）。** 止损是师父体系里反复强调的「第一课、第一个科普」——第一课没证明白，别的都别谈。（20261011）
- **只用输得起的钱。** 不加杠杆、不借钱、不用急钱、不卖房炒股、不融资。（20250709、20260826、20260923）
- **不杠杆。** 杠杆不是放大波动的工具，是改变系统结构的变量；靠杠杆/借债的「浪费」，怎么上去怎么下来（韩国、A 股 15/08/07 年）。（20260916、20260816）
- **不加杠杆、不碰期货、只拿输得起的钱；牛市才是亏大钱的地方。**（20250903）
- **先保命：不大亏 → 大亏变小亏 → 小亏变不亏 → 运气好赚一点。**（20260923）
- **止损要「无情」。** 防套 10% 不信 → 30% → 70% 陷阱。（20260923）
- **止损 = 正常成本。** 像篮球主投手 25 投 13 中，12 个 miss 就是止损；把止损当成血液里正常的事。（20250712）
- **止损像球星投篮：投丢马上回防、再投下一球，下意识止损，不纠结。**（20260408）
- **3~5 个点以内不叫套，叫波动；设好止损、位置到了就走，只赌一次。**（20250712）
- **永不套牢，只输一根。**（20251112、20251119）
- **止损是「舍小钱保大钱」；卖是为了买、买是为了卖（先分手才能找更好的）。**（20260304）
- **止损、止损、止损；失联一次就拍（不给第二次机会）；赚钱的票不要做成亏。**（20251119）
- **止损条件与仓位大小无关：买 5 万还是 500 万，止损条件一模一样。**（20251119）
- **善输善败者无敌。该输的钱要输：多头区间建仓止损 = 该输的钱；空头区间重仓赚的钱以后会亏回去。**（20260330）
- **赚钱的前提是先学会「守纪律地亏钱」。**（20250702）
- **空仓也是交易（买 0 卖 0、零伤亡）。** 不买就不承担任何交易风险；散户认知误区：不干 ≠ 怂/傻，空仓 = 已经做了一次买卖决策。每笔交易 = 一次打仗，零伤亡收兵一样值得吹。（20260202）
- **确定性大才出手，一年做四波左右，且要用止损守着。**（20260202）
- **暴跌大概率是机会（除非发生完全超预期的巨大事件）。**（20260204）
- **重仓不能被套（「可以要饭，不能当奴隶」）。**（20260220）
- **先小钱（如 2 万）刷够交易笔数，一两百笔「别说话」；交易是练/喂出来的，不是看会的。**（20260419）
- **亏损两大来源：瞎交易 + 到止损位不止损，不是完美图亏的钱。**（20260408）

**内在逻辑（本节是总纲第一环）：** 止损是「先保命」的落地；输得起的钱是「能止损、不怕输」的前提；不杠杆是「输得起」的边界；空仓是「不承担风险的交易」的极限形态。它们共同指向一句话——**你赚多少钱是市场给的，你能亏多少是自己决定的（20260916）**。能输多少自己定（止损/仓位），能赚多少靠抉择 + 经验 + 运气。

## 二、仓位观（余闲=现金、手紧手松、不满仓、旗杆、集中与分散、曼城阵容）

**师父仓位观的一句话内核：仓位不是为了「多赚」，是为了「睡得着觉」和「让净值曲线台阶式向上」；现金是武器，不是浪费。**

- **余闲 = 现金，永远不满仓；仓位越重人越笨。** 出处是读书分享《稀缺》：稀缺俘获大脑、压缩心智带宽（「是穷才笨，不是笨才穷」），满仓 = 人变笨 = 动作变形。（20260826）
- **只用输得起的钱；小仓位才能执行纪律（拿得住/止损快）。**（20260826）
- **手紧手松（德州扑克式出手松紧）：** 空头区间「守紧」只做最完美形态、仓位收缩；多头区间「守松」全策略可做、仓位推满。足球阵型：牛市打 343/433 压着打，熊市收缩 541 防守。（20251203）
- **满仓 = 总资金八成，留 20% 预备队。** 预备队永远给当天选出的完美新标的留仓，避免早盘被迫卖旧仓换新仓。（20250922）
- **配置、配置、还是配置；不要单仓重仓赌一个。** 连续止损 5 次 ×5% 就砍掉一半，再回本要翻倍。（20250625）
- **配置的意义不是每天赚钱，而是让净值曲线「台阶式」向上、求每周期大概率事件：阵容内对冲 + 阵容与市场对冲。**（20251110）
- **牛市拼配置、熊市拼选股。** 熊市一路过来靠重仓单票（米儿三倍、阿信翻倍）；牛市靠板块配置，不追单月翻倍，要「净值曲线永远往上走」。（20250907）
- **牛市开超市、熊市单抡。** 牛市大家 N 型往上无技术含量，关键是仓位；分散约 6 个板块各配一只，东方不亮西方亮。（20250917）
- **曼城阵容（配置=对冲）：** 红利低波 = 底仓/4 后卫（稳定军心，只买不卖让它自己膨胀）；主线做增强、主题做超额。账户每一分钱 = 一个士兵，别草率撒出去；散户要像打仗排兵布阵。（20250531、20250601）
- **旗杆 = 自己的巴菲特式核心锚定仓（高盛/可口可乐那一类），危机也不换。**（20260812）
- **分仓目标 = 让自己睡得着觉（吃波段）；重仓目标 = 快速赚「爆发差价」，赚到马上减，绝不能用重仓拿长线。** 严禁搞反：不要分仓做短线（赚不到快钱）、不要重仓做波段（拿不住、极端损失大）。散户最大问题就是这两者搞反。（20251112）
- **底仓 = 拿得睡得着觉的仓位（足够便宜或睡得着），作用是保持自己的节奏。**（20251217）
- **不主动超配，超配是涨出来的。**（20250601）
- **体系内无「加仓」、只有「减仓」（把钱揣兜里）。**（20250922）
- **资金规模决定打法：大资金要确定性（3%~5%）、小资金要边际值（追板/高弹性）；越大的账户越谨慎。**（20250917、20251217、20251112）
- **赚大钱 vs 赚小钱两套策略别混用：** 赚小钱（交易的钱）= B1 + 小止损 + 白黄线纪律；赚大钱（主仓拿住不动）= 大逻辑下用更大碗接受 20%~30% 回撤，前提是拿输得起的钱。（20251231）

**内在逻辑（本节是总纲第二环）：** 余闲（现金）= 空头区间的弹药 + 心态的安全垫；不满仓 + 配置对冲 → 净值曲线平滑 → 睡得着觉 → 心态从容 → 能执行纪律 → 回到第一环。**「余闲」把第一环的「输得起」和第三环的「从容」物理性地串了起来。** 集中还是分散不是对错问题，是由「资金规模 + 确定性」决定的：小资金博爆发要集中、大资金求确定性要分散、底仓永远要「睡得着」。

## 三、心态观（垃圾时间休息、耐心等待伺机而动、「我不要了」、慢就是快、赚的是精神损失费、四类人、认错）

**师父心态观的一句话内核：市场大部分时间是垃圾时间，赚大钱靠的不是天天努力，而是「等」和「拿得住」；心态崩了，技术再好也是给别人送钱。**

- **垃圾时间该休息。** 定义（NBA 比喻）：主力轮休、替补维持，散户只是角色球员；替补再牛最后一投也不会给他（= 只做主线龙头）。最佳策略 = 休息观望别瞎忙。（20260812）
- **耐心等待，伺机而动。** 师父八字总纲，贯穿 2026 全年。（20260819、20261014）
- **垃圾时间休息、趴好、等信号；不要牛熊概念，只有择时（上课/下课铃）概念。**（20260902）
- **「我不要了」。** 记住四个字「我不要了」，有这种气势所有专家都弄不走你；市场赚的钱就是比谁横，赚大钱的都是横，赚更大钱的不要命；前提是这玩意儿有点技术含量（是不是太子级别），不能在最高位穷晃。最好玩的就是让时间发酵，瞅准一个便宜的标的按实际情况配置梭一把，然后该干嘛干嘛。（20261011）
- **「我不要了」最无敌：拿输得起的钱；巴菲特买 Apple 拿 7% 资产、研究透全球垄断性质，买了之后「我不要了，你拿钱干吧」；有这种状态才能赚大钱。**（20261011）
- **慢就是快。** 不追高、等回调/补票；前几天高位没追上，今天回调再补。（20260505、20260517）
- **慢就是快两个维度：赚得比别人多 + 亏得比别人少（空头区间忍住，别人 10% 你 20%）。**（20260404）
- **赚的就是精神损失费：能担得起多少痛苦就值得多少利润。**（20261011）
- **赚的是「煎熬的钱/精神损失费」：一年 250 交易日约 200 天是绿的，回本靠「7 天里 5 个交易日」。**（20260923）
- **四类人（对号入座，认清自己是哪一种）：** 游刃有余（徐翔级）／不服（被叉死）／被动服／主动服（开悟 = 知道自己的能力边界）。重点是「主动服」= 认清边界。（20260906）
- **认错纪律：被套 = 已做错要认错；十笔七笔认错、三笔里一笔大赚两笔平。**（20260927）
- **敬畏市场：进市场先「跪下叫大 A 一声爸爸」，站着赚不到钱（龙队当年也被大 A 玩过天地板）。**（20260211）
- **不抱怨市场、不跟市场/弹幕杠、只跟自己比；做错一笔先反省自己。** 2.5 亿散户里「技术认知」可以提高，但「心态」对所有人公平，练心是关键。（20260211）
- **永远不要抱怨市场：市场一切走势都对，错了也对；抱怨一次就多一分负能量、动作就变形。**（20260219）
- **知行合一难在「知」：做不到 = 知不够，不是没执行力；先补认知与技能，再谈执行。**（20260504、20260517）
- **知行不合一 = 知不够（认知/内功不足）；补「内力/内功」（读书、心法）优先于补招式。**（20260517）
- **踏空比套牢难受；但高手不怕踏空——踏空只是众多可驾驭机会里「没按扳机」那一次，认知到位就找下一个。**（20250903、20251217）
- **恐惧踏空比恐惧亏损更害人（会导致动作变形、追高多亏）。**（20260404）
- **接受主动踏空，换净值曲线往右上走。**（20260219）
- **越没信心越要熬，熬到彻底没信心就快反转了（但要等全市场周期共振）。**（20260318）
- **顿感力（钝感力）只跟「经历多少」有关：要么一开始就信，要么反复折腾被打服后信；多经历自然脱敏。**（20260404）
- **难受（踏空/百爪挠心/被套崩盘）时不要做动作；舒服（浮盈看车、割完轻松）时做反向动作。**（20260419）
- **持仓税/摸顶税（心理账户）：** 趋势型只能等跌破位才确认趋势结束，所以净值创新高时计提 20%~50% 利润作为这波行情「门票费/小费」——心里先把一部分钱落兜里，剩下的才算市场暂时寄放的，这样才拿得住波段。（20250907）
- **买点决定能否拿得住：位置差就拿不住；挖出牛脱离成本区时已有浮盈，才有心理优势。**（20250914）
- **眼红别人的强势主线没意义：你不是成都人，守好自己看得懂的国安（自己的持仓）。**（20260531）

**内在逻辑（本节是总纲第三环）：** 第一环的「输得起 + 活得久」+ 第二环的「余闲 + 睡得着」= 第三环的「从容」。有了从容，才谈得上「垃圾时间休息」「耐心伺机」「我不要了」「慢就是快」——这些都是**从容的产物**，不是意志力口号。而「认错」「敬畏」「只跟自己比」是给从容兜底：承认自己会错、承认市场比你大，才不会在垃圾时间里硬找存在感。

## 四、认知观（只做看得懂的、反着来、贝叶斯只校准不推翻、噪声三问、政策红绿灯、价格包含一切、市场赚人性的钱、市场永远是对的）

**师父认知观的一句话内核：市场没有「为什么」，只有「概率」和「应对」；看不懂就不碰，看得懂的才敢下重注。**

- **只做看得懂的票（知道怎么输的钱）。**（20250618）
- **只做看得懂的（足够了解 + 足够相信）。**（20260812）
- **只赚认知内的钱；只做熟悉的战法。**（20260531、20260614、20260322）
- **赚你看得懂的钱；没研究、没依据的板块涨了不算踏空。**（20250625）
- **不要对市场「问为什么」——没人能回答、没有为什么；只有「应对」：给了就拿、没给就走、跌了止损、起来了拿着。经济学家炒股也不行，就坏在总想解释「为什么」。**（20260211）
- **反着来、走少有人走的路。** 找一个大而不倒的、越烂越好（越跌越被抛弃），这种机会往往比较明显，但什么时候不知道；08 年抄高盛同款；德某志跟了十几年，赌困境反转等人家一把等了十年，八倍折十年年化也很牛逼，关键这是确定性。（20261011）
- **人弃我取、人强我让；不贴新/旧标签，只按贵贱 + 情绪/实用价值评估。**（20260805）
- **后上船的人最先上岸：看不懂的新产业不急于上车，等产业逻辑兑现、看得懂的公司出现再上车。**（20260805、20260730）
- **贝叶斯只校准、不推翻。** 先有基础概率，新证据来加/减权重；反对「非零即一」的线性思维。例：降准小作文 → 基础概率很低 → 看信源强度交叉验证 → 调概率 → 映射仓位。（20260913）
- **噪声三问：①基础概率多大？②证据/样本量够不够、能否交叉验证？③这条信息背后谁受益？**（20260913）
- **信号 = 真实规律的投影；噪声 = 随机波动杂音；信息越多噪声越多，信号产生速度恒定，20 年本质规律没变。** 决定方向的三个慢变量：业绩、流动性、政策，其余都是噪声。（20260913）
- **慢变量（政策/基本面/流动性/国运 5-10 年）信号准确率高；快变量（短期暴涨暴跌/小作文）多为噪声。**（20260913）
- **政策红绿灯：鼓励/支持 = 绿灯；规范/有序开展 = 黄灯（收一收）；从严整治/限制 = 红灯（熄火）。**（20260913）
- **价格包含一切信息。**（20260819）
- **市场赚人性的钱：贪婪 = 赚了不走想赚更多；恐惧 = 一套就害怕要么割要么被套个大的；短期利润来自对手盘，对手盘来自想在短期获利的人（最容易被利用人性）。**（20261011）
- **市场永远是对的。**（20260927）
- **你能谈到什么姑娘一定是市场定价，做股票也是，市场不会错。**（20261011）
- **世界永远错配、市场永远是对的；所有人看好时一定不好，所有人看差时打空门。**（20260927）
- **利好出尽是利空 = price in；能看到的利好 = 已 price in；产业资本最懂行业（扩产 → 过剩 → 价格战）。**（20260913、20260819）
- **判断力本质是一套精密「算账」算法（正期望值），不是智商/学历/经验/运气。** 四根支柱：①会算账（正期望值）②抓重点（99% 信息是噪音）③管理情绪（损失厌恶/确认偏误/从众）④强者思维（识别、拆解、追随强者）。（20260614）
- **市场没有百分百可靠的方法；方法有效一段时间后市场会自我进化，风格/节奏会切换，所以别想一劳永逸，只能顺势应对。**（20260211）
- **去除偏见：二选一总选错，是因为对个股/板块/题材形成了偏见——选股时把右边股票名字盖住（或不看名字），只看左边图形，哪个漂亮选哪个。**（20260211）
- **谁的话都不信，就看规律、看数据本身。**（20260916）
- **想太多是主因：潜意识觉得被玩坏 / 历史高位套牢盘多 / 热点不是它——都是动脑子，一动脑就乱。图形第一、板块概念第二（图形是资金买出来的，图形先于消息）。**（20260311）
- **守株待兔：在牛股起涨点「收路费」卡它；只跟随不预测，做的是应对。**（20260408）
- **顶级交易员 = 极有耐心，一年就几笔看得懂的交易，大部分时间不做；交易员 ≠ 基金经理。**（20260408）

**内在逻辑（本节是总纲的「认识论」）：** 「价格包含一切」→「跟随不猜」→「不要问为什么」→「只做看得懂的」→「贝叶斯校准 + 噪声三问」→「政策红绿灯」是一条完整的认知链：先承认自己不懂市场为什么动，再用概率和证据去逼近，最后把仓位押在「慢变量」（业绩、流动性、政策、国运）上。「反着来」和「市场赚人性的钱」则是同一枚硬币的两面——市场专杀从众的人，所以你反着人性走、走少有人走的路，就是站到了赢家这一边。

## 五、周期观（万物皆周期、大中小周期、扩张/收缩、政策底→资金底→市场底、时间换空间、中美周期错位）

**师父周期观的一句话内核：别跟周期作对；先定位大/中/小周期，再反过来看盘，单日的涨跌在周期面前什么都不是。**

- **万物皆周期：先定位大/中/小周期再反过来看。** 单场 = 日线级，系列赛 = 中周期，四年大赛 = 大周期；别被单日情绪带着走。（20260920）
- **大周期看盘：「阿富汗的故事」——小孩看日线恐慌，老者让切周线/月线，看白大哥和黄大哥的关系、再看现在价格在哪个位置，至少周线到月线级别观察。**（20260920）
- **经济周期：扩张周期（适度宽松货币 + 积极有为财政）vs 收缩周期（财政货币双紧）。** 前几年收缩期该「躺好、别折腾、别买房、别捞偏门」。（20250531）
- **先政策底 → 再资金底 → 再市场底。**（20261003）
- **顺序永远是：先政策底 → 再资金底 → 再市场底。**（20261003）
- **大周期压制原则：逆不了大周期；大周期不支持，行业再强也熄火（乐视没等到内容付费时代、恒大没等到青训出成绩）。**（20260920）
- **时间换空间：横盘就是筹码交换，久了形成新筹码峰，方向就无法判断（盘久必跌）。**（20260408）
- **中美周期错位（分开看）：** 2009 年中国指数先翻倍，老美十年量化宽松硬顶到现在；不能套用同一节奏。（20260920）
- **中美错位：** 财政 + 货币都宽松 = 扩张周期（中国）；美国缩表加息 = 收缩周期，中美错位。（20260830）
- **板块估值轮动规律：前 5 年板块的估值排名/涨跌幅与去年完全相反，再过 3 年又反回来，20 多年从没变过（反者道之动）。**（20260330）
- **康波周期：康波起来后未来 2-5 年必然轮到消费，要提前布局，不能看现在某行冲过头去追。**（20260617）
- **人生发财靠康波。**（20260520）
- **大 A 时间分布：约 66% 垃圾时间、24% 舒适区间、10% 大波动时间。** 绝大部分散户真正亏钱在这 10% 里（追涨 → 被洗 → 创新高再追 → 再被洗）；赚大钱也在这 10%。（20250720）
- **牛市是「天天涨不停」而非「天天涨停」，约 10 年一次，会让你「同类项合并」记不清哪根大涨。**（20250720）
- **中国资本市场 = 先「集中力量办大事/充值」，办完后再「自由发挥/放烟花」。** 历史节奏：05-07 股权分置改革 → 09-10 四万亿 → 12-14 创业板 → 14-15 互联网+ → 股灾后大金融 → 贸易战核心资产「漂亮50」 → 924 新质生产力放烟花。当前处于「需要充值/众筹」阶段。（20260531）
- **盖楼顺序 = 市场恐慌悲观 → 密集出政策/讨论/强调 → 叙事 → 等信号 → 信号明确再盖楼。** 政策出来 ≠ 马上有表现：钱跟筹码交换需要时间和契机；政策密度越高、后面爆发高度概率上成正比；A 股每一个波段都有一个政策引导。（20261011）

**内在逻辑（本节是总纲的「时空坐标」）：** 周期观是「垃圾时间休息」「耐心伺机」的时空依据——当你不知道现在该干什么，先回答「现在在哪个周期、哪个位置」。扩张/收缩告诉你大势方向，政策底→资金底→市场底告诉你时机顺序，大中小周期告诉你用哪根线看盘，时间换空间告诉你横盘是在洗筹码不是没戏，中美错位告诉你别拿别人的节奏套自己。看清了周期，「等」就不再是焦虑，而是有坐标的等待。

## 六、纪律观（天天挨打三问、交易三前提、就事论事三原则、三不四不、收益率纪律、止损无情、频率纪律）

**师父纪律观的一句话内核：纪律是反人性的锁；大师靠纪律而非天赋，散户和大师之间差的就是「到点执行」这四个字。**

- **天天挨打三问：①像巴菲特那样择时了吗？②玩的东西看得懂吗？③看不懂看图说话，图变差撤了吗？**（20260812）
- **交易三前提：①行为符合自身层级 ②做最擅长的事 ③坚定认知不被噪音打乱。**（20260812）
- **就事论事三原则：①不幻想指数级暴涨 ②市场给什么玩什么 ③长期认账（A 股规则就这操性）。**（20260923）
- **四不原则：不追（不追高、只做 B1、止损幅度小）、不动（做对、有成本优势的仓位拿住不动）、不慌（择时看天气、持股/大跌看黄线）、不乱摸（沉住气别追杂毛热点）。**（20260204）
- **三不/四不：不装、不追、不慌、不动、（不乱摸）。**（20260920）
- **三不（资金纪律）：不加杠杆、不融资、不卖房炒股（顺序反过来：用股市赚的钱买房）；只拿输得起的钱。**（20250709）
- **收益率纪律：脉冲最高收益率 ≠ 平均收益率；巴菲特年化约 18% = 全球极限。**（20260906）
- **止损无情（见「风险观」）——它是纪律的试金石。**
- **频率纪律：不频繁交易，一周最多 1~2 个新仓，要有节奏；一月只开 4 次新仓（春节前只 2 次）。** 治「B1 老止损/开太多仓」的毛病。（20250531、20260204）
- **选股不重要，执行才重要。** 主观选股 = 你想比市场先预期；基金一配 100 只照样赚，因为做的是周期/板块，不是选股。（20250716）
- **交易只分「正确/错误」，不分「成功/失败」：按纪律止盈止损（赚钱或止损出来）都是正确交易；不按纪律（追高、不止损、越跌越补），哪怕三四个涨停也是错误交易。**（20250716）
- **90% 靠交易纪律与应对，看懂结构只占 10%。**（20250723）
- **反人性靠纪律来锁：大师靠纪律而非天赋。**（20260419）
- **每天就干三件事 = 止损、放飞、滴滴；没人套得了你。**（20251119）
- **盘前定策略、盘中只执行：前一天晚上写清「没到白线/黄线不操作」，次日盘中只执行、不因情绪追涨杀跌（= 摆大巴打反击：赛前定打法、场上只执行）。**（20260614）
- **盯收盘价做决策，别盘中决策；每根 K 线是每天 4 小时走出来的（还叠加自媒体噪音），复盘容易、实盘难。**（20260404）
- **卖出后踏空要认、走早了也要认；空仓也是策略。不严格执行纪律亏是应该的；先把每一笔交易做对，账户自然变红。**（20260318）
- **次次遵守纪律、养成肌肉记忆，才能躲过「那一次大的」。**（20260916）
- **每笔交易都会后悔，让遗憾少一点。**（20251208）
- **把纪律告诉大模型（豆包免费即可）当「风控委员会」，责任甩给机器，实现执行合一。**（20260902）
- **新手别着急：净值曲线是把每笔交易做对后自然起来的，别想快速翻倍。**（20260219）

**内在逻辑（本节是总纲的「操作系统」）：** 前五章的心法（风险、仓位、心态、认知、周期）最终都要靠纪律来兑现。天天挨打三问、交易三前提、就事论事三原则、三不四不——这些「三句/四句」是师父把整套世界观压缩成随身可背的检查清单；收益率纪律（年化 18% 是极限）是给贪欲设的锚；频率纪律是给「越亏越玩」设的刹车；「执行 > 选股」是给所有分析设的终局。纪律不是限制，是让「看得懂的少数机会」能被执行到位的那把锁。

## 七、对手盘观（大哥、做局者、击穿对手盘、气氛组、七分组、摆大巴防守反击、龙队的对手盘是公募险资）

**师父对手盘观的一句话内核：市场是筹码博弈，你赚的每一分钱都是别人亏的；想赢，先看清「对手是谁、大哥是谁、谁在割谁」。**

- **找大哥：想吃大肉要「找大哥」，跟麒麟会站在一起、打不过就加入，别跟主力作对。**（20250611）
- **大哥 = 主导市场节奏的大资金/主力；「左手媒体右手买」，消息永远在盘面之后。**（20251110）
- **只要大哥没上桌，局部所有都是噪音；大哥走你就走。**（20260812）
- **任何信息先看「大哥在不在」——大哥在就跟着、大哥走你也走，没大哥任何噪音都不听不看。**（20260621）
- **做局者模型：趋势 = 做局者讲故事 → 共识 → 泡沫 → 破裂。**（20260819）
- **击穿对手盘 = 主力用缩量假摔击穿短线对手盘的公众止损位来洗盘（制造恐慌把跟风盘洗下车），目的是吸筹/洗盘不是真出货。散户正确姿势是「看穿」主力如何击穿，从中渔翁得利（帮大哥锁仓、与庄共舞）。**（20251231）
- **你的止损位 ≠ 公众止损位：不能设在关键 K/N 型低点这些「公众位置」，否则被主力精准击穿。**（20251231）
- **气氛组：行情挣钱需要「气氛组」（人气/情绪）参与。**（20260805）
- **七分组 = 一波流（主力表演给你看）。**（20260906）
- **摆大巴防守反击：中美博弈 = 摆大巴防守反击；924 是「最关键时刻必须来一下」的一次性表态，不是常态。**（20261003）
- **防守反击 = 等别人稀缺心态发作（杠杆强平/基金赎回/年底回笼/风格漂移调仓）抄带血筹码，前提标的是真稀缺。**（20260826）
- **司马懿框架/防守反击：无「梅西 C 罗」级别绝对强势标的时，耐心防守、等对手（市场）犯错再出击。**（20260505）
- **龙队的对手盘不是散户，是公募和险资；散户的对手盘是游资（专门割散户）；游资大佬的「一进二、二进三」打板教学 = 教你如何成为一只羊。**（20261014）
- **跟机构做对手盘：散户唯一能胜主力的方法 = 打他软肋——大钱出不了货、跌不起，你在「放量花钱的大阳线（蹬起来）」时把筹码给他。**（20251119）
- **主力永远比你先知道消息：别活在消息面、别问为什么、别动脑子、别对票有感情。**（20251103）
- **对倒（对岛）只有两个作用：①对倒拉升（筹码都在手里，拉得快）②对倒维持活跃度（制造有人交易的假象）；洗盘/出货一般不用对倒，减仓是真卖。**（20260211）
- **对手盘最坏假设：把主力想得最坏，任何对你不利的动作都当真的进攻，不侥幸、不赌；市场里要当「坏人/Bad Boy」，比对手更坏才能守住自己（生活中才做好人）。**（20260621）
- **钱 vs 筹码：主力不缺钱、玩的是筹码，筹码最重要；散户别老盯钱，要盯筹码；低位筹码比钱重要得多。**（20260621）
- **做局的人永远低买高卖；在便宜、有价值的地方待着，至少不会被重创。**（20260621）
- **市场铁律 = 永远少数人赚钱（都挣谁亏？）。**（20261007）

**内在逻辑（本节是总纲的「博弈论」）：** 对手盘观回答了「你的钱从哪来」：短期利润来自对手盘，对手盘来自想在短期获利的人（最容易被利用人性）。所以「找大哥」「看穿击穿」「打主力软肋」「摆大巴」是一整套「选边站」的策略——你不必比所有人强，只要站在不会被割的那一边。而「龙队的对手盘是公募险资」这句话直接点破：散户以为自己是和主力对赌，其实连对手都排不上号，唯一现实的路就是「帮大哥锁仓、与庄共舞」。

## 八、国运观（跟国家走、相信国运、三类钱、大而不倒太子级别、穿透之后）

**师父国运观的一句话内核：A 股是政策市、资金市、技术市，但最底层的锚是「国家意志」和「国运」；跟国家走，相信国运，赚国运的钱，是普通人唯一的大道。**

- **大 A 不看基本面/情绪面/美股，只看「国家意志」。**（20250618）
- **跟国家走、相信国运、指哪打哪。**（20260816）
- **散户唯二可做：①跟着国家走 ②听黄大哥白大哥 + 看大哥态度，然后等。**（20260906）
- **三类钱：传统老灯赚周期的钱/红利的钱；科技类赚故事的钱；最核心的赚国运的钱——按风险承受能力去抡。**（20261011）
- **相信国运与 2035 测算：巴菲特能发财因美国是百年经济军事主宰、国运在这；中国也是超级大国；到最后就是相不相信这个国家。**（20261011）
- **社保年化 7%~12%，现在 38，未来 10 年社保不赚钱你信吗？这是信仰问题（相当于巴菲特在美国怎么赚钱）。**（20261011）
- **大而不倒、太子级别：找一个大而不倒的，越烂越好；德某志不是贝尔斯登/雷曼（它们需要死，大家才能上岸），德某志也是国家的太子；赌困境反转配四五个五六个这种玩意儿，一个大周期里机会挺多——这就叫确定性。**（20261011）
- **穿透之后：BBA 两个币从一战二战就开始了，只要这两个币在，无非是欧盟德国的英国的；敢卖中国这边刷花呗都上，一直谈最后到一块九毛，中国出手雷老板买了，直接小米 Maybach 联名——穿透之后一个时代就明白了。可口可乐这辈子会倒吗？美国倒了它都不会倒——穿透之后。**（20261011）
- **A 股 = 国有资产：国资委是所有上市公司大股东；往下杀 20% = 国有资产流失？只要国家在该回来还得回来；有能力的玩复杂点，没能力的赌国运就完了。**（20261011）
- **长期财产性收入增长 = 跟随国运（要么像巴菲特那么稳、要么老美指数基金）。**（20261011）
- **千万不要有「买什么东西让股市报销」的想法，你一般是给股市报销。**（20261011）
- **A 股见顶信号：只要有一个三斤（三中全会定调十五五/十六五），A 股就稳了，未来五到十年就稳了。**（20261011）
- **国家队/龙队有定价权，目标是慢牛：上有顶下有底，拉银行给大盘拉空间。**（20251112、20251123）
- **只有「顶级意志」（924 级）才给上方套牢盘解套。**（20260923）
- **财政绑定（924 本质从「核心资产绑定」升级）：地方国资通过一级市场股权（IPO）替代土地财政，二级市场只是「气氛组」；未来的钱和「头牌」在十五五规划重点产业里，且从源头就被国资一级绑定。**（20260621）

- **跟确定性，不瞎投；当前中美博弈第六/七回合，防守反击，别抱幻想。**（20260816）

**内在逻辑（本节是总纲的「第一性原理」）：** 国运观是所有心法的最终落点。因为 A 股是「政策市 + 资金市 + 技术市」、本质是「为经济提供融资再融资平台」，所以它的涨跌最终由「国家意志 + 国运」定价——这就是为什么「跟国家走」排在散户唯二能做的事第一位。三类钱（周期/故事/国运）把前七章所有心法归了位：赚周期的钱靠周期观，赚故事的钱靠对手盘观，而赚国运的钱，靠的是「相信国运 + 太子级别 + 穿透之后 + 时间发酵」。最后那笔「穿透之后」的账，是师父世界观最凝练的注脚——看穿一层层套娃，最后只剩一个判断：**这个国家、这家公司，会不会倒。**
