## 一、高尔夫的四个圈（框架起点）

打高尔夫打得好需要四个圈：
1. **体能**（fitness）—— 基础，吃天赋。含耐力、速度、弹跳、爆发力、柔韧性、协调性、力量(strength)、敏捷性、身高、体重。
2. **技术**（technique）
3. **心理**（psychology）—— 小麦大师赛多年因最后简单推杆失误（心理），中国球员黑三分钟被连进两三个（心理），赛前预期与走势不匹配（心理）。
4. **运气**（luck）—— 比赛那天大风、莫名其妙来一根。

结论：体能/技术/心理都完美，还得赶上运气，才能最终成为赢家（拿到自己的"铜钱"）。

## 二、框架推广到篮球/足球（举例教学）

四个圈可套一切体育运动。师父在篮球里把每圈拆细：

**体能**：耐力、速度、弹跳、韧性/柔韧性、协调性、力量、爆发力(acceleration)、敏捷性、身高、体重。→ 吃天赋。

**技术**：运球、传球、投篮（三分/中投）、抢断、篮板、盯人、突破、盖帽、罚球、视野、助攻（严格说不算技术）。

**心理（精神属性）**：想象力(创造力)、领导力、意志力、抗压性、专注力、团队意识、智力、自信心(confidence)、野心(ambitious)、侵略性(aggressive)、纪律性、责任心。→ "所有顶级学员都是最高智力……一项体育运动到最后玩的都是脑子"。

**运气**：天时(时代)、地利(球队)、人和(教练/裁判/贵人)、伤病、天赋。→ 天赋归运气，因为"你练不了，升上来有就有没有就没有"。

## 三、人生四个圈（核心正题）

把框架搬到人生，四圈：
1. **健康**：身体素质、力量、耐力、速度、经历、基因(遗传疾病)、视力、免疫力、伤病。
2. **能力**：智力、技能、认知、执行力、社交能力、观察力、创造力、情商、学习能力、沟通能力、记忆力。
3. **心性**：情绪调节能力、抗压性、自信心、意志力、专注力、团队意识、野心、纪律性、责任心、内在稳定度、耐心、好奇心、自律、勇气。
4. **时运**：天时、地利、人和、天赋、随机性。

### 历史人物框架（逐人画圈）
- **霍去病**（"获取病"）：心性极强（抗压/意志/专注/野心/勇气，从小述出、敢跟皇上叫板、一高人胆大），能力牛逼，时运有（有舅舅卫青），健康差（21岁死）。→ 放今天靠舅舅就保住了。
- **吕布**：心性太差（反复无常+智力差，想不清楚），能力有，时运差（没在正确时间遇到正确的人；若跟刘备一起卖草鞋、后三国时代没得选反而好）。
- **诸葛亮(丞相)**：能力拉满、责任心拉满，但时运差（刘备晚来10年）、天命（健康）差，天妒英才。→ 想当丞相但复制不了。
- **曹操**：均衡，精力牛逼，有遗传疾病（偏头痛）。
- **袁绍**：时运拉满（四世三公、天时地利人和都有），但健康不行、心性不行、能力不精 → 没用。→ "若给袁绍一个诸葛亮，后面就没三国什么事了"。
- **司马懿**：寿命长（熬死所有人）+ 心性牛（能忍、装病十几年一点声音没有）+ 能力一般（"捷径债打呆仗"、跟杨修/荀彧比不了文采治国）+ 时运（利用随机性）。→ **可复制的模板**。
- **周瑜**：能力被高估（纯个人观点）。
- **川普(穿)** = 司马懿模板的现代复制：心性牛（情绪稳定/抗压/fake news/能忍滑头/自信心/野心两次当总统/勇气真敢抡伊朗/内在稳定度），健康行（80岁扛过新冠），能力一般（"美国王思聪"），时运差（赶上中国崛起束手束脚）。
- **普京(精子)** = 同样司马懿模板：能忍能活、健康行、能力一般（"但凡有点智力，打乌克兰打成这样？"）。
- **巴菲特**：活得久把对手熬死，时运行。

### 核心结论（人生框架）
1. **不要追求 GOAT（四个圈完美）**——乔丹只有一个，丞相/周瑜/罗纳尔多/曹操都复制不了，只有司马懿模板可复制。
2. **最重要的是寿命（基础）**：先保命、别下牌桌、苟住能活着。金句："不下牌桌""非必要不游泳"（蹦极/滑翔伞别作死）。"你天赋60岁，别作，能活到60岁；你蹦极20岁就没了，比天赋都到不了。"
3. **心性 5 核心（最重要）**：抗压性、自信心、专注力、内在稳定度、耐心。其余：
   - 情绪不重要（"牛逼人都有脾气"，只有女人要求男人情绪稳定）
   - 团队意识不重要（=PUA，"特斯拉发明交流电跟谁交流了""马斯克有团队意识吗"）
   - 野心不重要、好奇心不重要（"好奇害死猫"）、自律不重要、勇气一般（有就有没有就没有）。
4. **时运（最好改变）**：
   - 天时改不了（生在中国/美国都是盛世；生在缅甸就暴弱）
   - 地利可改：出来、远行、换城市、换公司（"你孩子班主任就是你小学同学，你哪有人和"）
   - 人和可改：找大哥、拓宽社交（"去北京全是大佬"）
   - 天赋改不了：找到自己的天赋(Love marks)
   - 随机性靠耐心等待："活得足够长什么都见过，什么可能都有"
5. **能力（最难突破，但不重要）**：中国能力强的人太多。基础智力得有、认知得正确（逻辑/底层逻辑）、一定技能得有；"能力槽一半就够了，剩下就是活得长"。"乾隆没用过iPhone17，你用过。"执行力逼到份上谁都有（老虎追你你也跑）。社交能力/观察力（你不是特务）/情商/记忆力/学习能力都不重要。

## 四、抓羊角蜜（追女生）框架（今日"正题"）

标题里"羊角蜜"实为谐音梗（羊角蜜=杨幂/美女），师父把四圈框架套到追女生：

四圈：
1. **自身条件**：外形、衣品、经济基础、家庭、健康、人品、性能力（"长度硬度"）。
2. **方式方法**：智商、情商（=聊天能力+共情能力）、节奏感、执行力。
3. **心态**：不跪舔、不怕失去、有主见、情绪稳定、内核稳定、耐心、勇气。
4. **缘分时运**：君生我未生（时间错位）、单身/异地/对手/看对眼。

### 干货要点
- **不跪舔**：上来就"家家你真好看"=第一波淘汰（人从小听到大）。
- **不怕失去**：男人勇气最大来源，不要患得患失（"无所谓有，无所谓无"——鲁迅）。
- **有主见（核心案例）**：她问你吃什么，她说吃饺子，你偏说吃包子，最后陪她去吃包子——"你成了她跟闺蜜的 topic，过目不忘"；她说吃火锅，你别问"你来订吧"，直接订一家带过去"我知道哪家特别牛逼"。她说吃馅饼时，你就"正好我知道一家馅饼店巨牛逼，现在就去"→ 既尊重对方又不跪舔、还掌握节奏。
- **内核稳定 = 原则的稳定，不是做法的稳定**：不是"每天8点半打电话"，而是知道自己是泡妞/结婚/相亲、喜欢什么类型，底线不碰。
- **情绪稳定**：她3小时不回微信你就崩溃=淘汰。
- **耐心**：羊角蜜身边从不缺优质追求者，"最后谁能接盘？有耐心的，先不死、陪跑到最后"。
- **缘分时运不重要**（其他三圈够强时）：单身可谈、异地可飞（"全国可飞"）、有对手自然淘汰。

### 案例模板
- **李思聪** = 吃天赋（自身条件一项过强），不可复制。
- **童锦程（铜锦城/祖师爷）** = 外形+经济基础+网红，不跪舔人设，搭讪勇气，心态好，不可复制（吃天赋）。
- **烙矮** = 外形衣品强，靠节奏感+情绪稳定+有主见+耐心哄得好。
- **西门庆** = 吃天赋。
- **王石（王淡）** = 两个模板：前期老实/浓眉大眼/有主见/看对眼/缘分来了（覆手），后期框架变了所以离了。
- 结论：**"缘分不缘分都扯淡，还是不够爱，或者一定是权衡利弊了。"**
