## 一、踏空心态（当晚重头戏）

- 背景：6/24-25 大盘三连阳，非银金融暴涨（国泰君安国际拉200%），全网散户"踏空焦虑"
- 师父净值创新高（满仓拿住不动+主题：创新药/可控核聚变/新消费周一周二）——"你们抢我什么鼠标"
- **什么叫踏空（原话标准）**：
  1. 你研究一个月、反复讲的（泡泡/中国新消费），它涨15%你仓里没有→真踏空（"我他妈骑100公里进山出家"）
  2. 你一路跟踪有信仰的（稀土/券商），它创新高你没有→踏空（该你赚的）
  3. 你交易策略里的完美图形出现、你看懂了、没买→傻逼踏空
- 今天非银金融涨≠踏空："你了解国泰君安吗？了解稳定币吗？你的买点是什么？"——赚钱只有两种可能：一路套下来的（信仰）或一路B1抡下来的
- 散户心理："出门没捡钱就算丢"；"**踏空比亏钱还难受**"（4/7股灾没那么悲观，今天反而悲观）
- 卡佩罗案例：罗马夺冠70分钟球迷冲场庆祝，卡佩罗："你们没见过世面"——一根1%至于吗
- "**成功才是成功他妈**"；股票只跟两件事有关系：**经验**和**心态**（985/211学历没用）
- "只有你不敢买的，没有咱错过的热点"

## 三、坑的三级定义（核心方法论，截图）

- **大坑**：有历史新高 + 连续很长时间屁滚尿流一路下跌 + 起稳一段时间 → **大坑赚大钱**（拿住不动/信仰，月线级别）
- **小坑**：有阶段高点 + 连续回调后起稳 + 不破阶段前低点 + 拱到大复值 → **小坑赚小钱**（少妇战法，周线级别）
- **小洞**：连续N型上升趋势中出现黑天鹅（事件驱动）突然下杀 + 勾到大复值 → **快进快出碎银子**（就一根，日线/30分钟线）
- 深水炸弹=小洞，已被淘汰（不稳定）；"威回来形成几尺钉耙更稳定"
- 师父自己现在只做拿住不动（满仓+信仰）；"少妇战法是你资金积累期最好的"

## 四、目标价算法（"祖宗之法"）

**第一目标价 = (坑口/净线位/盖 - 坑底最低价) + 坑口**
即 (盖-底)+盖。原文案例（含实际兑现）：
- 中石化：盖5.97 底3.2 → 8.74（实际7.24"艺术"）
- **小米**：盖35.9 底8.31 → 63.5（实际59.45"艺术"）；突破后回踩36.05 vs 坑口36（"差一毛钱，你跟我说是巧合，我打死也不信"=麒麟会铁证）
- 三生制药：盖22.69 底4.17 → 41
- 同概念两龙头（黄金类）：盖78 底30 → 126（**实际126.3**"科学+艺术"）
- 新前锋：盖37.2 底24.3 → 50
- 新天风：盖26 底15 → 37（实际37.2）
- 某票：盖26 底18.5 → 33.5（实际33.58）
- 李宁：净线位28 底14.8 → 41.2（实际44.6"艺术"）

- 有反例（没成的），但基本面配合的基本都能到

## 五、关键K与出坑纪律

- **关键K**=突破坑口的旗杆K线，"顶天立地把价格带重新撑起来"；回调不能破它的低点，破=熄火（最多变区间）
- 出坑特扑→回踩坑口确认（5.96踩5.96不可能巧合）；回踩不破+勾大复值=接着抡
- 四分之三量线只在特扑关键位置看；**缩半量最好**；"这就是关键K后面才要看四分之三量线"
- **出坑起货=趋势的钱**；填坑阶段不赚就不赚（除非有信仰或恰好B1进）
- "不要跟主力抢筹码——确认有大哥来了再上"；散户不可能把中石化这种盘子拉起来，能起来=有大哥
- **坑里任何位置放量=好事**（有大哥来抄底，安免案例）；顶部放量=不好；爬山坡放量=好事
- 底部新低出来没依据；双底位置技术派抄底可能被套——"至少等一步连续放量"
- B1止损"只输一根"；"没涨=错（市场没证明你对，你就是错）"——但实操难，师父自己也承认
- 中石化案例止损亏4.5%；"一定要止损。你到别的票找一个成的，这把就回来了"
- 中小创波动率比沪深300高："沪深300给30%，中小创可以+150%"（爬山坡幅度容忍度）

## 八、答疑要点

- 空杯心态忏悔书（新手典型错误，师父点评）：①急着赚快钱 ②不遵守纪律：不及时止损（青花横横破位不走）、不及时放飞（可控核聚变吃20多个点不走还加仓——"上世纪20年代利弗摩尔玩法，大A基本就是送钱"）③下阶段"以净止损不看成本"
- 60万重仓赌一支：不行。"1.9万人抛硬币一晚上，几百人连抛20次都对"；"你赌对一次后面次次想赌；**连续回撤比单次回撤致命**（每笔砍5%，连续砍10次就没了，再打回来要翻倍）"；"留得青山在不愁没柴烧"
- 满仓低空经济："可以销户了"（说吹牛逼两三年了）；满仓海南自贸港：别气我
- **港股瑕疵股不碰**：基本面有大瑕疵（法律问题）的港股不要碰（博格巴类比：有污点就完了）
- 港股满仓浮盈：双B1可扛；"我没止损是因为我拿利润玩、成本440上来的；你们没浮盈，低位破掉就走"
- 踏空者的真相："你空仓说明你没听明白"；半仓=听话的；满仓=热泪盈眶
