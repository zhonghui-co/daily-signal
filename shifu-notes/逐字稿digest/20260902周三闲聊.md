## 二、大钱 vs 小钱思维（核心认知）

**大哥心态拆解：**
- 大哥们今年赚大钱；分"来得早的大哥"（2025年7月就来）和"来得晚的大哥"；早大哥8月份"聚开心"，晚大哥"攻击拴那"（套住），终于有机会喘口气先走

**社保（险资）逻辑：**
- 外面传"社保今年赚13%"是误解；**社保年化收益率约7%**（每年稳定7%），不是13%
- 社保=无限子弹、主人翁意识、越跌越敢买；散户/机构没有主人翁意识所以没这个魄力
- **大钱要的是：稳定性、确定性、相对低波动、绝对的价值安全（=足够便宜）**
- "短期你可以不给我蹬起来，但你别给我往下勾撸了；往下撸了可以，但得给我弹起来，别撸没了"
- 社保/龙队买的都是"国家蛋白"（国字头/央企国企）
- **社保老能整到空门**：它买的永远是市场不关注的地方（"管外"），价格更接近估值低估。例：去年反内卷出来时市场爆炒，社保一季度就去了；半年报出来发现很多趴地的东西社保/龙队进去了
- 大钱玩法：相对低位玩一个小波段就够了，一年收队（"险子证自职业就卖了"）

**社保赚的是谁的钱（重要澄清）：**
- 社保赚的**不是散户的钱，是公募的钱**——社保体量太大，只有公募的钱能接走；散户接不走
- 社保永远在"过程中"走，不会在最高点（最高点他出不去）

**产业资本意识（师父优化后的个人策略）：**
- 自己足够了解 + 建立产业资本意识；拿苹果举例：只要大逻辑没变，涨跌不重要，等"逻辑结束或最高潮（大SE）"才卖
- 飞特（巴菲特）做得很少=因为他相信美国经济
- 中国大A老乱=实际上所有人都不相信（2001年就喊"完善市场制度、保护投资者"，26年了还在完善，因为没人信→起起伏伏）
- 金融反身性

**逃顶方法论（大钱为什么总能卖在高位）：**
- 美股每次**周线KDJ 80以上开始卖、月线80以上卖**；**周线20以下/10以下、月线20以下=相对底部**（不是能精准买在最低，是大钱不容闪失）
- 机构靠**风控委员会集体决策**：勾80以上开会集体决定减50%，没个人压力，"集体对集体担责"，所以能严格执行纪律逃顶
- 公募基金永远高位追进去=主观跟随市场、不追求绝对收益；社保/险资追求绝对收益，有严格合同风控
- 明星基金经理（坤哥）无统一白纸黑字制度，风控总监管不住

**ABC建仓逻辑（大钱建仓节奏，重点）：**
- A=集体决策进场（社保底仓类资金，"到了纪律/估值位置就进"，分批进，不是坐右侧）；A不一定是绝对最低价
- B=又跌一段时间更便宜了、盈亏比更高、行业没问题（两年翻倍），集体决策再买20%
- C=市场转向、趋势来了、卖方都在宣，来大钱弄一下；**C可能阶段见顶**（若行业趋势没反转，到C反而见顶开始震）
- 如果C没了又回到B/A的位置 → **暴力K往往平行**（拉长看都在相同价格区间带）=有险资长期资金大哥在看着
- **大钱藏不住**（社保用钱当天顶板挂单买，麒麟会当天就拿到股东名单/知道哪个ETF、社保110几账户进来了），**庄稼的钱藏得住**

## 三、估值高低判断（真传一句话，本场最核心）

**英超足球类比：**
- 身价 = 定量（实打实花钱买的、业绩）；排名 = 变量（当前价格位置）
- 曼联身价10亿英镑、踢10轮排名垫底 → **排名被低估**（敢赌赛季38轮结束排名更高）
- 西汉姆联身价8000万英镑、排名第三 → **排名被高估**（敢赌赛季结束排名更低）
- 不要纠结身价高估（身价是定量）；看排名的高低估
- 黑马问题=配置（多压几个）；单压看多空很简单
- 最难的是排名接近身价排名的（身价第10排第9/11），难判断
- 时间拉长一定还是球员能力决定：曼联再差也没降级（常年前十以上）；热刺去年保级是几十年一次；天津泰达只要想保级肯定能保级（除非自己不想保级，像长春没钱运营主动降级）

**工具（免费）：**
- 一个免费APP，以前专业机构在用、现在APP免费，师父口述"叫WAN什么玩意儿"（**疑似"万得Wind"或"理杏仁"，存疑**）
- 用法：下载 → 任意股票 → 资料里找"PB PE的历史分位" → 选过去十年 → 看它在行业/历史中的估值水平 → 判断高估还是低估
- **看分位，不要看数值**（数值没用，看分位/百分位）；五年十年就够了，不用看二十年三十年
- 整体（公司整体值多少钱）看PB；短期表现看PE
- "我女儿都会看"

**定性金句：**
- **"短期是情绪，长期是估值"**——估值是长周期给你的平均价格，短期波动不改变估值
- 为什么跌破位了又悠上来：总有人知道它低估了来一波波抄底；时间线拉长"三年前就这价格，现在还是这价格，中间起起伏伏"=市场给的估值水平
- 没盈利公司=博傻/投机/讲故事/纯交易（"纯靠想象力、纯编故事"）
- 免A指数短期上不去：经济恢复速度不符合预期，政策会一直刺激到符合预期；地产新政（占GDP 18-20%）必然要动
- 赚确定性钱：国安案例（上半年主场只赢2场，下半年五连胜，现在排名第二）
- 4%/-2.3%已经这么准了，出现波动摩擦时还有人信不信

## 四、交易心法/纪律

- **择时=红灯绿灯，不是牛熊**（"择实"）：上课打铃就上课，下课铃就下课；树立红灯/绿灯概念，谁都骗不了你
- 最大的敌人=心魔/内耗
- **核心问题：赚钱的时候不卖**——没有决策机制、靠个人主观判断所以有心魔；卖完怕踏空、不卖找信念支撑
- **集体决策制（甩锅给大模型）**：把自己的纪律告诉大模型（豆包免费就行/千问/豆豆/智谱/宝宝/元宝），开一个"风控委员会"，让AI做决策、把责任推给机器；空船效应（对面船撞过来，一看没人就不生气了）
- 技术指标是解决"风险区间 vs 低风险区间"的，不是解决最高价；它反映市场情绪与合力的量价表现，是概率（社保就是这么做到的，但必须集体决策才能做到）
- 天气预报比喻：七八级大风/雷暴就不出海打鱼，再大台风也死不了——"不作死就死不了"
- 100个子弹消灭一个敌人就是神枪手（美国士兵战场数据）
- 不要追求完美（选股像选完美女友：22岁鼎美+北京户口+腰缠万贯+爱你+处女+真挚+骚+没前男友+懂恋爱=没有）
- 梁文峰量化系统运行多年，2026年还是亏钱（最高亏13%）——你怎么就能行
- 摘桃论（B2/B3直接摘桃）：摘十次成1-2次就发财，其他8-9次是人家干你（耐心资本布局多年，凭什么让你直接摘桃）；"兵不厌诈，严守纪律"
- 成本论：为风险付费（抓一次8000）
- 跟产业资本在一起，等他"下一支门"（下一波）；起来三五五十脱离成本区后给你"单针下20"（ASR写作"单身下饰时"）时就走
- 大股东持续增持（"橘子"例子，每天5000万/7000万/1亿买）=他知道你不知道的事（05-07国企改制、中石油48块套20年）
- 看产业资本公开动作：只做一次当骗人，持续做=真（"一天是玩玩/十天是情/三十天是惯性/六个月是习惯/三年是爱情"）
- 一级vs二级：产业资本等5-10年；二级等2年2个月完成/3年半年/半年2周（合肥投长鑫、杭州投语数前面都多少年）
- 老马（阿里）增发：涨跌由大哥意志决定，不由你能看到的消息决定
