## 二、主力出货的五种经典方式（核心）

> 总原则：只针对个股；大盘股见顶方式未来另讲。判断只看 **量 + 位置 + 音线（阴线）**，顶部不看MACD/KDJ背离（"顶部只有一个，背离每次上涨都有无限个"）。换手率不能用来判出货（大盘小盘不同：民政银行前十大股东拿90%筹码、外面只有10%，0.5%换手就能拉涨停）。
> 这五种方式**绝对不百分百判顶**（甚至小一半可能还有新高），但出现后**百分百是庄家/麒麟会/机构已经在出货**；后面还有多高，只看有没有新傻子接、能不能出得去货、市场还有没有鱼尾。

### 第1种 S1 = 加速之后单日放天量大阴线
- **三条件都满足才成立**：加速 + 放天量 + 大阴线。
- 处理：至少卖一半（若完全大阴线直接全卖），宁可信其有不可信其无。
- 案例：
  - **中财科技 8/19**（612亿中大盘）：当天不走第二天-5%，后续最大跌16.53%。
  - **镇阳发展**（59-70亿小盘）：小盘最易单顶，出不完就做双头，第二天直接跌停。
  - **光线传媒 2025/2/17**：放巨量（哪吒概念），当天223亿被套，一直等到"哪吒3"。
  - **中国中铁 2014/12/22**：连续加速后大阴线（师父当时在做，高开6点直接下来，看量后"收队"）。
  - **徐翔标准出货图 = 一字断头**：涨停板一笔单子砸到1点几，反弹再砸、再砸，不护盘不演了，尾盘出。
- 关键：顶部一定是走完才知道是顶部，尾盘才能确认。长上影+放量但没加速 = 试盘不是出货（"出货的逻辑不会告诉你出货"）。中大盘单根出不完，所以后面可能还有S2。

### 第2种 = 加速之后次高点突然巨量长阴
- **前一日最高点缩量甚至没放量，次一日巨量跌停/长阴**。大概率不是主操盘手本意：资金链断了/突发利空/被做空/想先出一部分货。
- 关键词"突然"很重要（每个字都有意义）。
- 案例：
  - **民生银行 2013/2/7**（史玉柱进股东）：天量天价放量沿白线走，次高缩量创新高，第二天摁着卖一波二波三波，跌9.27%≈跌停。
  - **东财 2020/7/16**：创新高缩量→突然放量跌停→横盘等黄线，后面又做一波。
  - **宁德 2021/12/7**：370高点，次高点放巨量跌4.47%；跌破黄线必须走。

### 第3种 = 新高之后连续阶梯放量下跌
- **麒麟会常装，A股独有，不适用港股美股**。核心判断："这一批太丑了"（下跌的阳量一根比一根大、盖过顶部阳量）。
- **B1这种图别做**（这位置麻烦）。
- 案例：
  - **民生银行 2025**：顶部阳量小，下来4根阳量一根比一根大，连续放量下跌。
  - **万科 2018/1/29**：次高点小放量不明显→突然杀一根放量破白线→放量破黄线，40%没了。
  - **禁忆实业**：糕点放量，连续阶梯放量下跌，10%没了。
  - **阿信**：次高点带量下跌很丑，只能靠某队magic（"能放量摁下来也能缩量/放量展上去"）。
- 例外：**幸福南海** = S1+第3种结合，被新大哥接住做出第二波（21.2亿接盘），极罕见。

### 第4种 = 双头双放量巨阴
- **适用于中盘股**。规律：小盘单顶A杀；中盘做双头；大盘做S1/S2/S3完整头部（头肩顶/M顶/多M顶）。**盘子越大盘顶时间越长**。
- 案例：**为宁健康**：S1假阴真阳但上影线长、空头优势大→攻击下来→又拉起来冲20%涨停（实15%）→尾盘又出→双头双放量 = S2。
- 踏空唯一情况：大哥放**超级天量且收盘价在套牢盘之上**全买走；十笔可能只一笔踏空。

### 第5种 = 顶部绿长红短（绿肥红瘦）
- **适用于盘子相对大的票**，性格"慢慢来、只蹭蹭不进去"，顶部绿肥红瘦。
- 案例：
  - **华谊兄弟 2013/9/24**（20.25，快千亿）：盘头两天放巨量→次高点跌停放巨量→绿肥红瘦一把17→10块跌百分之五六十。
  - **中色 2010/10/18**：顶部区域红瘦绿肥 = 有人大肆出货。
- 反包要求比之前量还大。看面积：顶部"绿油油全是卖出来的"。

### 第6种（补充）= 盘子越大、出货方式越综合
- **阿信 2015**：先S1 → 双头S2 → 连续阶梯放量。
- **中国神车 2015/4/20**：S1 + 次高点带量跌停 + 连续阶梯放量 + 无量一字涨停 + 天地板（涨停按跌停）大绿帽子。
- **东财 2019/2/26**：双头 + 第一种创新高量大于之前 + 次高点放量跌停 + 顶部绿肥红瘦（三门中炮反向）。
- **苹果/某大票（3772亿市值）**：一根出不完（一根才230亿成交额），综合：做顶→再顶→杀巨量→阶梯量→缩量阳线→平台→放量砸破白线出货完成，明年再来。
- "不是良心，是出不去，只能拉起来出。"

## 三、假阴真阳定论（重要统一规则）

- **从今以后取消"假阴真阳"概念，一律当阴线算**（回测无概率优势）。面对三万人，按交通法规一样低门槛统一界定（"酒后不要喝酒、开车不喝酒"，不再记双白双黄线/虚线/代转区）。
- 假阴真阳下来之后又被突破 = 新大哥来了。
- **顶部大风车标准图案**：宁可信其有不可信其无，**至少卖一半**；若完全大阴线则直接全卖。卖一半 = 应对不确定性的对策（不知道真假）。
- **追高的人出现此图形必须走**（那位置没有买点）；低成本有浮盈的可以拿一半仓赌第二天反包。
- "你是你账户资产安全的第一责任人"（骑摩托比喻：不要把性命交给路上的其他车）。

## 四、复盘/答疑干货

- **压盘 vs 放量**：没有区别，就是卖；放量=卖的人多。国家对没法对倒，压盘=真出货，但能压下去也能买回来。
- **中信证券**：3888开始调整、一路杀下来 = 压盘；蓝线距离 = 防守容余/时间换空间（时间换空间的空间）。
- **华通**：标准SE（第一种），所有卖方群都在宣，见顶确认。
- **半导体ETF**：阶梯放量下来=有人出货，但没标准SE顶部，B1可干但轻仓（10万 vs 券商25万），设止损。
- **新华保险**：三根压着卖=第三种（新高后压着卖），大哥（百岁山）来了。
- **荣发核链**：两根出来就要走；后面是油资轮的不典型，老庄在涨上就已走。
- **国轩高科**：四天都是出货，后面增量资金（百岁山踏空的）接。
- **金融科技/东财（27→48→75）**：回踩一半37/35合理，无明确出货迹象，减半仓拿；N型没破，下一波必须破高点，否则双头放量见顶。
- **星期眼药**：三根出不晚，横住有承接（白线70.96），不典型。
- **军工票（94块，97亿盘子）**：提前见顶，套牢盘多主力不解套，今年没了。
- **康平科技**：大哥被套、呼吸好、完美图；涨停板上面卖一半，第二天不破最低价拿着；再来一根卖一半（避免跌2.7%+跌10%共13%没了）；12点几B1来接着抡。
- **野马/黑马**：B1起来连军上涨回调踩黄线往上，两根不算出货（看面积，没前面量大）；顺势而为 = 白线上+顶部没放量就别天天担心。
- **牛逼的票不让你操心**（队长走主升很流畅、顶部不放量、没人问）；"你不可能从30块拿到42块，主仓该卖就卖"。
- **作业展示**：萱萱72%、队长66.5%、发载48.3%、西叶37.5%、紫xx 415.8%（减仓减下来的）。

## 五、白酒渠道数据（独门分享，截至2025年8-9月）

> 一般规律：白酒企业三四季度开始回款，强势的从三季度回、一般依赖批的从四季度回。

- **洋河**：2025回款45%，经销商库存4个月（"从前开始不再进货，还得卖4个月"），回款压力大；新光瓶酒（42度/52度，找东哥代言，京东卖几百万瓶，线上直营绕过经销商）；基本面所有上市白酒里**最差后三名**。光瓶酒52度可对瓶吹、42度调成30多度口感入口顺。
- **金志源（国源四开）**：回款破50%，库存3个月（比洋河少一个月），改善会比洋河快。
- **舍得**：动销改善、库存下降，9月第一周开瓶增长，7-8月回款超50%。
- **青花（山西汾酒）**：省外回款65%，9月底全年回款80%、增长10%，库存3个月（"晋商主打守得住、风控强"）。
- **泸州老窖**：6-7月下滑明显，回款50%多，库存略小于去年。
- **五粮液**：批发价下跌倒挂（很多地方800块），回款50%，改善需要时间（高端贵）。
- **茅台**：批价1820，1935降到640，全国回款65%；死任务 = 市场价不破1800，不破则基本面正式见底。
- **水井坊**：全年回款不到10%（全年），7-9月还要下滑32%，全国最大经销商之一爆雷甩货（之前300多抄底景台现470）；外籍高管"不懂人情世故"。ST不至于（真白酒账上现金多）。
- **倒数三名（经销商数据）**：建南春、水井坊、洋河（都是四百党/中端）。高端遭不住但能扛，低端往上走扩大份额（抢占中端），中端（四百党）不行。
- **结论**：白酒没主升浪（没业绩没故事），是交易性机会+流动性泛滥的应对板块；顺周期观点维持四季度不变。
