## 正课：普通人如何跟上 AI 时代的浪潮

### 一、浪潮即人浪（框架起点）
- **"浪潮哪来的？人民就是浪潮，浪潮就是人民"**——所有浪潮一波一波都是人浪（看球赛的人浪）。
- 移动互联网时代的表现形式顺序：**先是硬件（手机/智能手机）→ 再转软件 → 最终落实到应用（APP）**。真正让所有人变成人浪的是「应用」——B站、抖音、微信、王者荣耀都是应用。
- 关键认知：**"目前完全没有到人工智能的时代"**，硬件基建还在初期投入期，类比 GPRS 畅想 3G；3G/4G/5G 硬件迭代了三代之后才真正进入移动互联网时代（短视频/长视频/社交/支付/电商到这才来）。

### 二、现在是"诺基亚时代"（核心判断）
- **"现在还是诺基亚时代"**——还没有一个真正的 AI 超级终端出来，现阶段还是嫁接在上一代移动互联网的智能硬件上。
- 现在像 **Sony Ericsson T68 彩屏时代**：诺基亚黑白屏 → 彩屏过渡 → 智能手机。已经"马上就要看到了，但是还没来，一切还都是故事，但是已经马上就看到了"。
- 标志性的"iPhone"时刻**可能（只可能）是机器人**，也可能不是——"在诺基亚最牛逼的时代，没有人会想到来一个 iPhone"。
- 哈萨比（Hassabis）说 AGI 2030 年彻底来、号召拥抱 AI；川又起了"Super 超级智能"的名字——名字都不重要，都是初级形态。

### 三、中美格局与"收费站"逻辑
- 中国在大模型层面与老美没差特别多（不像早期 GPRS/3G/4G 完全没有技术）；高通在美国买华为 5G 专利；**AI 软件圈华人比例非常高（AI 领域 70% 以上华人华裔，有些公司 90% 以上）**，硅谷 AI 公司融资看高管名单里中国人比例，少了反而不投。
- 逻辑已变：不再"老美出什么我们抄什么"，中国人是领先者，思考要从**人性**角度出发，而不是简单的 copy。
- 美国把全美未来发展和美国经济都**捆绑在 AI 战车上，下不来（他是第一，不能退）**；中国可以撤。
- **收费站（收费站=赛道收费口）比喻**：每个看得懂、足够大的赛道就是收费站，"把板凳码在那等着"。错过第一辆没关系（第一辆绝对看不懂/看懂也不敢重仓），**对自己的要求是第二辆、第三辆车上去**。例：电商赛道五次上车机会（淘宝/京东/唯品会/拼多多/抖音直播带货）。判断机会大小的关键=**叠加的人性越多、赛道越大**。
- NVIDIA 四波估值重塑：显卡（配件概念）→ 炒币挖矿 → AI 视觉训练 → 现在四处投 AGI/大模型换股，想赶最后一把。

### 四、人性七宗罪框架（正课核心，逐条对应）
师父以「人性七宗罪」推演互联网→移动互联网→AGI 时代的应用在哪诞生。七宗罪 = 贪婪 / 懒惰 / 色欲 / 虚荣 / 嫉妒 / 饕餮 / 愤怒。**"这些领域就是未来的收费战"**。

**移动互联网时代每条赛道已有巨人（历史复盘）：**
1. **贪婪（占便宜的快感）**：淘宝、京东、拼多多、唯品会、抖音直播带货、"什么值得买"、得物（毒）。核心逻辑=占便宜的快感（线下 1250 → 淘宝 500）；双十一/618。
2. **懒惰（能躺着绝不站着）**：顺丰、美团、滴滴、各种到家服务（快递/外卖/打车）。美团从团购（贪婪）切入外卖大战——**大厂一定占了好多人性，否则生意做不了这么大**。
3. **色欲（荷尔蒙流量）**：陌陌、探探、各类擦边短视频、Telegram、游戏。国内严管，但仍有这些；"商 K 算场景不算应用"。
4. **虚荣/傲慢（身份认同感）**：微博、抖音、小红书、朋友圈、网红经纪、直播（陈珍老师例）。"能展示与身份"。
5. **嫉妒（胜负心/比较心态）**：直播打赏、榜单、直播 PK、朋友圈、教培（公立/私立都靠排名）、游戏皮肤。
6. **饕餮（口舌之欲）**：吃播（早期直播平台靠吃播起来）、美团大众点评、米其林/黑珍珠（卖认证）。
7. **愤怒（对立/情绪出口）**：媒体（哪打仗跑得最快）、微博、B站负面标题（"在 B 站你起个负面标题就火"）。

**AGI 时代机会映射（师父按顺序推演）：**
1. **懒惰 = AI 时代第一大入口（最大）**：各种 agent（帮你订票/回邮件/报销/比价/客服）；未来变个人助理（法务 agent / 旅游 agent / 就医问诊 agent / 炒股 agent / 企业自动化 agent）。现在还没一个垄断者，赢家通吃，但"现在都在打仗，都是 story，全都是故事，不用着急"。大厂里豆包工作/腾讯 workbody/通义问办公，新兴 Kimi/minimax/智谱等。快递机器人=酒店机器人 1.0 升级到 AI 配送 2.0/3.0。**具身智能机器人未来能干日常功能。**
2. **色欲（应用最早，与军事并列）**：视频生成 AI 的第一大客户就是他们（就像运营商早期最大流量用户）；国内不合法的做不了，只能做**陪伴**——AI 陪聊 / AI 伴侣 / 虚拟恋人 / 虚拟偶像（永不塌房）/ 私人定制 / 面向老年人的陪伴 AI / **AI 红娘**（基于大数据匹配，AI 主动给你打电话，"喂这里是陌陌2.0服务机器人"就是线性了，一定要像真人一样真实才能商业化）。真假难分=说明 AGI 已超人工。
3. **贪婪（机会最大但监管最狠）**：不要从"帮你赚钱"角度想（AGI 若能让 99% 人赚钱，谁亏钱？市场无法存在）；**从"省钱"角度想**（拼多多就是省钱，省钱也是贪婪）。比价 AGI、全品类/单商场垂直场景。**金融公司真正的护城河=数据**——有垄断性质的金融公司（如东方财富有上亿股民行为数据）+ 蒸馏到上月的大模型 = 比通用大模型更准；大模型通用技术花点钱就能买来（无非蒸馏到第几代）。金融科技一定会有，但强监管+牌照，难成新大厂。
4. **虚荣（目前被严重低估的赛道，尚未看到明显的东西）**：AI 让你零成本展示自我（个人写真/朋友圈 IP 经营/数字分身出席活动/自媒体代运营）。目前只有 P 图（美图翻身）、生成图文，都是工具级撑不起垂直赛道。**真实社交反而更稀缺**（数字人直播泛滥后，真人直播/线下聚会变稀缺）。**人力/手工变稀缺=硬通货**（景德镇青花瓷、紫砂壶、手工鱼香肉丝=真正设置品，因为"当人力稀缺时，跟人力相关的所有动作是稀缺的"）。
5. **嫉妒**：会融合到各种 AGI 里，不会单独做；除非胡润财富榜/米其林这种平台级比较玩法。
6. **饕餮（滔天/暴食）**：物质过剩后，AI 营养师 + 智能烹饪设备（大锅/箱子扔食材一键出菜）；"猜你喜欢"升级版——AI 知道你今天微信钱包收了 300 红包，推荐你去吃心彩并配好车/菜。**想吃怕吃胖帮你都算好**；贾维斯式的"情绪监测指数"（看到你微信吵架/心情指数从 80 跌到 30 来关心你）。
7. **愤怒（情绪出口反向做生意）**：AI 吵架陪练、吐槽搭子、情绪发泄仓、AI 带打；反向做"情绪教练"（随身 AI 手表/眼镜感知你情绪、提醒+劝下来）；舆情管理公司（微博/抖音假评论、智能搜、渔情监控机器人）是现在初级应用，还很假，未来会逼真到看不出来。

### 五、"贾维斯"（Jarvis）概念与数据壁垒
- 贾维斯=整合你所有人性点的超级 AI。现在大模型"有贾维斯的智商，但没有数据"。
- **难的不是定位/算力，而是"如何了解你、如何懂你"**。数据打不通——豆包只有你抖音刷的数据（还一毛一毛打赏），没有微信/淘宝数据；B站/抖音平台数据互相不授权。**短期没有贾维斯**，因为需要打通所有中国互联网大厂的数据门。
- 类比量化评估：AI 红娘不难在定位（像评估股票，200 个因子赋权重评分很容易），难在基于数据的最准确推荐模型 + 沟通技巧。

### 六、硬件与机器人
- AGI 与硬件嫁接 = **机器人**，全社会都在聊但还没看到。**斯科（特斯拉 Optimus）机器人出来=第一代，像 iPhone1**，至少得几百万台先跑起来慢慢迭代；届时中国马上跟进。
- **光有机器人没有 AGI 没用**（苹果 Vision 眼镜买了没应用，2022/2024 年拿过两次再也没用）。
- SpaceX 加 X、XAI 高估值逻辑：美国第一，"你们所有人赚的钱，最终终端口在我这，我是风口"——机器人是最天然承载 AGI 的终端。

### 七、三个形成认知（总结）
1. **顺着人性七宗罪把板凳（收费战）码好**，待在赛道里，容错率高（AI 能嫁接所有行业，故事足够大）。
2. **解决 AI 时代制造的新问题的机会**：如何在人人用 AI 时判断它对错；数据安全/防渗透（做成即绝对垄断，类比 361/美国杀毒软件）。
3. **判断机会大小**：叠加人性越多赛道越大（王者荣耀=贪婪+嫉妒+愤怒+虚荣全占，未来一定是超大收费站，规模应达微信/硬死级）。

### 八、相关投资/大势观点（散点）
- 关注领先者 + 后来者（突然被美国收购的中国不知名公司 / 某 AGI 应用拿到巨额风投）。
- 机器人承载 AGI；银行/保险金融是 AI 的大客户而非被淘汰；中国烟草/茅台/1573 是"人中龙凤"offer。
- 三年前"卖车去蔚小理做销售"、一年前"跳新能源车" = 大机会来时普通人一定在车上，只是先上还是最后追。
- 3 句话：别羡慕老美（阶段不同）；要担心的不是美股创新高而是压跌——因为中国 3.5 万亿美元外汇储备、6000 多亿美元美债，最希望美国"硬朗活着"的是中国（"你欠银行一个亿，最不希望死的就是银行"）。
- 美股若像 2000 年崩一把大的，中国"先充分做好准备之后再谈"（类比 7 月 Korea 那波先限制申购再崩）。
- 数字货币：中国不会错过，但一定是中心化的（不会让你去中心化，老美也不让）。
- 人民币国际化/数字人民币基础设施在铺。

### 九、交易金句（散点，师父自己的）
- 大 A 盈利模式 = **"涨起来就卖，卖完揣兜里"**（折叠论：华为搞出折叠说明在中国还得折叠）。
- **大风游戏：在你最兴奋、最舍不得卖的时候卖掉**（类比国资委领导在汇报最兴奋时出货）。
- 社保必须赚钱，否则 A 股直接一千以下；你不是跟社保抢钱，是跟在后面减点。
