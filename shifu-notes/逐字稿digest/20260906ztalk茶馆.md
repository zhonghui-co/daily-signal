## 二、PB/PE 估值讲解（补上节课，P1/P4/P5 反复讲）

> 上节课（周三）讲过英超身价 vs 排名 = 估值，本场大量网友追问 PB/PE 没搞懂，师父补课。

- **核心比喻：** 全队身价 = 基本面（扎不扎实/牛不牛逼/有没有业绩）；排名 = price（高跟低）。**曼联身价英超第二、但十轮后排名倒数第二 = 实力被低估 = 价值被低估**（对应伊朗/阿富汗 = 基本面被低估）。
- 身价是市场给的（曼城花 1.4 亿英镑买恩佐 = 市场给的估值），"你关注的是它本身的价值对应它的排名，这只球队有没有被低估"。
- **科技类玩故事玩成长**（谁能把泡沫吹大）不看 PB 也不怎么看 PE；**老灯（老产业）严格围绕价值**看 PB 看 PE。微软/联想/戴尔/惠普从科技高成长 → 老灯 → 机油股 → 白马 → 往价值靠拢。
- **两个指标都是"分位最低 = 安全边际更高"**（相对安全）。
- **PE 一句话定义（豆包/Kimi 大模型版）：** 你按现在的价格买下这家公司，靠它每年赚的钱多少年能回本。适应率 10 倍 = 10 年回本，20 倍 = 20 年回本。**阿富汗电信 110 位置买入 = 2000 年回本 = PE 2000 倍**（2200 倍口径）。
- **PB 一句话定义：** 这玩意值多少钱（你兜里只有 100 块，别人觉得你有 1000 块，PB 就是十倍 = 被高估 = 风险，你得从此向所有人证明你能挣到十倍）。
- **PB/PE 都是越小越好**；PB 不可能是负数（资不抵债早退市了）。
- **分位数怎么看（P4 四条线）：** 四条线之间是 0-25%、25-50%，越接近最高那条线分位越低；卡到最高那条线"出去" = 泡沫（泡沫也分大分小）。"只要百分位超越一百，外面飞起来了，那玩的就是故事，都是风险，不用管是大科技还是小科技"。
- **只跟自己比：** 你兜里 100 块变 1000 块 = 身价涨 10 倍；王思聪兜里 1 亿变 2 亿只翻一倍。"你只跟昨天的自己比，看位置就行"。历史有严格平台（1000 块平台上三五年、蹦到十万级平台上三五年），始终围绕价值中枢波动。
- **足球比喻（P5，估值均值回归）：**
  - 天津泰达保级 = 基本面实力在，赛季初于根伟关系没捋顺，后面打回来了（均值回归）。
  - 成都（蓉城）大白马：一直 45 度领先，中间五连平/横盘但"没有 A 杀"，因为基本面（身价/砸钱）在那；遇到河南（赫南）这种跟你较劲死干的空头，你也很难被砸出大阴线。
  - **董小姐（一路第一的大白马）= 赚不到钱**：从第一轮就赔率摇摇领先，买冠军不赚钱（都看得懂、走成预期）；要赚估值修复的超额收益，得等它出现估值偏离（开赛五轮三负两平排倒数 → 赔率下降 → 才有回报率）。
  - 泰山（鲁能）不稳定起伏 = 基本面不稳定（这季度毛利大涨下季度莫名其妙亏损）= 看不懂不做。
  - 联赛最后三轮、谁都不想争第二（争第二要打亚冠是负担，只有大连想打）→ **引申：定向增发价格有人想做高有人想做低**（大股东想增持就把价格压着，所以券商在相对低位完成并购，不可能在最高价并购，成本太高）。

## 四、阿富汗电信"做局故事会"（P2/P3，核心寓言）

> 用阿富汗电信 IPO 讲"一级+二级联动、把代表国家意志的超高溢价上市标的"的整套运作思路。阿富汗 = 中国、阿信证券（阿富汗信托证券）= 中信证券式券商，阿富汗电信 = 中国某电信/创字头标的。

- **背景设定：** 战后 10 年计划，阿富汗电信是国家级战略（让山洞里群众都用上 2.5G），国资只占 20%、其他 80% 要发动群众/土豪/华尔街财团。
- **IPO 首日：** PE 200 倍、定价 10 块。阿信证券背后的华尔街技术团队从敲钟第一秒开始直接顶上去，10 块 → 50（照单全收 + 市场自然换手），半小时后全球传开（自媒体 release），50 → 110（伊朗/日本/俄罗斯/土耳其/沙特资金涌入）。
- **当天操作：** 在 110 把早上 10→50 接的筹码全放掉当天回笼，尾盘快收盘打到 70，最后一刻"登登登"顶回 108（想省钱没顶回 110）。**当天倒来倒去没花钱**，一级财团和护航券商在 90/100 甚至 70 就开始卖。全球散户接盘。
- **2200 倍 PE = 从三国时期开始赚到现在才能对应价格**；"已经完全没人控盘了，如断了线的风筝上面飘着"。
- **110 的点叫"仙人指路"：** 在任何一个国家证券市场打开任何一个标的（含大宗）都先看**最高跟最低 = 空间**；只要基本面问题不大，最后都能把空间用满；"空间也意味着时间"。按玄学（无理论）概率**大于 50%**，第一天的拉出空间的点位，只要不崩不退市不瞎逼闹、时间足够长，就是给后人定下的空间（锚点）。国家垄断买卖 20 年后不可能不赚钱。
- **回归路径：腰斩再腰斩再腰斩三轮**：110 → 55 → 25 → 12.5（八分之一，跌百分之七八十），再从下往上 12.5 → 25 翻倍（有梦想）。
- **后续演绎：** 阿富汗电信作为"气氛组标的"为阿富汗石油/光刻机/钢铁/同业造势（都高溢价上市）；EPS 从一分钱变两分钱业绩翻番 → 股价 12 块 → 25 = **第一波翻番 = 大哥建仓**（信托证券自营盘 + 相关老主舱）；25 → 30 → 回 17/18 → 通货膨胀一波平稳上 50；50 处 **S1 双头 S2 大放量大换手**跌到 35（S1S2 放量两根 = 100 块位置套牢盘割肉）；**财政绑定接走**（阿富汗保险/平安、银行/农业银行/星业银行/起飞银行，规避经济硬着陆）；放水降息十万亿 → 2 个月从 50 蹬到 111 创历史新高填坑；花旗/高盛/大摩给价格指引 200/250；第二天跳空 **121**（过前高 + 10% 鱼量）高开低走大阴线历史巨量，自营盘把 12.5-30 筹码倒给全球投机资金；"Money never sleep 金钱永不眠""能让你信一次就能让你信两次"；中资宣布 90 块位置参与增发等利好全来 → 再跳空高开下杀放量；120 → 回调 60-70 → 反弹 90 → 再杀到 50 结束。

## 五、中美定价权博弈（P3/P4）

- **高盛跌 70% 中国也买不了：** 中国 3 万亿外汇储备，但"不是你想买想买就能买，你得是跟人家站在一起的"（站队问题，发钱的事轮不到你）。
- **小米人车生态比苹果立体，但价格是苹果的 1/20 甚至 1/30**——"人不认可，人不给你定价，人给你砍价"。背后是华尔街全球定价权 + 美国全球第一货币。
- **比亚迪想卖特斯拉价格卖不了**；"美国精神全球定价，从小到大你看的就是美国人的东西，你喝的就是可口可乐，你就卖不了这价格"。所以中国企业出海南南合作。
- **历史账：** 过去一百年中国人一件东西卖 100 个钱赚 2 个，人赚 98 个；你从 2 块赚到 4/10/12，人家从 98 降到 90/80/75，资本优势依然高出很多级别。只能时间 + 弯道超车。
- **华为车机垄断利润：** BBA/大众每辆车用华为车机 = 垄断利润，一台车机先要你 2 万、4 万你也得给（类似苹果 iOS 垄断利润）；美国/日本/德国企业赚这钱赚了一百年，你刚赚第一年（X23/X5 还没上市）。定价权是一整套（时间 + 空间）。
- **大疆上市都难定价**（终端零售用 Windows/苹果系统，背后体系能给你挖出来收 20% 税钱）。
- **元朝苏玛丽青瓷器全球共识**（成吉思汗打到莱茵河畔，欧洲人服）→ 定价权 = 谁都不服弄你。
- **哄着玩论：** 特斯拉不能倒（新能源车教育市场，特斯拉倒了欧洲人说"美国的车都倒了中国的能信吗"），斯克得接着玩 cyber；Nike 不能倒（AJ 得继续出到 AJ50，否则李宁韦德之道/库里进美国，美国人直接不玩了，NBA 从第三运动掉到第七第十，Nike 之前是阿迪的、德国资本玩不了美国核心资产最后交到 Nike 手里）。
- **以彼之道还施彼身（P4）：** 美国要加息抽全球流动性，中国先住 1600 亿资本金 + 保险 570 亿 + 2000 亿（"我还没做呢你他妈就一千弄了"）。美债筹码在日本/英国/中国手里，日本一卖咱们跟着卖 → 美债崩 → 美股崩 → 全崩（不希望看到，还得护着盘）。中国有高人试时提前部署 = 家长制帮很多人避了大险。
- **国人唯一能干的两件事：** ①跟着国家走 ②认识黄大哥（黄线）/白大哥（白线）= 散户唯一自救/喝点汤的方式。

## 六、结尾交易心法（P7/P8，重点）

- **不要有牛熊思维/择时思维**：A 股核心逻辑（23 年讲过）永远就是"拨断"（波段），无非长点短点，等着就行。
- **两个策略（现在这种环境下）：** ①休息 ②集中优势兵力打一个你最了解的（但太难了）。
- **伊朗市场踏不了空：** "凡是能让你踏空的就不是机会"；一波流谁都赚不到钱（一波流是气氛组给你看的，不是让你玩的，赚谁的钱）。
- **击穿对手盘：** "只要扛得住就不是击穿对手盘，只要扛不住那就是击穿对手盘"（洗到没人为止，他是互动的，洗不走就往下再来一根）。
- **梁文峰今年快进快出也亏钱但亏得不多**（因为尊重准率）。
- **能力 + 概率：** 要时刻调整最适合自己的策略。巴菲特美股年化不到 20%（18% 多）；博尔特百米 9.58 秒（世界最快就这人了，14 亿人没被埋没）；库里命中率 54%（不可能每球必进，投进的次数比丢的多才是球星）；梅西/C 罗射门是射出来的。
- **Plan A/B/C：** 不要只奔一个 Plan A。
- **地产理财例子：** 2022 年前银行 R1/R2 理财每年 4%-5% 收益，都是贷给地产公司发展起来的；不要过度关注哪笔坏账，跟着大趋势走。
- **中国教育 = 应试思维（现象思维）vs 思考型：** 大部分人只会做题不会思考；老外精英教育是开放性的"why not / 你想办法"，咱们是"别想办法，按这这么做"。（但外国底层傻逼比中国多多了，老外是精英教育，咱们是反过来——底下都精英、筛到最后是人精。）
- **不要怕踏空：** 怕踏空 = 还是有钱/不服/不信。"凡是怕踏空的就他妈抡，因为市场会教育所有人"。你要接受左侧崩击一轮后 3%-50% 的浮亏（这是你怕踏空做决策的结果之一）。
- **别把脉冲最高收益率当平均收益率：** 前年 300% / 去年 40% / 今年 -20% / 明年 0%，四年平均就够了。巴菲特 20 年年化 18%，也不是每年 17/18/19。"新人散户老爱把某个时间段脉冲的最高收益率当成平均收益率，这是老是不服的原因"。
