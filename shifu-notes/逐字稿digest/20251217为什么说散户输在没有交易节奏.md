## 二、核心框架：交易节奏 = 四节奏

交易节奏定义：**你在盘面上体现的入场点、离场点、持股依据、策略安排、持股心态，多方因素构成的持股节奏**；本质是"你参与这个市场、跟市场的关系"。

四个节奏：
1. **市场的节奏**
2. **板块的节奏**
3. **个股的节奏**
4. **自己的节奏**

四节奏**共振**才能赚大钱。反例层层递进：市场看对了（大A 3400→4000）但板块节奏没来（拿白酒/中免不动）→个股看对了但选错股（拿五粮液跌10%，人家三六零涨70%）→三个都对了但仓位不对（50%在赛赛、1%买Rita、1.2%买航天发展=自己的节奏没跟上）。

**高手不怕踏空**：踏空=你在众多能驾驭的机会里没按扳机那一次；你专门打的就是这种鸟。认为"航天发展踏空"=没入门（Rita完了又是航天发展，学会找下一个就行，无所谓）。

## 三、两个前提：资金规模 × 盈利目标（KPI）

找自己的节奏前，先加两个前提：**资金规模 + 盈利目标**。这是"多大屁股穿多大裤衩"。

### 盈利目标 KPI 表（对应资金规模）

> 注意：师父明确说"这不是2025年盈利目标，是你自己最理想的节奏追求（target/KPI）"，不是"没完成就枪毙"，是"从这数做到那数"的目标。

| 资金规模 | 盈利目标（KPI） |
|---|---|
| 10-50万 | 70%（汇总口径"十到五十 百分七十"；⚠️第一次枚举口误说"50以下…10到50"，后文汇总修正为70%，存疑标注） |
| 50-100万 | 50-70% |
| 100-300万 | 30-50% |
| 300-500万 | 20-30% |
| 500-1000万 | 10-20%（**最难做**：规模不大不小、波动不小、没信息优势没认知优势） |
| 5000万以上 | 只设底线，>无风险收益率（国债1.5%/理财2%，做到1.8%以上即可），**不设目标，盈利目标市场给你定**，核心是防风险 |
| 10万以下 | "没意思，别玩了"，翻倍也没意思（忙一年赚一万难受）；若玩必想翻倍 |

### 关键原话与数据
- "规模越大，盈利目标越要变小，越要考虑防风险。"
- 5000万账户：一个跌停=500万；涨1%=50万（一辆奔驰）；涨20%=1000万（"你这辈子都挣不到一千万"）。
- 5000万在市场上"还算一小机构"，小机构对收益率要求都没那么高。
- **摩尔（沐西）75亿买理财，2%=明年年报扭亏为盈**。
- 越大的资金赚的是**确定性**。
- 一万倍：纯命，没方法（除非老八股上市第一天买且不退市，或巴菲特美国常年长牛，或再来一遍比特币）；巴菲特放A股也拿不到那业绩。
- 机构今年已赚20-30%（指数增强ETF到十月23-25%就抡出来），险资私募出来公海止盈——因为市场给了"远高于无风险收益率"的利润。所以最近两个月大资金都在套现。

### 目标决定行为（核心）
- 20万账户 + 明年市场涨1000点（慢牛）：想赚70%翻倍"很合理"（涨1000点还没翻倍就没必要）。市场没给节奏就是另一回事。
- 10万以下想翻倍：每个票重仓单抡、快进快出，跌2%换票3%，赶一两个20%就上去；翻倍后"八十收手"一年不干——守住后面8个月，否则本金5万变3万。
- 100万赚30%：台子（茅台）任何一次周B1抡进去，明年总有高点反弹30%，到了就走。
- 想翻倍：100万分2-3份去抡科技里波动率大的票。
- 1000万三年赚30%（每年10%）：宁子（成本13-14，反弹到19.2/19.29又到前期高点，给20%确定性机会）。
- 德州扑克比喻：10万玩德州一晚上10万→100万（10倍）是"相对正常收益率"；新手目标是"只输10万"；会玩的赢20-30万翻倍；连续4个月冠军的目标至少10倍。
- 外面散户80%亏钱（大盘从年初3400涨到3870，散户是亏的），把前几个月利润亏回去——因为没交易节奏。

## 四、市场的节奏（看两点）

### 第一点：资金面——货币宽松周期 vs 紧缩周期
- 康波周期背后=美元周期=货币周期（美元是全球货币）。
- 美股过去十几年牛市：从2008经济危机→2009年QE开始，疫情印钱发钱延后QE，通胀后要缩表，缩表不行又降息扩表。
- 大A现在是**宽松周期（双宽：适度宽松的货币政策 + 更加积极有为的财政政策）**：钱没地去，大钱找舒服位置慢慢蹭进去（"大钱的节奏不是4000点"——大哥4000点进，过去一个月回调工作就丢了；私募大佬新发2亿产品在3900-4000进，两个月难受）。
- 宽松周期下："要么在高铁上别下车，要么一只脚在高铁一只脚在站台"（不知道什么时候瞪一下，就像今天下午这根）。
- **盯双宽转换**：双宽从"适度宽松+更加积极有为"转成"稳健财政+稳健货币"=进入紧缩周期，就收手不玩了（一切上涨都是反弹，容错率极低）。紧缩周期玩法=玩个股节奏（后期教）。
- 港股率先转宽松（港府先松手，给A股打样），所以2024年开始聊港股机会。

### 第二点：走势面——上涨 / 下跌 / 横盘
- 现在大A=**横盘区间（宽幅震荡）**：3800踩了几次=底，上面顶3900-4000，就200点（"上涨顶下涨底"）。年初3400→现在3870，一年才470点，不是3000→4000的一千点。
- 横盘区间策略：结合活跃市值，**只卖不买、仓位50%、一半一半、拿住不动（慢城阵容）**，低吸高抛；**邓家就卖（蹬家就卖：涨起来就卖把钱揣兜里）**。
- 科技：N型找低点反弹横盘；半导体ETF从10月9号后除指数贡献票外没有高点。
- 左侧入场时机：上证924之前7月下跌趋势、市场相对低位（高点3731跌好几年）可左侧买；高位票（如赛赛）越来越买没依据，要做右侧、破黄线止损。
- 宽松周期下的大策略=**指数贡献**（涨的还是大指数/华泰证券、中天等）。

## 五、板块的节奏（三种阶段）

板块节奏只分三种：**无人问津 / 人声鼎沸 / 主升阶段**。

- **地产**=无人问津（不碰，"动不动给你弄一根很难受"）。
- **白酒**=无人问津（不抱不切实际幻想，做左侧，降低目标收益率）。
- **新能源车（含固态/新能源）**=人声鼎沸，正往无人问津转。
- 飞龙在天→康龙有悔（亢龙有悔）→潜龙勿用→剑龙在天（利见大人）。

### 量化判据
- **无人问津**：成交量缩到最高时的 **1/4**（约=阶段底部）。缩到1/3-1/4就算缩到位。
- **人声鼎沸**：放天量后**偏离白线和黄线**；两个观测指标=①斜率特别高（股价大幅偏离白线黄线）②放量天量。
- **主升阶段**：白线之上上涨行情都叫主升。

### 买点铁律
- **"买在主升阶段里的无人问津（顺大势逆小势），人声鼎沸不要碰。"**
- 人声鼎沸不追；黄线附近入场=高手（不是顶就是底，博盈亏比）；跌到黄线沿黄线进相对好。
- 煤炭：连续顿起来偏离白线黄线=人声鼎沸（进了一根就杀你）；现在放大量又到无人问津。
- 卫星/航天ETF：主升阶段（斜率看），成交量有点人声鼎沸——**不能空也不能追**（斜率太高偏离白线太远），等拐下来（没跌破白线/黄线）位置=好的入场节奏。
- 半导体ETF：上升阶段的人声鼎沸，只要上升阶段没完，来B1缩量低量=上升阶段里的无人问津，**赌一把**。
- 补量：放量高点后量不够（跟前面比）必须补量，不补量就见顶结束。
- 铜（有色）：主升阶段里的人声鼎沸和无人问津之间徘徊，主升阶段就拿着。

## 六、个股的节奏（四种波）

个股节奏=**建仓波 / 拉升波 / 冲刺波 / 垃圾时间**。

- 商业航天：板块无人问津→个股被亮住→缩量到B1→有人进（建仓波）→B1进=主升/拉升波→简单洗盘→冲刺波结束。
- 瑞达期货：建仓波→拉升一半熄火→再拉→没天量→后面可能还有冲刺波（马上给还是再等不知道）；长阴短柱位置难判断见顶。
- **判断个股节奏不看股价看成交量**（没放量=没走完）。
- 360（三六零）：3.22、昨天5%，周日就画线苦口婆心说别干，"活该"；缩量骗人，几门中炮必须快速起来，不冲一律骗炮。
- N型判断：破低点再反弹不破高点、跌破低点=转震荡向下（N型向下）；现在是N型向上（没破高点也没破低点，画两根线变区间震荡）。

## 七、自己的节奏（本课重点，四类+空仓会儿）

### 四类节奏
1. **自己擅长（持股时间维度）**：长线 / 波段 / 短线，自己要有概念。
2. **满仓**（仓位维度）：师父现在就是满仓（一年多拿住不动），"满仓是我的tempo"。
3. **底仓+动态仓**：新手建议50%底仓+动态仓，伺机而动。
4. **动态仓**：两万块钱就动态仓（不用配置）；动态仓=打野仓、一秒满仓一秒空仓、短线仓位；短线买到波段好位置就等涨停拍一半（50%→25%）转波段仓；找感觉花一万买一个票"吃猴（试仓）"。

- 从满仓→底仓+动态仓→动态仓，是**资金规模从多变少**的逻辑；反过来两个亿天天玩动态仓=游资。
- **空仓=会儿（赖子/百搭）**：不属于任何一类，但适用于任何一类（长线/波段/短线、满仓/底仓+动态/动态仓都可以切空仓）。
- 长线也能动态仓（满仓茅台，周线高大复值拉升时放飞、钩大复值买回来）；波段也能满仓/动态仓。
- 每个票要标注自己的节奏（复盘时写下来，如"宁子=长线里的满仓"）。**不要老变**：短线做拉升波不止损漏下来变底仓=傻逼；长线看好票不涨进垃圾时间拍在第一低位然后骂=也不行。

### 关键个股节奏标注（师父口述）
- 宁子（李宁）=长线里边的满仓；目标35（34.8至少开始减仓）；19-24不走，35叫；做17→34一倍（"死等拿住不动"）。
- 队长（腾讯?）=长线满仓，17→688→现在600，看1000；队长还没开始讲AI故事。
- 米儿=长线（AI故事还没开始讲）。
- 发载（发债）=长线满仓（可能100%满仓，也可能是1/10仓位里的满仓）。
- 88=右侧短线（没成本优势，破止损就走，做紧一点）；周线B1可以赌，止损设N型低点（148；152买/146止损）。
- 大A从来都是波段（券商：大哥来了站上黄线缩量到B1缩进去，起来到S1走）；**"大A没长线，拉起来一把就走"**。
- 港股=长线满仓（大科技，这波核心主线是科技）。

### 止损铁律（重要）
- **止损看日线，不看周线**：B1买入当天那根K线低点下面3-5个价位设止损位；日K买只输一根日K。
- 周线B1看周五收盘，但止损价（N型低点）看日线。
- 短线跟波段入场后任何B1一定要止损，盈亏平衡点也一定要出来（节奏不一样）。
- **长线没有盈亏平衡点**（盈亏平衡点只对应短线/波段）：长线=买相对低位拿住不动看目标位（填坑或目标位），宁子三年750个交易日中间任何一天没意义，第750天当天蹬70%都行；免子56以下越低越买、台子1400以下越低越买。

### 资金规模案例拆解
- **10万**：目标70%（50-70%）；A股做波段，波段+满仓，放飞=底仓+动态仓；分两个票（4万+4万+2万备用打野不打满，练习期双线战法/少妇战法）。
- **2万**：短线+满仓，一个票。
- **100万**：配5个票（每票20万），目标30%（三五十合理，底线30）；20万一个仓位，长线满仓宁子等35+长线满仓队长等1000=40万底仓不动（市场节奏没变、双宽没转紧缩就不动），另外60%做A股波段+港股长线动态仓（巴巴成本高140-150→长线动态仓，B1进不涨止损出，周线B1再进日线止损）。
- **200万**：30%=五六十万；慢牛上摇顶下摇底，配无人问津主线（科技/有色/资源），长期横盘后周线B1或起来后周线B1/日线B1，A股波段+满仓；配港股恒生科技随风飘荡；个股找建仓波/拉升波/冲刺波，别垃圾时间干。
- **5万**：单轮。
- 88止损案例：152买/146止损，破马上止损出来，亏5个点，20万仓位亏1万（100万只亏1万=试驿仓）。

### 输得起的钱（风险纪律）
- "玩A股所有投机性质的东西，一定只拿自己输得起的钱玩。"
- 10万是你半条命（20万存款）就不该拿10万玩；最多一个跌停睡得着觉=5万或3万（3万一个跌停3000=半月薪水）。
- 20万存款拿2万玩练两年，2万做到4万再本金加到10万；2万做不到4万，给100万借4倍杠杆也赌不着。

## 八、实战案例拆解

### 航天发展（本课"龙头"样本）
- 咱家最后的大牛；上周三讲成交量"按成交量航天发展没完，后面大概率创新高"，昨天创新高；今天才来一根6%。今天权重回来龙队入场，商业航天没准见顶。昨天创新高了但你哪个位置进去、舍得卖吗，不卖今天锁你6个点。
- 航天发展=军工板块无人问津 + 个股完美建仓波 = **领先市场做出的龙头**（Rita同理，券商期货没起来时看到Rita建仓波干B1）。

### 段永平（节奏的极致样本）
- 40岁退休；节奏赶上"货币宽松周期下跌尾段"（美股纳斯达克崩掉，网易1美金以下）+板块=中概股互联网股无人问津+个股=网易垃圾时间，进6个月20倍，长线满仓（足够便宜所以长线满仓至少赚一倍）。
