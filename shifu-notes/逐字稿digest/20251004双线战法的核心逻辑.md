## 一、开场三个率（会议"听话听音"，重要铺垫）

国庆会议发布会，师父回看后拆出"就说了三件事"——三个率：

1. **波动率 = 监管层 KPI 考核指标**。领导说"十四五期间 A 股波动率大幅降低"。→ 结合"上要顶下要底、一个月一百点"，除非极特殊情况（如4月7那种），否则一直沿着上要顶下要底持续，直到达成慢牛情境。跌了敢买、涨多了敢卖。
2. **分红率 = 低波红利策略**。"过去六年低波红利翻倍了""A股分红率达到历史最高水平"，本质是"财政逐渐跟股权绑定，他能够坑你但他坑不了国家"。未来相当长时间低波红利都是重要策略。什么都不会就跟某队/国家/财政在一起，买每年分红 5%-7% 的（"10年人股权像白送你"），长线，不看股价波动。
3. **航科率（科技含量）** = 科技市值体量已超银行/大金融成 A 股第一。→ 科技永远是第一主线，AI+ 各种（"美帝做机器人→格力也做"）。

## 二、双线战法的定位与基础

- **双线 = 少妇战法的下一代 / 升级版（pro 版）**。少妇战法=单线战法=标准版（BBI 单线），双线=pro 版，后面还有 ultra 版（纯看线做，以后教）。
- **少妇战法适合**：震荡市、熊市末期、震荡市（做得快、敏感，白线/BBI 上一两根就放飞，只看 BBI 形成的短期趋势，不看中短期趋势）。
- **双线战法适合**：第二牛市第二阶段、增量资金越来越多、走势越来越流畅的强趋势行情（更立体、稳定性更高，"加了个维度"而非单纯加条线）。
- **三个基础：** ① N 形结构 ② 顺大势逆小事 ③ 少妇战法（BBI 单线）。
- **黄线三点定位（必须记）：**
  1. 主力是否入场的**标志性参考线**
  2. 拉升前**极限洗盘的极限位**（"你最害怕的时候你给他拍了，拍完蹭就起来"）
  3. **大哥控盘的成本线 / 盈亏线**（"主力建完仓之后一定要真实下杀跟洗盘，才能把跟风盘洗掉，但他往往不会跌破自己的盈亏线，而黄线就是他的盈亏线"）
- **黄线"接近61线但不是60线"**。

## 三、双线基础用法

1. **右侧交易只做白线在黄线上的票。** 股价在黄线之下不看；白线在黄线之下也不看（"没有意义，这段时间做就是浪费时间"）；只有"股价打上黄线 + 白线往上金叉黄线（白线在黄线之上）"才具备可操作性。
2. **左侧看估值，不看线。** 例：李宁每股净资产 10 块跌到 11 块 = 便宜；榻子每股净资产 25 但价格 50 = 贵。
3. **短期放量站上白线** → 结合形态判断是否具备上涨爆发力。连续拉升后回踩白线 = 第一支撑；破掉 = 短期趋势大概率走坏（牵牛绳意义）。破白线全清（"卖点对应买点，这是交易纪律"）。跌破后又出 B1 = 另一笔新交易。
4. **黄线之下无右侧交易价值**：黄线之下上涨都是反弹，不用做；白线黄线之下起来"特扑了"也没意义（高点连续降低的向下 N 型拿不了）。
5. **横盘震荡区间**：白线黄线操作概率优势不显著，需切换成顶部压力线 + 底部支撑线评估买卖（例：赛赛 140 顶 / 115 底，"拿锯不动"）。

## 四、双线核心玩法（重中之重，三个）

### 玩法1：白线金叉黄线 = 上涨趋势确立的概率大，等回踩 B1 入场
- **重点词"上涨趋势确立"**（不是"一定涨"）。放量后白线站上黄线之上 → 上涨趋势确立概率大 → 等回踩 B1 入场。
- 周线不适用。港股成交量/流动性不行，基础指标经常失真，港股做估值（如美团）；美股流动性强、可以用这套（尤其高大复值）。
- **"大傻子玩法"**：金叉买、死叉卖、中间不看，一直拿到死叉。
  - **好处**：任何周期、任何图形、任何行业（有色/指数/任何行业）都能吃满波段，肯定不踏空。
  - **缺点1（掐头去尾）**：只吃到中间波段，效率低。例：半导体区间涨幅 23.51%，但账户曾浮盈 50%、回撤一半；上证最高 3899、死叉回 3600。
  - **缺点2（震荡行情会亏）**：0.795 金叉进、0.718 死叉出，亏 11%。
- **大资金/机构赚的就是"掐头去尾"的钱**：看好估值低就敢抡（"前天涨17%我第二天接着敢抡进去，先站岗一个月回撤10%"），不精挑 B1/S1，因为资金体量玩不了那么细。
- 战略价值：连白线黄线都没站上去的票，毫无确定性、无交易价值。

### 玩法2：白线死叉黄线 = 最后离场时机，走错也要走
- 对应玩法1的买点（买点 A 对应卖点 A）。
- **白线跑到黄线之下 = 主力完全弃盘**。
- 案例：深期粉酒/青花 205 跌破 205 就撤，"188 不走直接一波干到 164"；新前锋金叉 31 死叉 27（一股亏 4 块），"不走直接连续两根，一根跌停又往下"。
- **盘面语言（重要比喻）**：白线站上黄线 = 麒麟会/主力"赌场开门"（名盘，大家一起玩）；白线在黄线之下 = "赌场关门"（风声紧不玩了）。
- 死叉出现 = 至少中期趋势结束（长线另说）。

### 玩法3：白线黄线"要死叉而未死叉"时，N型结构不破 + 勾大复值 = 极限买点
- 买进去"要么超压一大底，要么只输一根赶紧脚底抹油走"。
- 案例：宁德时代——大哥来了但量不完美（"大哥没买多少，只是抄了个底"），等 B1，回调一半（大 N 型结构）看一半 → 极限买点 → 一鼓作气上去。
- **成功率很高，尤其大票、流动性强的票；小票一般**（小票主力好划线）。
- **资金量越大、成交额越大的票，技术指标越有效**（因为划不了线）。队长（港股）每天两百多亿所以适用；港股创新药每天几百万几千万随便画图所以不适用。

## 五、最核心（今天重中之重）：N型上涨趋势中，白线与黄线区间的位置 = 容错率相对较高的买入区

> 原话："N型上涨趋势中，白线与黄线区间的位置，都是容错率相对较高的买入区。"

- **不用追求勾大复值**，只要"碗稍微大一点"，白线黄线区间内**任何位置都能买**。
- 前提是"白线已金叉黄线 = 趋势默认已经形成"，区间内慢慢买，无非买多买少。
- **黄线设止损**（区间上方买套几个点无所谓）。
- **布林带是走出来的（没用），这两根线是加出来的（拿钱画出来的）**——从未聊过布林带玩法。
- 案例：江铜区间 27/26 差 5%，分批 1万1万买；"10万一个仓位，这天买1万、这天买1万……3万会吗，崩上去了拿着3万也赚钱"。
- **横盘不适用**（大哥没来、没放量）；N 型结构才适用。
- **开口太大不买**（例：乔丹区域太远"不买，真要买等打黄线"）；加速后冲刺波不看了（"最后冲刺波之后不看了"）。
- **区间宽没有量化标准**（"每张图不一样"）；加速回到区间内就很宽。
- **大赚小亏**：十个票四五个大赚、三个小亏拍掉。
- **倒金字塔加仓禁止**：总仓位固定（如10万），分批买到全仓后就"只卖不买"（"别从10万一下加到20万/50万"）。加仓纪律：本金10万最多加到18万，确保一根跌停不破本金（10万赚到12万有2万浮盈，最多加仓到20万，保证市场一根跌停不破本金）。
- 与五种出货方式联动：阶梯量、边拉边出、压着出 = 出货图不买。

## 六、放量金叉后缩量回踩黄线 = 交易价值非常大（连续拉升前最后震仓动作 / 震仓点）

- "往往是连续拉升或快速拉升波的启动点"，即"承诺要讲的震仓点"。
- **越牛逼的主力越在这个位置珍惜筹码、挣扎，特别逼人**。
- 案例：
  - **香财**（踏空案例）：打到黄线，黄线第二天能收回来就不算破（要容错率）；第一天跌破黄线看第二天能否拉回来；第二天没拉回但趋势形成可设止损。性质是 SB1（钩值没到 SB1 但性质是极限洗盘）。
  - **中科/稳定币**：7月底8月初大盘调整打到黄线直接主升。
  - **四汇/富士、中晒**：放量缩量一直缩量下来打到黄线。
- **长阴短柱 = 缩量阴线都是洗盘不用怕**。
- 比喻（射门抡腿）：任何趋势要走必"回来"踩（后摆/后摇不可避免）；"发哥"案例——机构买不形成主升浪，因为白线还在黄线之下。

## 七、循环操作法（应用题/综合）

- **在上涨 N 型趋势不破的前提下反复轮：**
  B1 买入 → 白黄区间买满仓位 → 脱离成本区放飞 → 某天跌破白线（可减仓，但若没出货可加回来=下一笔交易）→ 反复轮。
- "跌破白线卖出、第二天开盘再买回来，不能跳步，一步步来"；脑子够用也可"接上买"（两笔交易合并，但本质是两笔，不是同一票倒金字塔加仓）。
- **得碰到牛股才能反复轮**。
- 案例：八一钢铁（量化模型选出）——B1/B2 都可，8.34 B1 可干（放量缩量放量缩量图形完美）。
- 中闪：5.65 金叉买，8.84 死叉卖（"玩大的"，牛市结束）。

## 八、死叉 / 死差多的补充口径

- **死叉时，如果前面有 N 型结构低点，可以稍微再等一等**（N 型不可能那么精准）。例：中闪死叉前有 N 型低点可等；青花"没有等的必要"（已经跌破）。
- **死差多（要死不死）极限买点的两条触发口径（加一句）：**
  1. 配合勾大复值（原口径，没那么精准）；
  2. **或"站回黄线之上"**——"只要它站上黄线了，不用考虑下面的勾值，意味着这口气上来了；站上黄线后（如7根）都不卖，跌破黄线再卖"。
- **带量长阴 = 真出货**（不管什么盘子都别侥幸；小盘可带量跌停对倒但没意义还交手续费）。

## 九、双线 = 三维（升维）

- 白线 = 一维；勾 = 一维；加黄线 = 三维。变三维后看二维世界视野就不一样了。
- 以后任何牛股，不用纠结"没有完美 B1"，只要"进到碗里了"就无所谓，剩下的是"你能不能拿得住"。
- **拿不住是散户赚钱的决定性障碍**："所有的大钱一定是拿住不动做出来的"。例：券商 ETF 17 个交易日才跌 2.69%，占十分之一仓位只回撤 0.3% 都不到，散户还是受不了拍掉，后面那根就吃不到。
- 放飞规则：碗大就慢慢放、十分之一放；碗小就二分之一、三分之一放；碗特别小就全卖。

## 十、指数贡献 / 入阁策略（额外送的"小自食"）

- **每年只等一到两波赚钱机会**：每年调整沪深300 / 上证50 成分股（"越往大市值调"）时，把这些票放进自选股，一路下跌之后，只要"白线站上黄线、放量、大哥来了"，就跟着 B1 入场，基本都能赚一波。
- **每个入格的票，入格后半年到一年内，三五十个点的行情是确定性的。**
- 机制拆解（韩王/寒武纪刚调进沪深300时是当时阶段最高点，很多人骂"最高点掉进去"）：
  - 刚入格拉到高位 = **表态 / 投名状 / 买门票入场券**。
  - 指数基金是**被动配置**，必须配、没法挑位置 → 高位时"不用让散户接盘，让基金接"（有对手盘）。
  - 大资金接完被套 → 散户互相踩踏下来 → 之前做那波的大哥重新入场做指数贡献 → 一把登起来（"知道你指数基金不会出货，买完拿住不动，只要有人买你还得加仓"）。
- 案例：赛赛（赛力斯）入格确定性，后面再来 20% 到 180 以上（第一募交价约 186/183，现价 171）；当时一根外盘是"指数基金被动配置当天建仓"，麒麟会不让涨洗了 8 个交易日，后面无量（筹码被指数基金锁仓）。
- 辨识度/纯血逻辑：指数贡献要"全国人民都知道、都能看懂"的龙头（赛赛只有问界，明儿三块业务=手机/汽车/家电，泽泰兰科=高科技运动鞋最纯血）。纯血≠更有优势，而是"更能看得懂，大资金爱做（因为出货方便）"。
- 三缩选股方法（预告，未教）：三根缩量阴线横盘缩量 → 未来教。B2/B3 没教过，别自己乱做（"不是所有的盒都能酿出茅台的味"）。

## 十三、成功/失败案例拆解

- **香财（踏空/震仓案例）**：放量金叉后缩量回踩黄线，第一天跌破黄线、第二天收回不算破；是 SB1 性质的震仓点，起来后踏空者追悔。
- **宁德时代（极限买点案例）**：大哥抄底但量不完美 → 等 B1 → 回调一半看一半 → 极限买点 → 一鼓作气。
- **青花/深期粉酒（死叉卖点案例）**：205 跌破 205 撤，188 不走干到 164。
- **新前锋（死叉卖点案例）**：金叉 31 死叉 27，一股亏 4 块，不走连跌停。
- **中闪（金叉买死叉卖吃满案例）**：5.65 金叉买、8.84 死叉卖，牛市结束。
- **八一钢铁（循环操作法案例）**：B1/B2 皆可，8.34 可干。
- **乔丹（开口太大不买案例）**：白黄区间太远，"不买，真要买等打黄线"。
- **寒武纪/韩王 + 赛赛（入阁指数贡献案例）**：入格拉高=投名状，指数基金被动配置接盘，洗8交易日后无量锁仓再登。

## 十四、答疑要点

- 双线会过时吗？"不可能，只要主力做盘就是这两根线，几百个策略都围绕这两根线展开。"
- 期货能用吗？可以，调整到 5 分钟线用，找依据。
- 港股/美股适用吗？港股流动性差基础指标失真（做估值）；美股流动性强可用（尤其高大复值）。
- 宽窄有量化标准吗？没有，"每张图不一样"，但加速回到区间内就很宽。
- ETF 适用吗？大盘子有成交量的 ETF 适用。
- 粉丝自研回测：B1 钩 20-25 根 + 7%-9% 振幅搭配效果最好（10年回测8年训练2年测试）——师父认可并鼓励自研、往里揉。
