## 一、开超市（牛市仓位管理，本次核心）

### 1. 前提：熊市 vs 牛市的仓位哲学
- 熊市：不要开超市，重仓压几个确定性的票（"与其给一个男人好几次机会"）
- 牛市：要散开（"不如给好几个男人一次机会"）
- 原话："熊市时候要重仓压压压他妈的几个确定性的，而牛市就是要散开啊"
- 金句："与其给一个男人十次机会，不如给十个男人一次机会"

### 2. 第一大精髓：满仓 = 八成
- 举例：20万账户，超市开10个票，每个票多少钱？
- 标准答案：**每个票1.6万**（16万买满10个），**剩下4万是备用金**
- "打2万的全错，2万以下的全对"
- "你的满仓就是八成"
- 160 = 16万满仓 + 4万备用（ASR噪声，实际是"16万=1.6万×10，剩4万"）

### 3. 备用金 = 20% 仓位，给"两个大美女"留的
- 备用金作用一：B1之后又B1、SB1 时有钱加仓
- 备用金作用二（更重要）：**永远给完美的标的留有仓位**
- 原话："你这个4万，是给2个大美女留的"
- 场景推演：满仓时晚上选出一个"完美乔丹图B1"，但现有持仓没到放飞/止损位置，明天开盘就面临"卖哪个换新票"的抉择
- 反直觉结论：**你90%的可能会把大牛股给换没了**——因为：
  - 套你最多的票你舍不得砍
  - 赚很多的票你也舍不得卖（觉得还能涨）
  - 你会砍"还没启动、也没跌、但怕它跌"的票 → 而往往这个就是明天后天大后天的大牛股
- 原话："最好的票实际上就是最让你恐惧的那个票"
- "套住你的、往下杀套你的，那他妈是大傻逼"——你已经被渣女欺负了，还对她心存善念充满期待，但人早一去不复返
- **震仓预告**（未来讲）：震仓就是让你的票在成本区上上下下、不远不近反复折磨你

### 4. 第二大精髓：存款搬家只能一个一个仓位搬
- 禁止：满仓20万了，看上新标的，直接搬40万过来把账户变60万、花10万买新票
- 正确：可以从20万扩到22万，搬出2万（或1.6万）增加一个仓位
- 纪律：早晨增加的这一仓，**晚上收盘前把原本10个仓位拍掉一个**，收盘时账户还在20万左右；把早晨从存款账户"借"的钱还回去
- 目的：既不错过完美标的，又不变成变相加仓

### 5. 第三大精髓：配置逻辑（懂公司买公司，不懂买ETF）
- 不是所有标的都适合买ETF，也不是所有都适合买个股
- 白酒：80%业绩利润都是茅台的，ETF里混着啤酒/葡萄酒/调合酒（678/789/890位置），启动逻辑不同。所以懂的话**单配台子+中盘+小盘各一个**（业绩基石+股价弹性+纯血）
- 券商ETF vs 自己配大差不差，无所谓
- 煤炭逻辑同白酒（大中小各一个）
- 固态/储能/电池：三个ETF最后都是电池ETF，跟哪边都蹭不上 → 直接在固态/储能里找核心标的，不必上电池ETF
- 创新药：看得懂的公司配公司，看不懂配创新药ETF
- 原话："如果对这个公司了解，你就买公司；不了解但想上车，你就买ETF"
- 买10个ETF开摆？不如直接买一个宽基（1000/2000）就完了

## 二、白线 / 黄线双线系统（持股实操）

- 来源：充电的专储动态里已发，评论区下载安装
- **白线 = 短期趋势线**（不能破，破了短期两三天就"细火"了）
- **黄线 = 大哥线**（股价打上黄线，才有可能加速上涨/连续上涨）
- 白线就是"牵牛绳"/"拴牛绳"（做斗牛市）
- 离场顺序：先看白线 → 白线看完看黄线 → 看完黄线看白线黄线死叉
- 大盘也会打白线、打黄线、甚至破黄线——"没有人能完全判断，只有操盘手能画这个图，你要永远想到最差的结果"

### 下礼拜（神仙打架没那么激烈的话）反弹票的标准图形
- 之前呼吸良好：放量上涨 + 缩量下跌，跟着大盘同步调整下来，**同时在黄线之上**
- 阶梯量判断 = 跟前面最高点的量比；难看的两根 = 阶梯量，但"马上缩量"就没事

## 三、持股案例拆解（怎么玩这两根线）

### 案例A：中复电路（脱离成本区后的持股全过程）
- 独立行情起20%，又起10%点几
- 脱离成本区后回调 = 获利回吐，不是下跌（没破前低都叫回调，N型结构）
- 缩量到"直接缩了四分之三的量"，回调时该涨不涨、出上影 → 可能踩白线
- 金叉启动后：跌破白线别慌 → 等黄线 → 第二天没打黄线、第三天打黄线
- 打黄线踏实后：-5.99 / -5.98 钩大复值，又在红线之上 → 反弹概率高（量价：阳量放量锁量放量锁量、红长绿短）
- 最难熬的两根（在黄线附近反复一致）→ **就是震仓点，未来会讲**；满仓者第二天容易卖掉去追新标的 → 结果"直接一根14厘米"
- 前高位置缩量阴线 = 不像顶部；无放量创出新高 = 贝利（背离），牛股都贝利因为已锁仓
- 减仓逻辑：离白线越来越远、速率/斜率改变（加速）→ 该减仓/放飞
- 止损细节：41.96 破白线收盘斩；往下找 -5.98 位置（黄线，量价好）当新交易再买；止损看当日低位往下两三个价位 38.32 / 38.35
- 结论：牛票沿牵牛绳走，大概率踏不了大空；这一波波段赚的比之前还多一根阳线（10% + 15%），资金效率更高

### 案例B：夏无心（三缩战法初露）
- 周三讲："一二三、三缩量、八下来" → 三缩战法，大概率后面必创新高
- 结果周五盘中打新高、拉到13%
- 顶部三天无量（平量小尖顶）→ 不属于五种出货标准形态
- 心态："你大不了打我白线，打白线就打我放飞过的"；每拉一根阳线就放飞也适合胆小的人

### 案例C：中小盘拉升 = 对倒拉升，不是出货（反常识）
- 原话："外面有些人讲'主力都是拉起来出货'，出牛逼呢，都是没操过盘的"
- 中小盘/麒麟会票：快速拉升过程是对倒（自己买自己卖），为保控盘不丢筹码，不是出货（没放量来根涨停就是这么弄上去的）
- 逻辑：盘子就100亿/150亿/350亿，每天成交量就那点，50多手、200多手蹦蹦蹦买，根本没人跟风脱单，不可能边拉边出
- **真正出货都在相对高位放量出**（消息散出去、资金涌进来就倒给你）
- 徐翔出货最高效率 = 一字断头（锁仓拉升，然后一字断头两三天一天全倒完）
- 中小盘涨停放量 = 异动 = 很好的信号（真金白银进）
- 最可靠的是**超大盘的攻击性阳线**（大徜徉）——见下

### 案例D：超大盘攻击性阳线 = 指数贡献 = 名牌
- 例：韩王底部20厘米涨停、海光底部十多厘米大阳线、发载那根涨停（机构真买，缩量下来走圆弧巴直接40%）
- "又粗又长，还是大盘票" = 指数贡献，师父在指数贡献策略那段时间教的就是这个
- 得 案例：涨10.37%（创业板改20厘米前就是一根10%涨停），涨停板启动大盘股突破前期阻力位
- 次日"半量"（不是四分之三量）：半量=不显著；若走成标准四分之三量线，70%概率是假突破
- 突破前高颈线位的"放量又粗又长"K线 = **标杆 = 大哥的底仓**，后面所有的量都跟它比（对照组）
- 之后反包放量但没超过大哥量 → 无所谓；若走成放天量 → 至少卖一半（"宁可心及五不可心及五"）
- 大票从底部起来23%、离白线越来越远、速率改变加速 → 放飞一部分（"你要的是赚钱，不是男人那很傻逼的成就感"）

### 案例E：海光（大哥入场K线）
- 放量 8.83厘米 = 大哥入场，这根K线很重要
- 收一根接近半量的阳线 = 赚钱线/发财线
- 下来杀一根不难受：①白线之上 ②相对大哥线缩量；放量反包后跟"得"一模一样
- 斜率变高、脱离白线快20%-30% → 至少减一点、该放飞放飞
- 盘后放飞后真打20%（收12.92、约13%）→ 短期离白线快50% → 至少卖一半
- 杀6.13%再杀 → "一先补缺口，二到白线"；"等白线上来，不是让你等白线"
- 反包后第二天放量包两根、量不足则再见（减仓）；大副值 -5.52 时睡得着觉，可开始买（但别加仓，系统里只有减仓没有加仓）
- 关键卖点识别：加速之后连续上升后的放量大阴线 = 第一种出货方式，**不再考虑假阴真阳，一律统一标准：放量就减，走错也要走，至少减一半**（"宁可信其有不可信其无"）
- 分歧巨大的一根：当日振幅 11.53%，获利盘出好多、筹码不稳 → 师父会只剩三分之一甚至四分之一，基金的话直接全卖

### 案例F：小V（两卖点实战复盘）
- 两根B1买入 → 脱离成本区 → 某两天拍掉（一天捡一部分舱）
- 第一卖点：量没放那么高但平量 → 对应第二种出货形式（次高点放量）；若次日跌停放巨量则标准第二种出货
- 后面最高登到 44.99，但师父不可能卖到（必须等他后面确认）；卖点之后 25个交易日（一个多月）持有完全无效率
- 两根合并换算 = 一根放天量的大阴线（标志性）
- 后面又给一个B1（12点多，很多人吃到）→ 跌破白线拍掉；没捡过仓的这把白做
