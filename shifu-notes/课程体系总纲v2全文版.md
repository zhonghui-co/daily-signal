## 二、战法谱系（意在前、形在后）

> 编排逻辑：按"赚钱的层次"从底层到高层排列——**择时（何时出手）→ 选股（买什么）→ 买点（B1/B2/B3）→ 持有（双线/防卖飞）→ 卖出（S1/放飞/滴滴）→ 专属形态战法（对称/砖型图/关键K/瑜伽裤/击穿/筹码/MACD）**。每个战法先讲「意」（赚什么钱、底层逻辑、适用环境），再讲「形」（操作细则、参数 ⚙️ 以 MOS 系统为准）。

### 0. 总纲级工具：择时（0AMV 活跃市值）与双线（白线/黄线）

这两个不是单一战法，而是所有战法的"前置环境判断"与"后置持仓骨架"，放在最前。

#### 0.1 择时（活跃市值 0AMV）

- **意**：先于选股解决"现在能不能做"。活跃市值（HYSZ / 0AMV）判断大盘**真实增量资金**——红柱=钱转筹码（涨）、绿柱=筹码转钱（跌）；本质=**赚钱效应**。空头区间一切买点分析都降级，多头区间随便干。师父名言："投资收益不来自勤奋，而来自节奏。"
- **形**：⚙️ MOS 现行口径——转多 = 1-2 日合计涨幅 > **+6.5%**；转空 = 跌幅 < **-4.5%**。课程原始口径（+4% 转多 / -2.3% 转空）仅作历史参照。空头区间唯一动作 = 只卖不买、去弱留强。
- **出处**：20250702（首次）、20251012、20251022（极简"只看两个数"）、20251203（手紧手松）、20260415。

#### 0.2 双线（白线 / 黄线）

- **意**：白线=短期趋势线/牵牛绳（持仓跟随线，主升浪不破）；黄线=大哥线/多空线（主力是否入场的标志、拉升前极限洗盘位、主力控盘成本线）。**"白线之上做、黄线之上才做 B1"**。三条性质合起来一句话：黄线是大哥的底牌，白线是自己的安全带。
- **形**：⚙️ MOS 现行口径——白线 = **EMA(EMA(C,10),10)**；黄线 = **BBI(14,28,57,114)**。金叉=上涨确立等回踩 B1；死叉=最后离场。熊市/震荡用黄线单线、右侧牛市用双线吃满波段。⚠️ 注意：20260422 MACD 语境里的"白线=DIF、黄线=DEA"是另一套，勿混。
- **出处**：20250831（诞生）、20250906（唯一精确公式）、20251004（最完整论述）。

### 1. 少妇战法（六步）——体系总纲

- **意**：本质=**跟随不是预测**。赚的是"第一波填坑的钱"（N 型结构回到前期高点）。解决散户三大死穴：①一买就被套（B1=短期获利盘/卖盘枯竭的位置）②盈亏比差（向上 10% / 向下 2% ≈ 5:1）③节奏乱。适用环境 = 有增量资金的多头区间（B1 才有意义）。
- **形**（六步）：
  1. **择时**（最难）：经济周期 + 政策指引 + 增量资金（最重要）+ 入场时机（等 B1）。
  2. **选股（五看）**：看政策 / 行业 / 龙头公司 / 有没有人搞（资金/大哥）/ 估值（主题可放一放）。
  3. **等比一（等 B1）**：主线等周 B1、主题等日 B1；⚙️ J < 15（MOS 口径）。
  4. **设止损（上套）**：当根入场 K 线最低点下方 / N 型上一低点；"只输一根"。
  5. **止盈放飞**：BBI 线上两根中大阳减仓；放飞后不管。
  6. **彻底离场**：连续两日跌破 BBI 线收队。
- **成功率（🔶 口径漂移，仅供参考、不重要）**：约 30%（游资打板十分之零点五）；胜率三处不一致（55-60% / 37-40% / 40%多）——**三个数字仅供参考、不重要，不作定稿依据（MOS 定稿：B1 胜率不重要）**。
- **出处**：20250531（前 4 步）、20250709（补 5/6 步）、20250712（B1 本质）。

### 2. 补票战法 / 单针下 20/30——偷袭机构的超短

- **意**：专治"错过 B1"。用知行洗盘短线指标（红线=机构/长期资金、白线=散户/短期资金）抓主力"既控盘又让散户在底部换筹码"的洗盘末尾。赚的是主声浪里洗盘结束到再拉升的那一段。只在小资金、只做看得懂的那一根。
- **形**：单针下20 = 白线≤20 + 红线≥80；单针下30 = 红线 70 / 白线 30（参数可选 80/20、85/30、70/30）。只在主声浪（斜率 35~60 度，45 度最完美；60 度以上冲刺波不用）；持有 1 交易日、必须脱离成本、未脱离次日开盘拍。
- **出处**：20250601、20260429、20251126。

### 3. 挖坑填坑战法——中长线第三件武器

- **意**：赚"恐慌深坑 → 修复"的确定性钱。核心是**目标价算法（祖宗之法）**：坑口价×2 − 坑底价。大坑（月线级）靠信仰拿住、小坑（周线级）用少妇战法、小洞（不建议碰）。适用环境 = 有基本面、有主线/主题背景的坑。
- **形**：三个不能做（没填像样坑 / 基本面不懂 / 不在当前主线主题）；三个能做（填完中型坑出坑回踩 / 填大坑 N 型完美 / 主线出坑低点抬高）。破位=破坑沿（不是破低点）；假破位=跌破该段 50% 后收回。
- **出处**：20250625、20250626、20260219。

### 4. B1 / B2 / B3 三件套——买点体系（组合关系核心）

**组合关系**：**B1（等比一，最低位潜伏）→ B2（确认 B1 的那根放量阳线）→ B3（⚙️ 定稿：放量后缩量两天加仓点；原“中继小阳”为历史口径）**。B2 一定接 B1（不是凭空突破）；B2 确认 B1、B3 确认 B2（三重保险）。三维排名：**盈亏比 B1>B2>B3；确定性 B3>B2>B1；止损幅度 B2>B3>B1**。

- **B1**：意=赚第一波填坑的钱，盈亏比最高、潜伏型；形=⚙️ J<15（勾到大复值）。附加量化（20250903）：涨幅 -2%~+1.8%（小阴小阳）、振幅 ≤7%（最好 ≤4%）、缩量地量。次日涨停概率 ≈1%，买入后 3 天窗口。
- **B2（三大高爆发力）**：意=确认 B1 后最快启动、最敏感；形=①平行重炮（平行位置放量长阳 ≥2 根）②灾后重建（放量金叉后缩量回踩黄线、黄线处放量长阳确认）③跃跃欲试（横盘放量大阳、红肥绿瘦、事不过三）。选股 5 条件：B1 后勾拐头 / 涨幅 ≥4% / 放量 / 勾 <55 / 无上影线最好。
- **B3**：意=最安全的中继买点（"B3 比 B1 安全"）；形=⚙️ 定稿：以 MOS 说的为准（系统现行 B3=放量后缩量两天加仓点）。历史课程口径：缩量小阳/十字星（长安战法）、必须涨、不涨马上拍（最多等 1 天）；⚠️ 师父 20260415 自认"没系统讲过、没给图"（该"待补课"已由 MOS 定稿作废）。
- **出处**：20250907（三件套成型）、20251006（B2 最完整）。

> **⚙️ 定稿：以 MOS 说的为准（系统现行 B3=放量后缩量两天加仓点）。** 以下为历史课程口径（🔮 归纳推演，非师父原话）：B3 曾被归纳为“B2 放量启动、趋势确立后”的缩量回踩/中继确认买点，三重排名里确定性最高（B3>B2>B1）、盈亏比最低。师父零散口径仅三处——20251006“B3=中继小阳”、20250907“B3=缩量小洋实体（振幅 4.39%、7% 以内）”、20260415“B3=大阳后缩量长安图”——从未给完整图与条件，且 20260415 当场自认“没系统讲过、没给图，回头补一节”。B3 之后趋势已成、专形图稳定性低，应改盯白线（牵牛绳）而非专形图（20260415 原文）。

### 5. 建仓波 / 拉升波 / 冲刺波——一波行情三阶段

- **意**：把一波行情拆成三段，判断"现在赚的是哪一层的钱"：建仓波（底部放量、涨幅 25-50%、不涨停，主力吸筹）→ 拉升波（快速脱离成本、不翻倍）→ 冲刺波（75-80 度连板）→ 横盘 → 再建仓波。**建仓波不追（要等第二个 B1 甚至 SB1）、拉升波选股谨慎、冲刺波是出货区。**
- **形**：建仓波"两个 30%"（涨幅 + 大阳线累计换手率各 30% 掐正态分布尖）；换手率 >100%（甚至 150%）=一波流出货。涨停幅度折算（创业板 20% / 主板 10%）。
- **出处**：20250716、20251217、20260309。

### 6. 双线战法（白/黄）与循环操作法

- **意**：少妇战法的"pro 版"——用白黄两条线把"跟随"固化成可循环的持仓骨架，解决"拿不住主升浪"。
- **形**：到 B1 抡 → 白黄区间接着抡 → 加速放飞 → 跌破白线（顶部无量未出货）→ 回 B1 再买，反复循环。"碗"=白线与黄线之间容错买入区（不必追求完美 B1）。
- **出处**：20250831、20251004。

### 7. 防卖飞策略——主升浪拿住主仓

- **意**：牛市多急跌（盘中/隔日洗盘），真顶唯一标志=放巨量大阴线（放天量）。未放天量的快速下杀一律先当洗盘。价值 1200 万的踏空教训。
- **形**：每日持股检查 7 条（核心：只看收盘价是否比前一天高）；五分评分体系（收盘价升/不破 BBI/无巨量阴线/趋势向上/勾未死叉，5 分拿住、3 分可减、2 分完蛋）。
- **出处**：20250730。

### 8. 卖出体系：S1 / S2 / S3 + 放飞 / 滴滴 / 赢转亏

- **意**：卖点是买点决定的；卖出信号是买点的镜像。S1=加速后放天量大阴线（最确定大顶，"走错也要走"）。⚙️ 定稿：S2、S3 不存在——卖点体系只保留 S1（加速后放量大阴线）+ 两根就卖/死叉 + 活跃市值离场线；历史课程曾提及 S2=次高点/双头二次出货、S3=阶梯量/最后反抽，但 MOS 已定稿不采用。
- **形**：放飞（大阳线先卖 10%~50%、中长阳 4%+/大阳 7%+）；滴滴（N 型反弹高点结束/高位两根阴线第二根破第一根最低点）；赢转亏（浮盈转浮亏即走，优先级最高）。主力出货方式（历史课程曾列五种：①S1 ②S2 ③S3 ④双头双放量巨阴 ⑤顶部绿肥红瘦 + 第六种综合出货）——⚙️ 定稿后 S2/S3 不采用，只保留 S1 + 两根就卖/死叉 + 活跃市值离场线。
- **出处**：20250824、20250917、20251112、20260415。

> **⚙️ 定稿：S2、S3 不存在——卖点体系只保留 S1（加速后放量大阴线）+ 两根就卖/死叉 + 活跃市值离场线。** 历史课程提及但 MOS 已定稿不采用：20250824「牛市逃顶」曾完整讲三级（S1=加速后放天量大阴线、S2=S1 后反弹做双头+MACD 顶背离、S3=反抽到放最大量阴线下沿清仓）；20260415 官方模块总结里师父已明确“双头起来=S2（不讲了），S2/S3 都不再讲，只看 S1”。

### 9. 对称战法——独门

- **意**：借杨振宁"对称性支配相互作用"——多空能量本质守恒，**交易做的是"不守恒/走势不完美"**。走横=平衡/对称=无交易价值；**走横的 B1 最有价值（本应跌却横住=趋势被改）**。最大价值=判断某个 B1/B2 到底有没有交易价值。
- **形**：从不完美（打破平衡）位置进，拿到对称（左右平衡/完美）位置卖。斜率太斜的 B1 第二天必须涨停；A 杀（直接对称完美下杀）票不碰；连续上涨后第 1、2 个 B1 别碰、做第 3 个。
- **出处**：20251022、20251027。

### 10. 砖型图三种定式（红持绿空 / 专形图 / Z-Ranko）

- **意**：底层=宝塔线 + 活跃市值 + 参数 + 量价。红持绿空、绿转红买、红转绿卖。核心是**"数四块砖"**（第 4 块红砖放飞、随时反转）——"4"源自威尔德 Delta 三角洲理论（市场每 4 天/4 月/4 年/19 年重复）。
- **形**：三种定式 = ①N 型起跳 ②横盘起跳（"大块红砖压绿砖"成功率更高，起来前一定要有横盘）③上升波段延续。三要素（缺一不可）= 位置 + K 线形态 + 砖块大小。卖出三条件 = 数四块红砖减/清、红变绿走、买入不涨次日走。参数 4 与 6；持仓 4~6 天。
- **出处**：20260220（瑜伽裤）、20260224、20260318、20260325。

### 11. 瑜伽裤战法（知行专形图超短线）

- **意**：寻找转折点的爆发力，只做"绿转强红"（红柱幅度 ≥ 绿柱三分之二），赚绿转红后两根 K 线的钱。师父自称"暗器/绝学"，第一次动私心教的真东西。只适合小资金搏命。
- **形**：位置过滤=黄线之上 + 白线在黄线之上（多头）才做；六步 = 绿转强红→尾盘买/次日不追高→分两仓→止损=买入 K 线最低价或 2 日不拉起走→蹬起来 3% 以上分批卖→脱离成本 5% 以上最多持 4~6 天。口诀：我要赚钱/给多少拿多少/不给就走/永不完美/下一个会更好。
- **出处**：20260220。⚠️ 底层参数"优化过的成功率参数"未公开，难以精确复现。

### 12. 关键K 战法

- **意**：绝大部分 K 线无意义，只服从 1~3 根关键K（关键位置/黄线上的放量中大阳线/涨停板）=大资金入场/离场信号。趋势反转六型（V 型/紧急刹车/平地惊雷[横盘→上涨，确定性最高]/A 刹/上涨转横/丢盔卸甲）+ 走势衰竭（卖盘枯竭=B1 买点）。
- **形**：画关键K 最高/最低两条线，站上最高价稳住才做多、跌破最低价离场；高开关键K 最低价≈主力建仓成本；量不够价值不大、不追等 B1。只适用大 A（T+1），港股不能勾大复值。
- **出处**：20251015。

### 13. 击穿对手盘——最难一课

- **意**：主力用缩量（长阴短柱）跌破短线对手盘的公众止损位（关键K/N 型低点/黄白线）来**洗盘吸筹，非真出货**；与"斩杀（放量长阴=真砸）"相对。散户正确姿势是"看穿"主力如何击穿，渔翁得利（帮大哥锁仓、与庄共舞）。口诀：**长阴短柱是击穿、放量长阴是斩杀**。
- **形**：只忍一根、次日收回；**你的止损位 ≠ 公众止损位**（不能设在关键K/N 型低点等公众位置）。三种必须走：破止损位/放量斩杀长阴/基本面逻辑重大改变。
- **出处**：20251231、20260211。

### 14. 筹码理论

- **意**：只看低位筹码有没有转移到高位——没转移=锁仓/没出完，转移=出货/换装。筹码峰下沿"不是顶就是底"：向上突破=底（新主力建仓）、向下跌破=顶（出货）。只判断建仓与出货、不决定买卖点；SE 永远优先于筹码。
- **形**：锁仓拉升=长庄形态（B1 敢买）；高位密集=危险；超大盘（万亿市值）不看筹码；反弹看上方套牢盘比例（需 ~80% 低位密集才可能启动）；周线不看筹码。
- **出处**：20260408、20260419。

### 15. MACD 用法——一票否决权 / 最后顾问

- **意**："唯一具有趋势预判性质的指标之王"，把 B1/B2/双线/S1/筹码验完再回看它。三大用法：判多空（DIF 零轴）/ 看背离（顶背/底背）/ 金叉空死叉多（空中加油）。背离背后 = 建仓完成后洗盘锁筹 → 量价关系失效 → MACD 难创新高。
- **形**：顶背离看日线、底背离可参考周线；与活跃市值印证（活跃市值先翻、MACD 后确认、共振最好）。⚠️ 白线/黄线在此是 DIF/DEA，勿与知行趋势线混淆。
- **出处**：20260422。

### 16. 指数贡献策略——防踏空

- **意**：赚"大而不倒"的确定性——每天收盘看个股对指数"贡献点数"，持续上榜的权重股=指数贡献股（工农中建/石油/移动等），下跌跌得比小票少、不存在对倒。2015 股灾后研发，专户年均约 25%。
- **形**：配法=一纯血+一混血；数量 10 万~100 万配约 10 个（5~7 行业各 1~2 个）；上车=等调回 B1 不追高；"入阁（调入指数）后半年~一年确定性行情"。
- **出处**：20250827、20251221、20251229。

### 17. 其他工具 / 战法（清单）

- **低波红利底仓**（散户版社保）：周线大复值买"大"、日线买"小"（比例 5:1），只买不卖，每年先保底约 5% 分红。
- **深水炸弹/双马尾/两排重炮**：两根放量巨量线（人为建底仓痕迹）。
- **四分之三阴量线**：突破次日量缩到前日 1/2~4/4 的阴线 = ≥70% 假突破，不加仓；缩半量以下 = 真突破 77-80%。
- **倍量柱**：量 ≥ 前日 2 倍 = 真实买入；倍量再倍量 = 天量（警惕放飞）。
- **长阴短柱**：长阴配缩量短柱 = 主力洗盘控盘。
- **低低战法（DD）**：用前一根 K 线低点作持仓线，收盘跌破前一天低点就卖。
- **手紧手松**：空头只做 B1（仓位 0-50%）、多头全策略（80-100%）。
- **每日五步工作流**：择时→定策略→复盘→选股→执行（每天 ≤12 分钟）。
- **仓位管理（盈亏同源）**：按单仓跌停幅度倒推仓位（主板 10%→20%、创业板 20%→10%、科创 30%→7%）。
- **大傻子战法（DSZ）/长安战法**：砖型图傻瓜式数砖；量在价先。
