## 第 1 层：全A N型 vs 状态机 头对头

- 数据：000985（中证全指，0AMV 相关性 0.9963 的代理），2018-2026 九年同窗
- 两臂：状态机(基准) / N型（挑战者）；各 + 买入持有（对照）
- 判据（预注册，N型必须全部满足才允许换引擎）：
  1. 九年净收益 ≥ 状态机净收益 − 3pp
  2. MaxDD ≤ 状态机 MaxDD + 5pp
  3. 三个熊年（2018/2022/2023）每年收益 ≤ −10% 的次数 ≤ 状态机
- W 稳健性：W∈{2,3,4,5} 网格，≥3/4 个 W 满足上述判据；只在 W=3 成立的结论作废（参数孤点）

## 第 2 层：板块 N型转涨 事件研究

- 数据：申万 L1 31 个指数九年日线（近似版；v4 正式口径为自由流通股本加权 0AMV，差异 ~2%）
- 事件：因果 N型状态 由非上涨N → 上涨N 的首日（转涨日）
- 度量：事件后 5/20/60 日超额收益（板块收益 − 000985 收益，剔 beta）
- 对照臂（缺一不可）：
  - A 随机日期臂：同等数量随机日期（同板块集合），超额收益分布
  - B 全板块同日臂：事件日当天全体板块的平均超额（剔除"那天大盘好"的成分）
- whipsaw 先数后测：每板块每年状态切换次数，预注册阈值 = 年均切换 ≤ 10 次（超过则"任意违规断开"规则成本不可行）
- 判据（预注册）：20日超额中位数 > 0 且 > 随机日期臂中位数 + 1pp，且 5/60 日方向一致；W 网格 ≥3/4 稳健

## 第 3 层：N型上涨板块里的 B1 增量（真正值钱的问题）

- B1 信号按所在板块因果 N型态分组，比前向分层收益
- 验收尺子：B1∣板块上涨N 较 B1∣板块非上涨N 的分层增量 ≥ +0.3pp/笔（前向、真次日、扣费）
- 依赖：板块 N型态九年序列（第2层产出）+ 全市场 KDJ/日频（库内 2018 起）
- 状态：第 1、2 层通过后启动
