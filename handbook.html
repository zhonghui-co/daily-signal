卷零 · 为什么你要读这个

先回答一个问题：为什么你炒股老是亏，而有人能稳定赚？

因为市场是筹码游戏——你赚的每一分钱，都是别人亏的。而散户和主力之间，存在三个你永远追不平的差距：

  • 信息差：主力永远比你先知道消息。
  • 资金差：主力不缺钱，散户的钱是有限的。
  • 定价权差：价格是主力说了算，散户只能跟随。

    • 所以散户想在市场活下来、甚至赚钱，只有一条路：不要和主力对着干，而是站在主力那一边——师父管这叫「找大哥」。

    这套体系，就是教你怎么「找到大哥、跟住大哥、在正确的时候上桌、在危险的时候下桌」。

    通识（书里教的"价值投资""长期持有"）在博弈里是被拿捏的料。这套体系不是通识，是非对称优势。
    📖 背景知识（先认识几个词，后面全要用）：
    - 筹码：股市黑话，指「你手里的股票」。买入 = 拿钱换筹码，卖出 = 拿筹码换钱。
    - 主力 / 庄家：手里资金量大、能影响股价的大资金（机构、游资、国家队等）。
    - 散户：资金小、只能跟随的个人投资者，也就是"你"。
    - K 线：一根竖线记录某只股票一天的四个价格——开盘价、最高价、最低价、收盘价。红色=涨（收盘>开盘），绿色=跌（A股约定）。后面说的"只输一根"，就是"只亏这一天的波动"。

    卷一 · 世界观：先懂市场是什么（道）

    1. 市场是筹码游戏，不是"投资"

    你买入股票，本质上是用钱换筹码；卖出，是用筹码换钱。活跃市值这个指标（后面会讲）衡量的就是"钱和筹码在怎么换"。

    师父的话："市场没有为什么，只有应对。" 别问"为什么跌了"，只需要应对——给了就拿，没给就走，跌了止损，起来了拿着。

    2. 大哥才是定价的人

    大哥 = 主力 / 庄 / 麒麟会 / 国家队（不同语境指不同的主导大资金）。

  • 大哥入场，行情才有持续性；
  • 大哥没上桌，所有上涨都是噪音；
  • 大哥走了，你也得走。

    • 师父铁律："只要大哥没上桌，局部所有都是噪音；大哥走你就走。"

    3. 先保命，再谈赚钱

    📖 背景知识：
    - 止损：股票跌到某个预设价位，不管多难受，都强制卖出，把亏损"截断"。
    - 套牢：股票跌了却不卖，一直扛着，钱被"套"在里面出不来，越套越深。
    - 杠杆：借钱炒股。赚了放大赚，亏了放大亏，甚至亏光还倒欠。

    这是整套体系的第一公理，比任何技术都重要：

  • 只用输得起的钱：不加杠杆、不借钱、不用急钱、不卖房炒股。
  • 止损无情：亏损的第一课就是"不要被套住"。
  • 永不套牢，只输一根：亏损控制在买入那根 K 线的范围内。

    • 师父原话："先保命，永远记住先保命。" 你能赚多少是市场给的，你能亏多少是自己决定的。

    4. 垃圾时间休息，耐心等待

    市场大约 66% 的时间是垃圾时间——主力轮休，行情无意义。这时候最聪明的操作是不操作。

    师父八字总纲："耐心等待，伺机而动。"

    小结（卷一）：市场是筹码博弈 → 跟大哥 → 先保命 → 垃圾时间休息。这四条，是后面所有技术的前提。世界观不对，技术再好也是送钱。

    卷二 · 大势判断：什么时候能做、什么时候该歇（看天）

    1. 核心指标：活跃市值（0AMV）

    活跃市值是判断"大盘真实增量资金"的最有效指标（指南针软件发明，杨新宇+陈昊）。

  • 红柱 = 钱换成筹码（资金进场，涨）
  • 绿柱 = 筹码换成钱（资金离场，跌）
    • 📖 背景知识（这些词是"活跃市值"的原料，先看懂）：
    - EMA（指数移动平均）：一种"均线"，越近的价格权重越大，比普通平均更灵敏地跟随最新走势。EMA(成交量,10) = 最近 10 天成交量的指数平均。
    - OHLC：Open/High/Low/Close 的缩写，即一天的开盘价、最高价、最低价、收盘价。
    - 成交量：当天成交了多少股。成交量大 = 交易活跃、资金进出猛。
    - 换手率：当天成交的股数 ÷ 流通股本，衡量"这只票被买卖了多大比例"。
    - 流通股本：能在市场上自由买卖的股份总数。
    - 多头 / 空头：多头 = 看涨、资金在进；空头 = 看跌、资金在撤。

    我们的工具（v6）是「双口径」，两组阈值：

    口径算法转多阈值转空阈值用途
    口径1（主）Σ(10日EMA成交量 × OHLC)+6.5%-4.5%活跃市值作战图（v6.html）主力口径
    口径2EMA(换手率,30) × 流通股本（活筹）+5.4%-2.6%0AMV v2 活筹口径
    📌 注解：
    - 为什么两组阈值？ 两个口径的算法不同，量纲和波动幅度不同，所以阈值也各自校准过。口径1 加成交量平滑（EMA10）后波动更大，阈值相应放宽到 +6.5%/-4.5%；口径2 是换手率加权的活筹，波动相对小，阈值收紧到 +5.4%/-2.6%（外部拟合 8/17 定）。
    - 师父课程里的原始口径是 +4%/-2.3%，那是最早、最松的版本。我们工具里已经迭代到上面两套更精确的双口径。
    - 核心逻辑三者一致：涨幅超阈值 = 钱进场 = 多头；跌幅超阈值 = 钱离场 = 空头。具体用哪个阈值，看你用哪个口径的数据。你也可按自己风险偏好微调，但别调太松。

    2. 师父四步链：每次判断前必走

    这是强制前置流程，任何行情/个股/大势判断，下结论前必须先走完这四步：

    ① 大哥在不在：主力资金有没有真金白银进场（绝对值 + 连续性），有没有明确主线。大哥没上桌，一切判断降级为「观察」。

    ② 周期定位：先答「现在在哪个周期、哪个位置」——政策底 → 资金底 → 市场底，到哪一步了。单日涨跌放进周期里看。

    ③ 噪声三问：①基础概率多大？②证据能不能交叉验证（价格/资金/方向是否一致）？③谁受益、谁在割谁？用这三问给新信息定权重。

    ④ 纪律锁：不追高、等 B1、控频率、留预备队、先保命。判断的终点是「该不该动、动多少、错了怎么止损」。

    小结（卷二）：活跃市值看多空 → 四步链定判断。空头区间=垃圾时间，休息；多头区间才考虑动手。

    卷三 · 选股逻辑：涨了买什么（看地）

    1. 核心框架：从 Beta 里找 Alpha（三层递进）

    📖 背景知识（金融圈最核心的两个词）：
    - Beta（β）：跟随大盘整体涨跌的那部分收益。大盘涨 1%，你的票也跟着涨 1%，这 1% 就是 beta——你赚的是"水涨船高"，不是自己的本事。
    - Alpha（α）：跑赢大盘的那部分超额收益。大盘涨 1%，你的票涨 5%，多出来的 4% 就是 alpha——这才是真本事赚的钱。
    - ETF：交易型开放式指数基金，一篮子股票打包成一个可以像股票一样买卖的品种（比如"半导体ETF"= 打包买一篮子半导体股）。买 ETF = 买整个行业/大盘的"平均涨跌"，也就是 beta。
    - 行业 / 板块：把业务相似的公司归成一类（如半导体、医药、白酒），方便看"哪类在涨"。

    这是选股的灵魂，三层递进：

    第一层：Beta 是大盘普涨？

    先确认这是不是大盘整体上涨（beta）。如果是，光吃大盘 beta 不够。

    第二层：从行业里找 alpha

    普涨中，跑赢大盘的行业 = 行业 alpha（主力资金明显净流入、超额收益）。

    第三层：行业 beta 里再找 alpha

    当一个行业被 ETF 化、买 ETF 就等于买行业 beta 时，钻进行业内部，找真正有超额的具体个股。

    一句话：大盘涨是 beta，行业跑赢是 alpha；行业被 ETF 化后买 ETF 又退回 beta，得下沉到个股再找 alpha。选标的永远往「超额收益」的方向钻。

    2. 主线 vs 主题：两种不同的"涨"

    主线主题
    性质能容纳中长线/机构资金、对全市场有号召力概念票、快进快出、一波流
    轮动有轮动容错无轮动
    例子新能源车、科技、白酒顺周期可控核聚变、创新药、低空飞行
    做法等周线 B1、潜伏 3-4 天右侧 B1 一波流

    师父："主线做增强，主题做超额。"

    小结（卷三）：先看大盘 beta → 找跑赢的行业 alpha → 下沉到个股 alpha。主线可长做，主题快进快出。

    卷四 · 买点：什么时候买（术）

    这是整套体系里最精细、也最容易出错的部分。前面三卷告诉你"该不该做、买什么方向"，这一卷告诉你"具体在哪个价位、哪根 K 线上出手"。

    1. 两根线：白线和黄线

    📖 背景知识：
    - MA（简单移动平均）：最近 N 天收盘价的算术平均。MA14 = 最近 14 天收盘价加起来除以 14。
    - BBI（多空指标）：把 4 条不同周期的 MA（14/28/57/114 日）再平均一次，得到一条"中长期平均成本线"。
    - 金叉：短线上穿长线（白线上穿黄线），转强信号。
    - 死叉：短线下穿长线（白线下穿黄线），转弱信号。
    - 放量 / 缩量：成交量比前一日明显放大 = 放量；明显缩小 = 缩量。

    这是师父体系的地基，几乎所有买点、卖点、纪律都围绕这两根线展开。

    线全称公式含义
    白线知行趋势线（牵牛绳）EMA(EMA(收盘价,10),10)短期资金趋势线，主升浪不破白线
    黄线知行多空线（大哥线）(MA14+MA28+MA57+MA114)/4（即 BBI）主力成本线 / 多空分界线
    📌 注解：
    - 白线 = EMA 的 EMA：对 10 日指数均线再平滑一次，是"短期趋势的趋势"，更灵敏地跟随主力。
    - 黄线 = BBI：4 条均线（14/28/57/114 日）的平均，代表"市场中长期平均成本"，近似主力的控盘成本。
    - 师父课程里黄线有过"60 日线"的旧说法，但体系定稿口径是 BBI(14,28,57,114)。周期参数可以微调，白线的 10 日建议别动，它是灵敏度核心。

    两根线的核心关系（必背）：

  • 白线 > 黄线 = 趋势上行（多头结构），可以做多；
  • 白线 < 黄线 = 趋势走坏（空头结构），不做或离场；
  • 白线上穿黄线（金叉） = 转强信号；
  • 白线下穿黄线（死叉） = 转弱信号。

    • 2. KDJ 的"勾"：判断超买超卖

    📖 背景知识：
    - KDJ（随机指标）：一个衡量"当前价格在过去一段时间里处于高位还是低位"的技术指标，由 K、D、J 三条线组成。
    - J 值（师父叫"勾"）：KDJ 里最灵敏的那条线，波动最大。J 值越低 = 越超卖（跌过头了），越高 = 越超买（涨过头了）。
    - 超卖：短期跌太狠，卖压释放过头，往往要反弹。
    - 超买：短期涨太急，买盘透支过头，往往要回落。

    KDJ 里的 J 值，师父叫它"勾"。

  • 勾到极小值（大复值） = 超卖 = 阶段性低点，买入时机窗口；
  • 勾到极大值 = 超买 = 阶段性高点，警惕回落。

    • B1 的阈值（量化，可微调）：

    📌 注解：师父体系里 B1 的 J 值阈值有多个历史口径（13 / 12 / 10 / 20 都有提过）。体系定稿标准是 J < 13，但师父多次强调"每个票有自己的性格，有些票到 20 以下就是底部"。所以：
    - 保守者：用 J < 10（等更深的超卖）；
    - 标准：J < 13；
    - 激进者：J < 20（但容易接飞刀）。
    关键是"J 在低位 + 缩量 + 趋势没破"三者同时满足，而非死磕一个数字。

    3. B1 / B2 / B3：三个买点

    这是师父体系的核心买入节奏，三个买点依次递进，确定性递增、盈亏比递减。

    买点定义特点
    B1勾（J）勾到低位（<13）的阶段性低点盈亏比最大，确定性最低，潜伏 3-4 天
    B2确认 B1 低点的那根阳线（涨幅 ≥4%、放量、勾拐头）确定性提升，止损幅度稍大
    B3B2 之后的中继小阳（缩量）确定性最高，但盈亏比最小
    📌 注解：B3 在师父课程里没有系统讲过、没给图，定义略有缺口。实操上 B1 是核心，B2 是确认，B3 可作参考。三重排名：盈亏比 B1>B2>B3，确定性 B3>B2>B1，止损幅度 B2>B3>B1。

    4. B1 的真正语义：切 alpha 的时机（重点）

    这是本体系最精髓的一句话，很多人误以为 B1 就是"抄底"，其实不是：

    B1 = 在趋势上行的回调中（J 值跌到极小值），完成一次「切 alpha」的动作。

    拆开理解：

  • 大前提：趋势上行（白线 > 黄线，多头结构没破）——B1 不是空头里抄底，是多头趋势里的回调。
  • 时机：回调把 J 值打到极小（超卖）——回调到位了。
  • 动作：两种——
  • 从 beta 切到 alpha：已持有大盘/行业 beta（ETF 或跟随大盘的票），在回调时把仓位从 beta 换成真正有超额的具体标的；
  • 从空仓直接买 alpha：本来空仓，在回调低点直接切入 alpha，而不是先买 beta。
    • 关键：B1 不是"抄底大盘"，也不是"买入 beta"，而是在回调的时机窗口里，把资金从 beta 换到 alpha（或空仓切入 alpha）。

    5. 止损：只输一根

    📖 背景知识：N 型结构 = 股价"低点 → 高点 → 更低点 → 更高点"这样一低一高交替走出的波浪形，像字母 N。上涨趋势里，低点一次比一次高、高点也一次比一次高。止损常设在前一个低点下方。

    买入后，止损位怎么设？

  • 买入当根 K 线的最低点，往下 3~5 个价位（或 1%~3%）；
  • 或 N 型结构的前低。

    • 核心心法："永不套牢，只输一根。" 亏就亏这一根 K 线的钱，不扛、不补、不幻想。

    📌 注解：止损幅度有多种口径（前低下 3-5 价位 / 3% / 3~5% / 无前低时 1%~1.5%）。核心是"只输一根"——把亏损限制在买入那根 K 线内，具体下探多少点位按风险承受微调。越保守止损越紧。
    小结（卷四）：白线黄线判趋势 → KDJ 勾值判超卖 → B1（趋势上行回调中切 alpha）→ 只输一根止损。买点的精髓不是"跌了就买"，是"多头趋势 + 回调到超卖 + 切 alpha"。

    卷五 · 卖点与纪律：什么时候卖、怎么守住（法）

    📖 背景知识：
    - 阳线 / 阴线：收盘价高于开盘价 = 阳线（红，涨）；收盘价低于开盘价 = 阴线（绿，跌）。
    - 大阳线 / 大阴线：涨/跌幅度很大的那根 K 线。
    - 天量：成交量创出很长一段时间以来的最大量，往往是见顶或见底的极端信号。

    1. 卖出信号（S1 / 放飞 / 滴滴）

    信号含义动作
    放飞大阳线起来先卖一部分（10%~50%）减仓落袋，不贪
    S1加速后放天量大阴线（天量天价）最确定的大顶信号，走错也要走，至少减一半
    滴滴（DD）高位两根阴线，第二根收破第一根最低价离场

    师父："卖是为了买，买是为了卖（先分手才能找更好的）。"

    2. 纪律：反人性的锁

    这是整套体系的"操作系统"，技术是招式，纪律是内功：

  • 不追高：追高是坏习惯，概率上亏 > 赚。等 B1、等回调。
  • 控频率：一周最多 1-2 个新仓。频繁交易是亏损最大来源之一。
  • 留预备队：满仓 = 总资金八成，永远留 20% 给当天选出的完美标的。
  • 交易只分正确/错误，不分成功/失败：按纪律止盈止损（哪怕亏钱）就是正确交易；不按纪律（追高、不止损），哪怕涨停也是错误交易。

    • 师父："纪律是反人性的锁。大师靠纪律而非天赋，散户和大师之间差的就是「到点执行」这四个字。"

    3. 完整闭环

    ① 大势判断（师父四步链）→ ② Alpha 挖掘（beta→行业alpha→个股alpha）→ ③ 等 B1（回调 J 极小）→ ④ 执行「切 alpha」+ 纪律锁

    小结（卷五）：放飞/S1/滴滴是卖点；不追高、控频率、留预备队是纪律。判断的终点是「该不该动、动多少、错了怎么止损」。
